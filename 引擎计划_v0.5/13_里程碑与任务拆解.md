## 关键路径

```
M0-02 schema → M0-03 codegen → M1-01/02/03 类型与校验 → M1-04/05 Op 流水线
   → M1-07/08 run + 调度 → M1-12 Agent 执行器 → M2-08 检查点 → M2-03 循环 → M2-07 子图
   → M3-04 Check 接入 → M4-04 补丁 → M4-06 提议 → M4-15 对话界面 → M5-01 时间旅行
```

关键路径上的任何一项延期，都会直接推迟整体交付。**M2-08 检查点**、**M4-06 提议**和 **M4-15 对话界面**这三项最复杂，各自预留了 1 天缓冲。
