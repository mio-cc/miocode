## 1. 语气
- 像一位靠谱的同事在说明情况：直接、具体、平静。
- 用"你"称呼用户；AI 自称"我"（对话里）；系统提示不用第一人称。
- 不卖萌、不用感叹号、不用"亲""哦"、不道歉过度（"抱歉"只在确实是程序问题时用一次）。

## 2. 用词
- **U.15-R1** 只用 `P.06` 术语表里的标准名或界面名；"不要叫"列里的词一律不出现在界面上（`G.02.05-R26`）。
- **U.15-R2** 不用技术黑话：界面上说"AI"不说"LLM"；说"数据"不说"T"或"泛型"；说"子图"不说"subgraph"；说"等待审批"不说"挂起"。技术名词（端口类型、事件名、路径）只在展开的详情里出现。
- **U.15-R3** 节点类型名、端口名、参数名按 NodeDef 的 `label` 显示；内部名（`output_schema`）只在详情和悬停提示里出现。
- **U.15-R4** 数字和单位：`12 秒`、`3.2 万 tokens`、`¥0.42`；大于 1 万的 token 数用"万"；时间用相对时间（"2 分钟前"），悬停显示绝对时间（本地时区）。

## 3. 句式
| 场景 | 句式 | 例子 |
|---|---|---|
| 按钮 | 动词开头，2–4 个字 | 运行、采纳、全部拒绝、进入编辑 |
| 状态 | 名词或"正在…" | 已完成、正在重连 |
| 错误 | 发生了什么 + 怎么办 | 「验收者」缺少模型。连接一个资源节点到 model 端口 |
| 确认框 | 问题 + 后果 | 删除会话「竞品调研」？图不会被删除，可以在「所有图」里找到 |
| 提示 | 一句话，不超过 30 字 | 双击进入子图，单击缩略图预览 |
| AI 的理由 | "为了……，" 开头 | 为了避免错误的"达成"让流程提前结束，加一道人工复核 |

## 4. 文案存放
- **U.15-R5** 所有界面文案在 `web/src/lib/i18n/zh.ts`（按区域分组），错误和诊断文案在 `schema/builtin/messages/*.zh.yaml`（`G.13-R5`）；组件里不写中文字面量（`G.06-R4`）。
- **U.15-R6** 文案键名格式 `区域.对象.用途`：`nest.parent.title`、`run.status.waiting`。
