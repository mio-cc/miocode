## 1. 运行状态动效
| 状态 / 事件 | 动效 |
|---|---|
| 节点 running | 头部状态点为橙色旋转弧（持续）；外框 `accent-line` + 3px `accent-weak` 光晕，进入时过渡 `--hx-t-2`；状态脚进度条 `scaleX` |
| 循环节点 running | 头部状态点改为环形进度（按 `轮次 / 最大轮数` 填充） |
| 节点刚完成 | 状态脚收起，留 2px 绿线，1.2 秒后淡出 |
| 连线有数据通过 | 叠加一条 `stroke-dasharray: 1 11`、圆头的 `--hx-accent` 路径，持续动画 `stroke-dashoffset`，像光点流动；只加在活跃连线上 |
| waiting | 黄色暂停符，不动；节点上的等待时长每秒更新（文字，不是动画） |
| 模型直接修改了节点 | 节点闪一下 `--hx-model` 光环 600ms |
| 模型正在编辑 | 顶部条"模型正在编辑…"胶囊左侧的模型色呼吸点（透明度 0.4 ↔ 1，周期 1.2 秒） |
| 急停 | 顶部条立即变为 `danger-weak` 底（不渐变）；运行中的节点立即转为取消态 |

- **U.07.03-R1** 同时运行的节点超过 30 个时，连线流动动画只保留最近活跃的 30 条（性能）。
- **U.07.03-R2** 画布处于 LOD 第 3 级（`U.10.06`）时，关闭连线流动动画，只保留节点颜色变化。
