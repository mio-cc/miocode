# U.07.04 减少动效模式

| 项 | 内容 |
|---|---|
| 编号 | U.07.04 |
| 类型 | 规范 |
| 上级 | U.07 动效 |
| 下级 | 无 |
| 状态 | 草稿 |
| 素材 | 设16 |
| 最后修改 | 2026-11-22 |

## 1. 触发
- 系统设置 `prefers-reduced-motion: reduce`；或用户在设置 → 外观里打开"减少动效"（覆盖系统设置）。

## 2. 减少动效模式下
| 原动效 | 替代 |
|---|---|
| 进入 / 返回子图的缩放转场 | 透明度淡入 `--hx-t-2` |
| 适应画布、聚焦节点的视图过渡 | 直接跳到目标位置 |
| 面板、菜单、预览浮层的缩放进入 | 只做透明度 |
| 连线流动光点 | 关闭；活跃连线改为实线加粗（线宽 2.5） |
| 运行中旋转弧 | 改为静态的半圆弧图标 |
| 呼吸点、光环闪烁 | 关闭，保持静态颜色 |
| 分段控件滑块移动 | 直接切换 |

- **U.07.04-R1** 减少动效不能减少信息：每一种被关掉的动画都有静态替代，状态仍然看得出来。
- **U.07.04-R2** 实现方式：所有动画样式写在 `@media (prefers-reduced-motion: no-preference)` 里，或通过 `<html data-motion="reduce">` 关闭；JS 动画（视图过渡）读取同一个开关。

## 3. 验收标准
打开减少动效后，所有功能可用，截图里所有状态都能分辨（`U.20`）。
