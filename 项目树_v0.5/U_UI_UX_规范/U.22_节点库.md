## 1. 结构：分类树
节点库是一棵最多三层的分类树，每一项都是某个包贡献的节点预设（`C.15`）。内核只有 13 种原子节点，库里可以有成百上千项。

| 一级 | 二级（来源或用途） | 举例 |
|---|---|---|
| 智能体 | —、按角色 | Agent、提示词、上下文装配；主脑、决策者、执行者、验收者 |
| 模型 | 按连接（DeepSeek、Anthropic……） | DeepSeek V4 Pro |
| 工具 | 内置、MCP · <服务>、扩展包 · <包> | 检索、github.create_issue、读取表格 |
| 数据与状态 | — | 常量、列表、读取 / 写入 / 追加账本 |
| 流程控制 | —、聚合 | 扇出、汇合、分支、循环；投票、去重、排序取前 K |
| 人工 | — | 人工审批、人工输入、人工选择 |
| 子图 | —、端口、子图库 | 空子图；入口、出口；资料采集 v1.2 |

## 2. 规则
| 编号 | 规则 |
|---|---|
| U.22-R1 | 一级分类固定（上表），由核心包定义；二级由包的 `path[1]` 决定，来源是 MCP / 扩展包 / 连接时带一枚小来源标 |
| U.22-R2 | 顶部三个筛选：全部 / 收藏 / 最近（最近 10 个）；鼠标移到条目上出现 ★ 收藏 |
| U.22-R3 | 搜索匹配名称、说明、分类路径、来源、原子节点类型；有搜索词时平铺显示结果，每条下方显示分类路径 |
| U.22-R4 | 未启用包里的条目灰显并写原因（"扩展包未启用""等你确认"），点击跳到对应包详情 |
| U.22-R5 | 折叠状态、收藏、最近使用存 localStorage；默认展开"智能体""工具 › 内置" |
| U.22-R6 | 每个一级分类底部有入口：模型 › "连接更多模型…"；工具 › "接入 MCP 服务、安装扩展包…" |
| U.22-R7 | 拖入或点击添加：生成对应原子节点并套用预设参数和标签，记入"最近" |
| U.22-R8 | 底部三个入口：包管理、连接、资源库（`U.21`） |
| U.22-R9 | （待做）"能接到当前端口"筛选：从输出端口拖线到空白处时，节点库只显示有兼容输入的条目 |
| U.22-R10 | 条目超过 500 时按分类懒加载，搜索在后端做（`GET /node-presets?q=`） |
