## 1. 目的
设计令牌（`--hx-*`）是颜色、字号、间距、圆角、阴影、动效、层级的唯一来源。本文规定令牌放在哪、怎么新增、怎么改。

## 2. 规则
| 编号 | 规则 |
|---|---|
| U.02-R1 | 令牌源文件是仓库 `design/tokens.css` 和 `design/themes/*.css`（`U.03.05` §4），由设计规范 v0.3 的 `tokens.css` 迁入；`web/src/styles/tokens.css` 是生成的副本（`G.16`） |
| U.02-R2 | 令牌分两层：**基础令牌**（色值、尺寸，只在 tokens.css 里出现）和**语义令牌**（`--hx-bg-2`、`--hx-ok` 这种按用途命名的）。组件只能引用语义令牌 |
| U.02-R3 | 每个颜色令牌在每套内置主题的浅色和深色下都有值（`U.03.05-R2`）；缺值的主题不允许合并。与主题无关的令牌只在 `tokens.css` 的 `:root` 定义 |
| U.02-R4 | 令牌名一经发布不改名、不删除（`交接说明`）；要废弃时保留旧名指向新值，并在 tokens.css 注释里标注"已废弃，改用 xxx" |
| U.02-R5 | 新增令牌：先在本枝对应文档（色彩写进 `U.03`、尺寸写进 `U.05`……）登记用途，再加进 tokens.css；同一用途不能有两个令牌 |
| U.02-R6 | 新增颜色令牌必须验证对比度（`U.16`）：文字类 ≥ 4.5:1，次要文字和图形 ≥ 3:1，两个主题都要达标 |
| U.02-R7 | 不引入第三方 UI 框架的令牌体系（`G.02.05-R27`） |

## 3. 令牌类别
| 前缀 | 类别 | 定义在 |
|---|---|---|
| `--hx-bg-*`、`--hx-line-*`、`--hx-text-*`、`--hx-highlight` | 表面、线、文字 | `U.03.01` |
| `--hx-accent*`、`--hx-ok*`、`--hx-danger*`、`--hx-wait*`、`--hx-model*`、`--hx-focus` | 语义色 | `U.03.02` |
| `--hx-type-*` | 端口类型色 | `U.03.03` |
| `--hx-mark-c1…c6` | 节点和便签的标记色（新增） | `U.03.01` |
| `--hx-grid-dot`、`--hx-marquee*`、`--hx-scrim` | 画布专用 | `U.10.01` |
| `--hx-font-*`、`--hx-fs-*` | 字体、字号 | `U.04` |
| `--hx-s-*`、`--hx-node-*`、`--hx-port`、`--hx-ctl-h*`、`--hx-grid` | 间距、尺寸 | `U.05` |
| `--hx-r-*`、`--hx-shadow-*`、`--hx-z-*`、`--hx-blur-*` | 圆角、阴影、层级、材质（`z`、`blur` 为新增） | `U.06` |
| `--hx-t-*`、`--hx-ease*` | 动效 | `U.07.01` |
| `--hx-ls-w`、`--hx-rs-w`、`--hx-top-h`、`--hx-comp-*`（新增） | 布局尺寸 | `U.09.01` |

## 4. 检查方式
- `tools/gen tokens` 生成副本时检查：每个令牌两个主题都有值；对比度达标（用脚本计算）。
- Stylelint 禁止裸值（`G.06.03`）。
