## 1. 气质
**精密仪器面板，不是营销页。** 默认是白天的浅色工作台：白色面板浮在浅灰底上，信息靠层级和留白区分，颜色只用来表达含义。

## 2. 原则
| 编号 | 原则 | 落地方式 |
|---|---|---|
| U.01-R1 | **内容是主角，界面退后** | 面板浮在画布上方，不切割画布；工具栏、边框用最低对比度 |
| U.01-R2 | **颜色 = 含义** | 一个颜色只表达一种含义（`U.03.02`）；禁止装饰性用色 |
| U.01-R3 | **状态一眼可读** | 状态同时用颜色、图形、文字三种方式表达，不能只靠颜色 |
| U.01-R4 | **模型的行为永远可见** | 模型做的事带模型色标记和理由，可以撤销（`U.12`） |
| U.01-R5 | **直接操作优先** | 能在节点上直接改的不进属性页；能拖的不用点；常用操作都有快捷键 |
| U.01-R6 | **流畅是功能** | 拖拽、缩放、连线保持 60fps；任何操作 100ms 内有视觉反馈（`U.17`） |
| U.01-R7 | **渐进披露** | 缩小时节点只显示标题；悬停才出类型；选中才出完整参数 |
| U.01-R8 | **始终知道自己在哪** | 任何时候都能看出当前在哪一层、在看哪次运行、AI 有多少权限（`U.09`、`U.13.06`） |
| U.01-R9 | **给非专业用户讲人话** | 界面文案不用技术黑话；技术细节可以展开看，但默认不显示（`U.15`） |

## 3. 禁止
渐变色块、玻璃拟态（毛玻璃）、彩虹配色、emoji 图标、每个卡片都带悬停动画、每个区块都有入场动画、全大写的小标签、所有元素都套同一个圆角和阴影。

## 4. 检查方式
`U.20` 交付验收清单逐项检查；评审时对照本表。
