> 来自 demo v0.5.2–v0.5.3 的几轮打磨。对所有界面生效；与旧规范冲突时以本文为准。

## 1. 色彩比例
| 编号 | 规则 |
|---|---|
| U.23-R1 | 界面约 90% 是中性色（背景、文字、分隔）；主色只用于"运行中、主路径、唯一的主按钮、选中"；模型色只用于 AI 做的事；红、黄只在真的需要注意时出现（失败、急停、待审批） |
| U.23-R2 | 实心主色只用于顶部"运行"按钮、H 标识和输入框有字时的"发送"；其余按钮透明底、悬停才出现填充 |
| U.23-R3 | 节点按类别有一个克制的类别色，只用在图标底色（13% 浓度）和卡片左上角极淡的晕染（9%），不用在文字和边框 |

## 2. 层级与材质
| 编号 | 规则 |
|---|---|
| U.23-R4 | 层级：底（bg-0：顶部条 + 左栏一体，无分割线）→ 画布卡片（bg-1，圆角 14，极淡阴影）→ 节点卡片（bg-3，双层阴影 + 顶部 1px 高光）→ 卡片内凹槽（参数区，bg-1 与 bg-3 调和）→ 控件（在凹槽里凸起）。右栏与画布同级，是浮起的圆角卡片 |
| U.23-R5 | **控件不加边框**：按钮、输入框、下拉、标签、卡片、表格靠填充色和明暗分层；只有键盘焦点显示外环（主色 45%，2px） |
| U.23-R6 | 浮在画布上的面板（停靠栏、对话框、小地图、浮动回复、提示）用半透明 + 背景模糊（玻璃，blur 18px）。这是 `U.01` §3 禁止毛玻璃的唯一例外，其他位置仍不用（`P.09` K55） |
| U.23-R7 | 画布背景：点阵（11% 浓度）+ 两团极淡主题色光晕（缓慢漂移，48 秒周期）+ 细颗粒 + 四角暗角 + 跟随指针的柔光；"减少动效"时全部静止 |
| U.23-R8 | 子图节点后面垫两张更淡的卡片（叠层）；运行中节点主色外环 + 柔和外发光 |
| U.23-R9 | 缩小到 30%–55% 时文字变骨架条，不出现空白方块；低于 30% 只显示标题 |

## 3. 少文字
| 编号 | 规则 |
|---|---|
| U.23-R10 | 能用图标、颜色、位置表达的不写字；说明放悬停提示。顶部条：档位只剩刻度 + 数字；运行状态只在运行时出现；急停平时是灰色图标，运行中才显示红底"急停"；主题只剩三粒色点；通知只是圆点 |
| U.23-R11 | 根图时不显示面包屑和分支 |
| U.23-R12 | 不常驻显示提示语、快捷指令、"没有选中节点"之类的说明 |
| U.23-R13 | 空状态最多一句标题 + 一句说明 |

## 4. 墨鲸配色调整
填充主色由 `#4361f0` 调浅为 `#6b88ff`（深色 `#8ea2ff`）；主按钮 `#4866f8`（白字对比 4.63:1）；文字用 `#3d5ae8`（对 bg-1 5.22:1）。见 `U.03.05`。

## 5. 待改（见 `U.24`）
本文对应的 demo 仍有若干问题未修，登记在 `U.24`。

## 6. 纠偏（v0.5.5，用户反馈 v0.5.4"整体变丑、侧栏没了层次"）
| 编号 | 规则 |
|---|---|
| U.23-R14 | 去亮色不等于去颜色：不要把主色全部压成灰，否则界面失去焦点。运行按钮和 H 标识保持实心主色（v0.5.3 样式，用户确认）；新建会话的 + 用主色 |
| U.23-R15 | 侧栏分区必须一眼分得清：分区之间留白 + 一条 1px 细分隔线；分区标题 12px / 600 / `text-2`；当前会话和当前层是浮起的白卡片（`bg-2` + 柔和阴影），不能只靠淡灰底 |
| U.23-R16 | 去边框只针对控件；分区、分组之间的结构分隔要保留（用细线或留白），否则层级会消失 |
| U.23-R17 | 侧栏三级层级：① 分区标题 = 图标 + 13px / 600 / text-1，顶格；② 分组（置顶、最近、节点库大类）= 11px / text-3；③ 条目 = 13px / 400 / text-1。② ③ 缩进到分区标题文字下方，左侧一条 1px 引导线把分区内容挂在标题下；结构树每深一层再缩进 16px 并有自己的引导线 |
| U.23-R18 | 条目第二行（元信息）单行省略，不换行；去掉元信息前的图标 |
| U.23-R19 | "新建会话"是独立的操作行，不属于任何分区：上下留白，下方一条与分区相同的分隔线；左侧 + 放在主色浅底小方块里；快捷键只在悬停时显示 |
| U.23-R20 | 滚动条平时完全隐藏，鼠标移进可滚动区域才出现一根 6px 半透明细滑块；侧栏预留滚动条位置，出现时内容不跳 |
| U.23-R21 | 侧栏、图标栏、画布停靠栏的悬停高亮是一块"流动"的底：鼠标在按钮之间移动时，高亮从上一个平滑滑到下一个（位置和大小 0.32s 缓动），离开区域时淡出；不再每个按钮各自变灰变白 |
| U.23-R22 | "新建会话"居中、主色浅底（11%）+ 主色文字 + 极淡主色描边，比分区标题高一级，比顶部"运行"低一级 |
