## 1. 规则
| 编号 | 规则 |
|---|---|
| U.13.03-R1 | `Ctrl+Z` 撤销、`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做 |
| U.13.03-R2 | **撤销按操作者分开**：用户的 `Ctrl+Z` 只撤销用户自己最近的一组操作，不撤销模型的操作（`引08` §6） |
| U.13.03-R3 | 撤销模型的修改：点 AI 角标的"撤销"，或通知里的"撤销"，或操作历史里该条的"撤销"；这些是 `revert_op`，可以撤销任意一条，不只是最近的 |
| U.13.03-R4 | 一组操作（一次拖动、一次打包为子图、一次 GraphPatch）撤销时一起撤销（`C.05-R3`） |
| U.13.03-R5 | 撤销失败（例如节点已被删除）时，通知说明原因，不静默失败（`C.05.03-R4`） |
| U.13.03-R6 | 撤销、重做后，画布自动定位到被改动的位置：不在当前层时进入那一层；不在视口内时平移过去 |
| U.13.03-R7 | 撤销作用于整张图，不只是当前层：在子图里按 `Ctrl+Z` 也可能撤销上一层的操作，此时按 R6 定位 |

## 2. 操作历史（右侧栏 › 监控 › 操作历史，`U.09.07`）
- 每条显示：操作者（人 / AI，AI 用模型色）、时间、一句话描述（"添加了「验收复核」"）、理由（AI 必有）、所在层。
- 每条提供"撤销这一条"和"回到这里"（`revert_to`）。
- 撤销过的条目划线显示，可以"重做"。
