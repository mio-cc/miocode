## 1. 规则
| 操作 | 结果 |
|---|---|
| 单击节点 | 选中它（取消其他选中） |
| `Shift` 或 `Ctrl` + 单击 | 加选 / 减选 |
| 在空白处拖动（选择工具下） | 框选；框选和节点相交即选中 |
| `Shift` + 在空白处拖动 | 加选框选 |
| 单击空白 | 取消全部选中 |
| `Ctrl+A` | 选中当前层全部节点 |
| `Esc` | 取消选中（没有选中时：返回上一层） |
| 单击连线 | 选中连线 |
| `Tab` / `Shift+Tab`（画布有焦点时） | 在当前层的节点之间按从左到右、从上到下的顺序移动焦点并选中 |

- **U.13.01-R1** 选中只在当前层内；进入或返回子图时清空选中（返回时自动选中刚离开的容器节点，`U.07.02`）。
- **U.13.01-R2** 选中节点后：属性页内容更新（右栏收起时只在开关上显示小圆点，`U.09.02-R1`）；对话框显示"将附带选中 · 3 个节点"（`C.10` Selection）。
- **U.13.01-R3** 多选时属性页显示"已选 N 个"，列出共同参数（值不同时显示"多个值"），提供批量操作：打包为子图、删除、复制、对齐。
