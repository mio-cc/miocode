## 1. 全局
| 键 | 作用 | 备注 |
|---|---|---|
| `Ctrl+K` | 命令面板 | 输入框里也有效 |
| `Ctrl+,` | 打开中心窗口（`U.21`） | 输入框里也有效 |
| `Ctrl+Enter` | 运行当前图 | 对话框里是发送（见 §4） |
| `Ctrl+.` | 急停 | 任何地方都有效，包括输入框里 |
| `[` | 收起 / 展开左侧栏 | — |
| `]` | 打开 / 关闭右侧栏 | — |
| `I` | 打开右栏属性页 | — |
| `F` | 专注模式 | — |
| `/` | 聚焦节点库搜索 | — |
| `?` | 显示快捷键速查 | — |
| `Alt+[` / `Alt+]` | 切到上一个 / 下一个会话（`U.09.04`） | — |
| `Alt+N` | 新建会话 | — |

## 2. 画布
| 键 | 作用 |
|---|---|
| `V` | 选择工具 |
| `H` / 按住 `Space` | 平移 |
| `A` / 双击空白 | 快速添加节点 |
| `Delete` / `Backspace` | 删除选中 |
| `Ctrl+A` | 全选当前层 |
| `Ctrl+D` | 复制选中 |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴（跨层、跨图可用） |
| `Ctrl+G` | 打包为子图 |
| `Ctrl+Shift+G` | 解散子图 |
| `Ctrl+Z` / `Ctrl+Shift+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `1` | 适应画布 |
| `2` | 聚焦选中 |
| `L` | 整理布局 |
| `F2` | 重命名选中节点 |
| 方向键 / `Shift` + 方向键 | 移动选中 1 / 5 格 |
| `Alt` + 拖动 | 关闭吸附 |
| `Tab` / `Shift+Tab` | 节点之间移动焦点 |

## 3. 嵌套导航
| 键 | 作用 |
|---|---|
| `P` | 预览选中的子图节点 |
| `Enter` / 双击子图节点 | 进入子图（预览打开时：进入预览中的子图） |
| `Esc` | 按顺序：关闭弹层 / 预览 → 取消选中 → 返回上一层 |
| `Alt+↑` | 返回上一层（和 Esc 不同：不会先取消选中） |
| 浏览器后退 | 返回上一层（`G.06.02-R8`） |

## 4. 对话框
| 键 | 作用 |
|---|---|
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |
| `↑`（输入框为空时） | 编辑上一条消息 |
| `Esc` | 失去焦点，回到画布 |

## 5. 规则
- **U.13.04-R1** 单字母快捷键在输入框、文本域、可编辑元素里不生效（急停、命令面板除外）。
- **U.13.04-R2** 不占用浏览器和系统的保留快捷键（`Ctrl+W`、`Ctrl+T`、`Ctrl+N`、`Ctrl+L`、`Ctrl+R`、`Ctrl+Shift+[` / `]`、`F5`、`F11`、`F12`）。
- **U.13.04-R3** 快捷键由统一的注册中心管理（`W.02.04`），注册时检查冲突；本表就是注册中心的数据来源（`schema/builtin/shortcuts.yaml`）。
- **U.13.04-R5** 本表的 `Ctrl` 在 macOS 上对应 ⌘；注册中心里写作 `Mod`，显示时按平台换成 `Ctrl` 或 `⌘`（`W.02.04`）。
- **U.13.04-R6** 输入法正在组字（中文、日文输入）时，任何快捷键都不响应，`Enter` 也不发送。
- **U.13.04-R4** 相对设计规范 v0.3 的变化：`Tab` 不再切换面板显示；`F` 从"全屏"改为"专注模式"（收起两侧栏）；新增 `[`、`]`、`I`、`P`、`Alt+↑`、`?`、`Ctrl+C/V`、`Alt+[`、`Alt+]`、`Alt+N`。
