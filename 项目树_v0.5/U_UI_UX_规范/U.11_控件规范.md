# U.11 控件规范

| 项 | 内容 |
|---|---|
| 编号 | U.11 |
| 类型 | 规范 |
| 上级 | U UI/UX 规范 |
| 下级 | 无 |
| 状态 | 草稿 |
| 素材 | 设10 |
| 最后修改 | 2026-11-23 |

## 1. 共同规则
- 控件高 `--hx-ctl-h`（节点内 `--hx-ctl-h-sm`），底色 `bg-4`，外框透明；悬停外框 `line-3`；聚焦外框 `text-2` 再加 3px 同色 15% 光晕。
- 禁用：透明度 0.5，鼠标为 `not-allowed`，提示框说明为什么不能用。
- 锁定（参数 `def` / `kernel` 锁）：控件只读，右侧显示锁图标，悬停说明"由节点类型定义"或"由内核规则 INV-07 固定"。

## 2. 控件
| 控件 | 规格 | 交互 |
|---|---|---|
| 按钮 | 主按钮：`primary` 底、`primary-fg` 字（`U.03.05-R5`；全界面只有运行、H 标识、发送三处实心，`U.23-R2`）；次按钮：`bg-4` 底；幽灵按钮：透明；危险按钮：`danger-weak` 底、`danger` 字；模型按钮（采纳）：`model-weak` 底、`model` 字 | 按下 `scale(.97)`；加载时文字换成旋转弧，按钮宽度不变 |
| 图标按钮 | 28×28（小号 24×24），`r-md` | 悬停 `bg-4`；提示框带快捷键 |
| 数字步进 | `[ − 数值 + ]`，数值 mono | 数值上左右拖动连续调整（`Shift` 加速 ×10）；滚轮调整；双击输入；拖动期间合并为一条 Op（`C.05.04` §4） |
| 滑块 | 轨道 4px `bg-5`；已填充 `text-2`；拇指 12px | 拖动时上方浮出数值；拖动合并为一条 Op |
| 下拉 | 右侧 ▾；弹层 `bg-2` + `shadow-pop` | 可以输入过滤；键盘上下选择、Enter 确认 |
| 分段 | 2–5 段，选中段 `bg-5`（浅色主题 `bg-2` + 阴影） | 选中背景在段之间滑动（`--hx-t-2`） |
| 开关 | 28×16 | 打开时轨道 `accent` |
| 单行输入 | — | Enter 提交，Esc 取消 |
| 多行输入 / 代码框 | mono，行号 `text-3`；YAML / 表达式高亮：键名 `text-2`、字符串 `type-list` 色、数字 `type-ctx` 色 | 表达式（`expr` 参数）实时校验，错误在下方一行显示 |
| 选择器 picker | 搜索框 + 结果列表 + 预览 | 用于模型、配方、角色卡、工具、类型引用 |
| 标签、徽标 | 高 18，`r-xs`，mono 10.5 | 状态徽标"弱色底 + 实色字" |
| 参数接线 | 每个参数在节点左侧都有同名输入端口（`U.10.07` §2） | 接线后控件变为"由上游「X」提供"（斜纹底、只读）；断开后恢复原值（`C.03.05`、`P.09` K42；原"参数转端口"控件取消） |
| 提示框 | `bg-2`、`shadow-pop`，延迟 400ms | 内容 + 快捷键 |
| 菜单、右键菜单 | 宽 220，项高 28，分组标题、快捷键、子菜单 | 键盘可以完整操作（`U.13.05`） |
| 命令面板 | `Ctrl+K`，宽 560，居中偏上 | `U.13.05` |
| 通知 | 右上角堆叠，宽 320，最多 4 条，4 秒后消失（错误类不自动消失） | 可以带"撤销"按钮 |
| 确认框 | 宽 400，居中，模态 | 只用于不可撤销的操作（删除会话、删除分支、清空数据、解除急停）；危险按钮在右 |

## 3. 规则
- **U.11-R1** 能撤销的操作不弹确认框，改为"做了再提供撤销"（通知里的撤销按钮）。
- **U.11-R2** 控件的生成规则（哪种参数用哪种控件）见 `C.03.02` §4，界面不为单个节点类型定制控件。
