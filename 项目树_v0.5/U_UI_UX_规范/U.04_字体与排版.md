## 1. 字体
| 令牌 | 字体栈 | 用途 |
|---|---|---|
| `--hx-font-ui` | Geist → Noto Sans SC → 系统界面字体（微软雅黑、PingFang SC） | 界面文字 |
| `--hx-font-mono` | Geist Mono → 系统等宽字体 | 数值、类型名、运行路径、快捷键、YAML、代码 |

## 2. 自托管（替代设计规范 v0.3 的在线字体，`P.09` K12）
- **U.04-R1** 字体文件放在 `web/public/fonts/`，随程序打包，完全离线可用；不从任何在线字体服务加载。
- **U.04-R2** 格式只用 WOFF2。Geist、Geist Mono 用拉丁子集；Noto Sans SC 按常用 3500 字 + 界面文案用到的字做子集（由 `tools/gen fonts` 扫描 `messages/*.yaml` 和 `i18n` 文案自动补充）。
- **U.04-R3** `@font-face` 用 `font-display: swap`；首屏预加载 `Geist 400` 和 `Noto Sans SC 400` 两个文件。
- **U.04-R4** 子集里没有的生僻字回退到系统字体，不报错。

## 3. 字号与字重
- **U.04-R5** 字号只允许 8 档：`--hx-fs-10`（10.5）、`11`、`12`、`13`、`14`、`16`、`20`、`28`。界面基准是 13。
- **U.04-R6** 字重只用 400、500、600。
- **U.04-R7** 数字一律 `font-variant-numeric: tabular-nums`（等宽数字，跳动的数值不晃）。

| 场景 | 字号 | 字重 | 字体 |
|---|---|---|---|
| 正文、面板内容、消息 | 13 | 400 | ui |
| 节点标题 | 14 | 600 | ui |
| 节点类型行、端口类型标签 | 10.5 | 400 | mono |
| 端口名、控件标签 | 12 | 400 | ui |
| 面板标题 | 13 | 600 | ui |
| 顶部条会话名 | 14 | 600 | ui |
| 辅助说明、时间、计数 | 11 | 400 | ui / mono |
| 首次引导大标题 | 28 | 600 | ui |
| 空状态标题 | 20 | 600 | ui |

## 4. 排版
- 行高：正文 1.55，紧凑列表 1.3，标题 1.25。
- 中英文混排不手动加空格，由字体处理；数字和单位之间不加空格（`12s`、`3 份` 例外：中文量词前加空格）。
- 长文本截断用省略号，悬停显示全文（提示框）。

### 实施卡
- 要建的文件：`design/fonts/`（原始字体）、`tools/gen/fonts/`（子集化）、`web/src/styles/base.css` 里的 `@font-face`。
- 测试用例：`U04-T1`（断网时界面字体正常，Playwright 离线模式截图比对）。
