## 1. 用法
每个界面相关的任务合并前，实施者逐项自检并在 PR 里附检查结果；里程碑结束时设计方对全部界面再走一遍。

## 2. 清单
### 视觉
- [ ] 没有裸色值、裸尺寸、裸时长；全部来自令牌（Stylelint 通过）
- [ ] 浅色、深色两种主题都截图检查过，没有看不清的元素
- [ ] 颜色含义符合 `U.03.02`：橙只表示运行中和主操作，蓝紫只表示 AI
- [ ] 所有状态同时有颜色、图形、文字
- [ ] 符合 `U.01` §3 的禁止清单（没有渐变、emoji、全大写标签；毛玻璃只出现在 `U.23-R6` 列出的画布浮动面板上）

### 布局
- [ ] 在 1440、1180、1100、900、760 宽度下截图，没有重叠和截断（`U.09.03`）
- [ ] 浮动元素互不遮挡；"适应画布"避开了停靠栏、对话框、父图位置卡
- [ ] 侧栏收展时画布不跳动

### 交互
- [ ] `U.13.04` 中与本功能相关的快捷键全部可用、无冲突
- [ ] 所有修改都能撤销；AI 的修改有角标、理由、撤销入口
- [ ] 嵌套导航：预览、进入、返回、直达、刷新后停留同层（涉及时）
- [ ] 不可撤销的操作有确认框，能撤销的没有

### 状态
- [ ] 加载、空、错误、离线状态都有设计并已实现
- [ ] 错误文案说清发生了什么、怎么办；没有技术黑话

### 可访问性
- [ ] 键盘能完成全部操作；焦点可见；弹层关闭后焦点回位
- [ ] 打开"减少动效"后，动画关闭、信息不丢失
- [ ] 对比度脚本通过

### 性能
- [ ] 200 节点下拖动、缩放 60fps（DevTools Performance 截图）
- [ ] 平移、拖动时 React 提交次数为 0

### 文案
- [ ] 只用 `P.06` 的标准名和界面名
- [ ] 文案全部来自 `i18n`，组件里没有中文字面量

## 补充（demo v0.5.4–v0.5.11 的教训）
| # | 检查项 |
|---|---|
| 1 | 在真实浏览器（Chrome / Edge）里打开，控制台无报错，10 秒内完成渲染；不能只依赖 Node 假 DOM 冒烟测试 |
| 2 | 所有 MutationObserver / ResizeObserver 回调：修改被观察对象前先判断值确实不同，并有重入保护（`G.02.05`） |
| 3 | 画布上的单击、双击、悬停判断用指针坐标取真实元素，不用 `event.target`（画布有指针捕获，`U.13.06-R7`） |
| 4 | demo 单文件产物 ≤ 600KB（Quick 预览上限），`build.py` 默认压缩 |
| 5 | 一处视觉调整后，回看整体：是否把所有颜色压成了灰、是否去掉了结构分隔（`U.23-R14`–`R16`） |
| 6 | 用户已确认的样式（例如运行按钮和 H 标识的实心主色）登记在 `U.23`，后续修改不得改回 |
