# U.16 可访问性

| 项 | 内容 |
|---|---|
| 编号 | U.16 |
| 类型 | 规范 |
| 上级 | U UI/UX 规范 |
| 下级 | 无 |
| 状态 | 草稿 |
| 素材 | 设16 |
| 最后修改 | 2026-11-22 |

## 1. 目标
达到 WCAG 2.2 AA 级别（画布的部分交互除外，见 §4）。

## 2. 规则
| 编号 | 规则 |
|---|---|
| U.16-R1 | 对比度：正文 ≥ 4.5:1；大号文字、次要文字、图标、控件边界 ≥ 3:1；两个主题都要达标（`U.02-R6`） |
| U.16-R2 | 状态不能只靠颜色：每种状态都同时有图形和文字（`U.01-R3`） |
| U.16-R3 | 所有可点击元素都能用键盘聚焦和操作；用 `<button>`、`<a>`、表单元素，不用 `div` 加点击事件（`G.06.01-R6`） |
| U.16-R4 | 焦点环使用 `--hx-focus`，只在键盘操作时显示（`:focus-visible`）；不允许 `outline: none` 而没有替代 |
| U.16-R5 | 图标按钮有 `aria-label`；状态变化（运行完成、审批到来、急停）通过 `aria-live="polite"` 区域播报，急停用 `assertive` |
| U.16-R6 | 弹层、菜单、命令面板、预览浮层：打开时焦点移入，`Esc` 关闭后焦点回到触发它的元素；模态弹层内焦点循环 |
| U.16-R7 | 支持系统的"减少动效"（`U.07.04`） |
| U.16-R8 | 界面在浏览器缩放 200% 时可用（按 `U.09.03` 断点降级） |
| U.16-R9 | 最小点击区域 24×24（`U.05-R5`） |

## 3. 画布的键盘操作
| 键 | 作用 |
|---|---|
| `Tab` / `Shift+Tab` | 在当前层节点之间移动焦点（从左到右、从上到下） |
| 方向键 | 移动选中节点 |
| `Enter` | 进入子图；非容器节点：打开属性页并聚焦第一个参数 |
| `C`（节点有焦点时） | 进入连线模式：方向键在本节点的输出端口间切换，`Enter` 后再用 `Tab` 选择目标节点和输入端口，`Enter` 完成连线，`Esc` 取消 |
| `Shift+F10` / 菜单键 | 打开当前焦点元素的右键菜单 |

读屏：每个节点的可访问名称为"{类型} {名称}，{状态}，{N} 个输入、{M} 个输出"；连线为"{源} 的 {端口} 连到 {目标} 的 {端口}"。

## 4. 已知限制
画布的自由拖拽布局本身无法完全满足读屏用户；提供替代：右栏属性页列出当前层所有节点和连线（"列表视图"开关），可以在列表里完成增删改连。
