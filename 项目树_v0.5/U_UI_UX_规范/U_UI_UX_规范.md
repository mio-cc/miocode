## 1. 这一枝管什么
界面长什么样、怎么交互：设计原则、设计令牌、色彩、字体、间距、动效、图标、应用布局、画布视觉、控件、模型操作者界面、交互模式、状态反馈、文案、可访问性、性能体验、首次使用、用户流程、验收清单。

**前端实现（`W`）必须照本枝做。** 本枝说"是什么样"，`W` 说"怎么写代码做出来"。

## 4. 整枝共同约束
- **U-R1** 设计令牌是视觉数值的唯一来源（INV-20）。本枝文档只写令牌名，不写裸值；需要新数值时走 `U.02` 新增令牌。
- **U-R2** 默认浅色主题，深色可选。所有规范都要在两种主题下成立。
- **U-R3** 规范和 demo 不一致时以规范为准，并修改 demo（`R.03`）。
- **U-R4** 界面用词只能用 `P.06` 术语表的标准名或界面名（`U.15`）。
- **U-R5** 画布交互和 Figma、ComfyUI 的用户习惯保持一致，不发明新手势。

## 5. 素材与改动
主要素材是 `设计规范_v0.3`（DESIGN.md、docs/00–19、tokens.css）和 `布局demo_v0.4`。相对设计规范 v0.3 的主要改动：
| 改动 | 原因 | 在哪 |
|---|---|---|
| 应用布局改为画布居中 + 底部对话框 + 左右侧栏，取消"画布以卡片嵌在对话里"和底部运行抽屉 | ADR-008 | `U.09` |
| 新增嵌套导航：预览、进入转场、结构树、父图位置卡 | ADR-009 | `U.07.02`、`U.10.04`、`U.13.06` |
| 字体改为自托管 | `P.09` K12 | `U.04` |
| 新增 z-index 层级令牌、标记色令牌 | 原来缺失 | `U.06`、`U.03.01` |
| 端口类别"泛型 T"界面名改为"数据" | 非专业用户看不懂 | `C.04.01`、`U.03.03` |
| 快捷键按新布局调整（`[` `]` `I` `P`），`Tab` 改为与专注模式统一 | 新布局 | `U.13.04` |
