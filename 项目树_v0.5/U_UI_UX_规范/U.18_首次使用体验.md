# U.18 首次使用体验

| 项 | 内容 |
|---|---|
| 编号 | U.18 |
| 类型 | 规范 |
| 上级 | U UI/UX 规范 |
| 下级 | 无 |
| 状态 | 草稿 |
| 素材 | 新 |
| 最后修改 | 2026-11-23 |

## 1. 目标
**新用户第一次打开后 10 分钟内，用模板跑通一次"闭环迭代"，并看懂每一步发生了什么**（`P.01` 成功标准 1）。

## 2. 流程
```
启动 anydoor → 浏览器自动打开 → 引导第 1 步 → 第 2 步 → 第 3 步 → 进入会话，画布上是模板图 → 引导气泡带用户点一次运行
```
| 步骤 | 内容 | 可以跳过吗 |
|---|---|---|
| 1 欢迎 | 一句话介绍 Anywhere Door；选择主题（浅色 / 深色 / 跟随系统） | 可以 |
| 2 连接模型 | 选择提供方（OpenAI 兼容 / Anthropic / Gemini），填地址和密钥，"测试连接"；说明"密钥只保存在你的电脑上" | 可以：跳过后进入**演示模式**（fake 模型，所有输出是示例数据，顶部条显示"演示模式"） |
| 3 选一个起点 | 3 个模板卡片（闭环迭代、生成-评审、代码评审），每个一句话说明和预计花费；或"从空白开始" | 不可以（但可以选空白） |
| 4 模板填空 | 模板的 `inputs`（`C.13.04`），如"你想调研什么？"，有默认值 | 可以（用默认值） |
| 5 画布导览 | 最多 4 个引导气泡：①这是画布，每个方块是一个节点 ②这个循环里面还有一层，双击进去看看 ③在这里用文字告诉 AI 怎么改 ④点这里运行 | 每个引导气泡都可以"跳过导览" |

## 3. 规则
- **U.18-R1** 引导只在第一次启动时出现；之后在设置 → 帮助里可以"重新查看导览"。
- **U.18-R2** 引导页不是模态弹窗，而是占满画布区域的页面，顶部条和侧栏可见但不可用（让用户先熟悉整体布局）。
- **U.18-R3** 引导气泡 `bg-2`、`shadow-pop`，指向具体元素，不遮挡被指向的元素；不使用全屏遮罩。
- **U.18-R4** 第一次运行完成后，对话里 AI 给一段简短总结："这次运行用了 31 秒、约 5 万 tokens。闭环迭代在第 2 轮通过了验收。你可以点任意节点看它的输入和输出。"
- **U.18-R5** 演示模式下运行必须能完整跑通模板（`--fake-llm` 的录放数据随模板发布，`C.13.04` fixtures）。

## 4. 验收标准
5 位没用过的用户（画像 A）测试，至少 4 位在 10 分钟内完成首次运行，并能说出"循环为什么跑了两轮"。
