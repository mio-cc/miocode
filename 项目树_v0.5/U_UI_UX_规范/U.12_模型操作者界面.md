## 1. 目的
让用户任何时候都知道"AI 做了什么、正在做什么、能做多少"（INV-24、`U.01-R4`）。

## 2. 标记
| 对象 | 呈现 |
|---|---|
| 模型改过的节点、连线 | 节点头部右上角 16px 高的"AI"角标（`model-weak` 底、`model` 字）；悬停显示：理由、时间、所用档位、"撤销"按钮 |
| 模型改过的参数 | 属性页里该参数行左侧模型色竖线；悬停同上 |
| 操作历史 | 模型的条目用 `model` 色图标和"AI"字样；人的条目用中性色 |
| 对话框 | 右下角显示编排者模型标签（`model-weak` 底），例如"AI · large-model" |

- **U.12-R1** AI 角标在节点被人再次修改后消失（`origin.actor` 变为 user）。

## 3. 提议（档位 1，或需要审核时）
| 元素 | 呈现 |
|---|---|
| 幽灵节点 | 主体透明度 0.72；外框 1.5px `model-line` 虚线；头部下方提议条："模型提议 · 理由一句话 · [采纳] [拒绝]" |
| 幽灵连线 | `model` 色虚线 |
| 被提议删除的元素 | 红色虚线外框，标题加删除线 |
| 被提议修改的参数 | 值前显示划线的旧值和"→"，新值为 `model` 色 |
| 提议栏 | 对话框上方："模型提议 N 处修改 · [逐条查看] [全部采纳] [全部拒绝]"；"逐条查看"依次聚焦每处修改（左右箭头切换） |
| 对话里 | 同时出现提议卡片（`C.10` proposal 块） |
| 过期 | 提议栏显示"已过期：图在提议后被修改了 · [让 AI 重新生成]"，幽灵元素消失 |

- **U.12-R2** 提议涉及其他层（子图里）的修改时，提议栏写明"另有 2 处在「闭环迭代」里"，点击进入那一层。结构树里有待处理提议的层显示模型色小点。

## 4. 直接修改（档位 2 及以上）
- 改动立即生效；节点闪一下 `model` 光环 600ms 并带 AI 角标；通知里提供"撤销"。
- 一次 GraphPatch 修改多处时，通知写"AI 修改了 5 处 · [查看] [全部撤销]"。

## 5. 正在工作
- 顶部条模型胶囊左侧出现模型色呼吸点，文字"AI 正在编辑…"；对话框上方状态行显示当前步骤（"正在读取图"、"正在添加节点"）。
- 画布上显示模型光标：带"AI"角标的小指针，移动到它正在操作的节点（图协同流 `model.activity` 的 `target`；当前运行里的编排者另有运行流 `orch.tool_call`，`P.09` K79）。
- 用户正在编辑的节点，模型会回避（`C.05.04` §5）；用户能看到"AI 等你改完这个节点"提示。

## 6. 档位胶囊
- 顶部条右侧，5 格刻度条；当前档位以内的格子实色填充；0–2 档中性色，3 档 `wait` 色，4 档 `accent` 色。
- 文字：`0 只读`、`1 建议`、`2 部分`、`3 高度`、`4 完全`。
- 点击展开授权面板：每档一句话说明（"1 建议：AI 只能提议，由你决定是否采纳"）、当前生效的授权书名称和挂载位置、"在这一层单独设置"入口。
- 当前层和上一层档位不同时，胶囊旁显示"本层"字样。
