## 1. 间距
- **U.05-R1** 间距用 `--hx-s-1`（2）到 `--hx-s-10`（48），基本是 4 的倍数（`s-1` 2px、`s-3` 6px 用于紧凑场合）。
- **U.05-R2** 浮动面板距画布边缘 12px（`--hx-s-5`）；面板之间至少 12px。

| 场景 | 间距 |
|---|---|
| 图标和文字之间 | `s-3` |
| 控件之间（同一行） | `s-3` |
| 面板内边距 | `s-5` |
| 面板分区之间 | `s-6` |
| 列表项高 | 28（紧凑）/ 32（节点库） |

## 2. 尺寸
| 令牌 | 值（说明用） | 用途 |
|---|---|---|
| `--hx-node-w` / `--hx-node-w-sm` | 236 / 184 | 标准节点 / 紧凑节点宽度（资源、分支、人工、子图端口、账本、汇合为紧凑） |
| `--hx-node-head` | 38 | 节点头部高 |
| `--hx-node-row` | 24 | 端口行高 |
| `--hx-node-widget` | 28 | 内联控件行高 |
| `--hx-port` | 10 | 端口圆点直径 |
| `--hx-ctl-h` / `--hx-ctl-h-sm` | 28 / 24 | 控件高度 / 节点内控件高度 |
| `--hx-grid` | 20 | 画布网格和吸附步长 |

- **U.05-R3** 节点高度由布局常数计算（头部 + 端口行 × 行数 + 控件行 × 行数 + 子图缩略图 + 状态脚），前后端（自动布局）和画布引擎用同一套常数：唯一来源是 `schema/builtin/layout.yaml`，生成到 Go 和 TS 两边，公式和测试向量见 `W.06.10`（`P.09` K102）。
- **U.05-R4** 节点坐标吸附到 `--hx-grid`；按住 `Alt` 临时关闭吸附。
- **U.05-R5** 最小可点击区域 24×24；端口热区 18×18（`U.10.03`）。
- **U.05-R6** 没有给坐标的新节点（模型用图操作工具添加，`E.17.02`）由服务端按同一套常数放置：有上游连线时放在上游节点右侧（上游右边缘最大值 + 72），`y` 与第一个上游对齐；没有上游时放在当前层所有节点包围盒的右侧、顶边对齐；吸附到 `--hx-grid`；与已有节点重叠时每次向下移 1 格，最多 50 次（`layout.yaml` 的 `place`，`P.09` K102）。

## 3. 布局尺寸
应用布局的尺寸令牌（`--hx-top-h`、`--hx-ls-w` 等）定义在 `U.09.01`。
