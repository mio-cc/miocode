# U.05 间距、尺寸与栅格

| 项 | 内容 |
|---|---|
| 编号 | U.05 |
| 类型 | 规范 |
| 上级 | U UI/UX 规范 |
| 下级 | 无 |
| 状态 | 草稿 |
| 素材 | 设04 |
| 最后修改 | 2026-11-22 |

## 1. 间距
- **U.05-R1** 间距用 `--hx-s-1`（2）到 `--hx-s-10`（48），基本是 4 的倍数（`s-1` 2px、`s-3` 6px 用于紧凑场合）。
- **U.05-R2** 浮动面板距画布边缘 12px（`--hx-s-5`）；面板之间至少 12px。

| 场景 | 间距 |
|---|---|
| 图标和文字之间 | `s-3` |
| 控件之间（同一行） | `s-3` |
| 面板内边距 | `s-5` |
| 面板分区之间 | `s-6` |
| 列表项高 | 28（紧凑）/ 32（节点库） |

## 2. 尺寸
| 令牌 | 值（说明用） | 用途 |
|---|---|---|
| `--hx-node-w` / `--hx-node-w-sm` | 236 / 184 | 标准节点 / 紧凑节点宽度（资源、分支、人工、子图端口、账本、汇合为紧凑） |
| `--hx-node-head` | 38 | 节点头部高 |
| `--hx-node-row` | 24 | 端口行高 |
| `--hx-node-widget` | 28 | 内联控件行高 |
| `--hx-port` | 10 | 端口圆点直径 |
| `--hx-ctl-h` / `--hx-ctl-h-sm` | 28 / 24 | 控件高度 / 节点内控件高度 |
| `--hx-grid` | 20 | 画布网格和吸附步长 |

- **U.05-R3** 节点高度由布局常数计算（头部 + 端口行 × 行数 + 控件行 × 行数 + 子图缩略图 + 状态脚），前后端（自动布局）和画布引擎用同一套常数（`W.06.10`）。
- **U.05-R4** 节点坐标吸附到 `--hx-grid`；按住 `Alt` 临时关闭吸附。
- **U.05-R5** 最小可点击区域 24×24；端口热区 18×18（`U.10.03`）。

## 3. 布局尺寸
应用布局的尺寸令牌（`--hx-top-h`、`--hx-ls-w` 等）定义在 `U.09.01`。
