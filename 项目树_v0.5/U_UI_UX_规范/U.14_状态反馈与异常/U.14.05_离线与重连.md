## 1. 场景
`anydoor` 是本机服务，"离线"指浏览器和服务之间的连接断开（服务被关闭、崩溃重启、电脑休眠唤醒）。模型厂商连不上不属于这里（按节点失败处理，`U.14.03`）。

## 2. 规则
| 状态 | 呈现 |
|---|---|
| 连接中断 < 3 秒 | 不提示（SSE 自动重连） |
| 中断 ≥ 3 秒 | 顶部条下方黄色横幅"与 Anywhere Door 的连接已断开，正在重连…"；画布变为只读（拖动、编辑被禁用，提示"重连后可编辑"） |
| 重连成功 | 横幅变绿"已重新连接"，2 秒后消失；自动补齐断开期间的事件和图版本（`B.05.02`、`W.04.05`）；未提交的本地修改重新提交 |
| 服务已关闭（重连 30 秒仍失败） | 横幅"Anywhere Door 已关闭。请重新启动 Anywhere Door，然后刷新这个页面" + "刷新" |
| 服务重启后 token 变化 | 自动跳转到重新登录流程（打开启动时的地址即可，`B.03.05`） |

- **U.14.05-R1** 断开期间的本地修改（乐观更新的 Op）保留在本地队列，重连后按顺序提交；冲突时按 `U.14.03` §2 处理。
- **U.14.05-R2** 运行不受浏览器断开影响（运行在服务端），重连后显示最新进度。
