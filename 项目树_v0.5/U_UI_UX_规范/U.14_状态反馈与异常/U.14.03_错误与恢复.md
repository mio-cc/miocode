## 1. 错误分级
| 级别 | 例子 | 呈现 |
|---|---|---|
| 字段级 | 参数值不合法、表达式语法错误 | 控件下方一行红字，控件底色 `danger-weak`（不画外框，`U.23-R5`，`P.09` K127） |
| 节点级 | 节点执行失败、校验错误（V 码） | 节点外框和状态；校验错误在节点头部显示红色小点，悬停看诊断文案 |
| 图级 | 运行前校验不通过 | 运行按钮旁显示"3 个问题"徽标，点开列出所有诊断，点一条进入对应层并选中节点 |
| 操作级 | Op 被拒绝、冲突、撤销失败 | 通知（不自动消失的错误类通知）；冲突按 §2 |
| 全局 | 服务断开、急停 | 顶部横幅（`U.14.04`、`U.14.05`） |

## 2. 常见错误的处理
| 错误 | 呈现与恢复 |
|---|---|
| 版本冲突 409 | 自动合并能成功：通知"已和最新版本合并"；不能：弹出对比"别人（或 AI）已改为 X · [保留我的] [用对方的]" |
| 授权拒绝 403 | AI 的操作被拒：对话里说明"这个操作需要更高档位"，附"调整档位"按钮；不弹通知 |
| 节点锁定 | 通知"「xxx」已锁定"并提供"解锁" |
| 急停中 423 | 不单独报错，顶部急停横幅已经说明 |
| 模型调用失败 | 节点失败，状态脚显示"模型返回错误：限流，2 秒后重试（第 1 / 2 次）"；最终失败时显示"重试"和"换一个模型" |
| 内部错误 500 | 通知"程序出了问题，已记录" + "复制错误详情"（`G.13-R4`） |

- **U.14.03-R1** 错误文案按 `G.13-R2`：说清发生了什么、怎么办。
- **U.14.03-R2** 能撤销的失败操作不需要用户确认，直接回滚并告知。
