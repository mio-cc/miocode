## 1. 端口
- 圆点直径 `--hx-port`，填充为类型色（`U.03.03`），外加 2px `bg-3` 描边形成细缝；圆心正好在节点左右边框上。
- 端口名 12 号、`text-2`；悬停时旁边浮出数据类型标签（mono 10.5，类型色），多连端口加"· 多连"。
- 热区：圆点周围 18×18。
- 必填但未连接的输入端口：圆点改为空心（只描边），校验报 V08 时端口名标红。

## 2. 连线形状
- 三次贝塞尔，两端切线水平；控制点偏移 = `clamp(|dx| × 0.5, 48, 180)`；终点在起点左侧（回连）时偏移固定 120。
- 线宽 1.75；悬停 2.5；选中 2.5 并加一层 6px 宽、透明度 0.18 的同色光晕。
- 颜色 = 源端口类型色，透明度 0.75；上游完成后变为 1。
- 未激活的连线（分支没走这条）在运行中和运行后显示为虚线、透明度 0.35。
- 每条线另有一条 14px 宽的透明路径作为点击热区。

## 3. 连线交互（与 ComfyUI、Figma 一致）
| 操作 | 结果 |
|---|---|
| 从输出端口按下拖动 | 拉出预览线跟随光标；兼容的输入端口放大发亮，不兼容的变暗 |
| 拖到兼容端口 18px 内 | 端点吸附，端口出现光环 |
| 在端口上松开 | 建立连线；目标不支持多连时替换旧线，并提示"已替换原来的连线" |
| 在空白处松开 | 打开快速添加面板，只列出能接这种类型的节点；选中后自动创建并连好 |
| 从已连接的输入端口拖出 | 拔下这条线，可以接到别处；拖到空白处松开即删除 |
| 悬停连线 | 线变粗，中点出现"+"（插入节点）和"×"（删除） |
| `Alt` + 点击端口 | 断开这个端口上的所有连线 |
| 类型不兼容 | 预览线变为红色虚线，旁边显示原因（`C.04.02` 的提示文案） |
| 连出非法的环 | 拒绝，提示"环只能通过循环节点形成" |
| 自动展开（C7） | 吸附时端口旁显示"逐项执行"小标签，让用户知道下游会执行多次 |
