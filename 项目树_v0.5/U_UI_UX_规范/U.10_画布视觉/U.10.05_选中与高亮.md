# U.10.05 选中与高亮

| 项 | 内容 |
|---|---|
| 编号 | U.10.05 |
| 类型 | 规范 |
| 上级 | U.10 画布视觉 |
| 下级 | 无 |
| 状态 | 草稿 |
| 素材 | 设08 |
| 最后修改 | 2026-11-22 |

## 1. 规则
| 对象 | 选中样式 | 其他 |
|---|---|---|
| 节点 | 外侧 2px 处画 1.5px 的 `--hx-focus` 环（outline + outline-offset），不改变节点尺寸 | 多选时每个都有环 |
| 连线 | 线宽 2.5 + 6px 同色光晕（`U.10.03`） | — |
| 便签 | 同节点 | — |
| 键盘焦点 | 同选中样式，但只在键盘操作时显示（`:focus-visible`） | — |

## 2. 高亮
| 场景 | 样式 | 时长 |
|---|---|---|
| 返回上一层后，刚离开的容器节点 | `--hx-focus` 外环闪烁一次 | 600ms |
| 对话里点"看这里"卡片（`C.10` focus 块） | 画布进入对应层，目标节点 `--hx-focus` 外环闪烁两次，其余节点透明度降到 0.5，2 秒后恢复 | 2s |
| 模型直接修改节点 | `--hx-model` 光环 | 600ms |
| 结构树"在结构树中定位" | 结构树对应行 1.5px `--hx-focus` 外框 | 900ms |
| 搜索结果（命令面板选中节点） | 同"看这里" | 2s |

- **U.10.05-R1** 高亮只用 `--hx-focus` 和 `--hx-model` 两种颜色；不用 `accent`（橙色专门表示运行中）。
