## 1. 节点结构
```
        ┌──────────────────────────────────────┐
        │▌[图标] 标题                AI  ● 状态 │ ← 头部 38：标记色条 3px（可选）、图标格 20、标题 14/600
        │        类型 · 补充（mono 10.5）       │
        ├──────────────────────────────────────┤
  ●─────┤ context  上下文包                    │ ← 端口行 24：输入在左，输出在右
  ●─────┤ model                       result ├─────●
        ├──────────────────────────────────────┤
        │ 输出类型        [ 方案@1        ▾ ] │ ← 内联控件行 28（最多 4 行，`C.03.05-R1`）
        ├──────────────────────────────────────┤
        │ ▬▬▬▬▬▬▬▬▬▬▬▱▱▱▱  生成中 62%         │ ← 状态脚（只在运行相关状态出现）
        └──────────────────────────────────────┘
```
- 宽：标准 `--hx-node-w`，紧凑 `--hx-node-w-sm`（资源、分支、人工、子图端口、账本、汇合）。用户拖宽后按 `ui.width`。
- 主体：`bg-3` 底，`line-2` 外框，`r-lg`，`shadow-node`。
- 图标格 20×20，`r-xs`，`bg-5` 底，图标 `text-2`（`U.08-R3`）。
- 类型行：`类型 · 补充`，补充按节点类型显示最有用的一项（Agent：`生命周期 · 输出类型`；资源：`种类`；容器节点：`N 个节点`；循环运行中：`第 2 / 5 轮`）。
- 被提升成端口的参数，在输入端口列表里显示，端口名后加 `⇢`。
- 折叠（`ui.collapsed`）时只显示头部，端口收成头部左右两侧的一个汇总圆点。
- 锁：`lock=user` 时头部显示锁图标（`text-3`），悬停提示"只有你能修改"；`frozen` 时锁图标为 `text-1`，整个节点不可拖动。

## 2. 状态
| 状态 | 外框 | 头部状态点 | 状态脚 | 其他 |
|---|---|---|---|---|
| 待运行 idle | `line-2` | 无 | 隐藏 | — |
| 排队中 queued | `line-3` | 空心灰圆 | "排队中"；在资源池排队时"排队中 · 前面 3 个" | — |
| 运行中 running | `accent-line` + 3px `accent-weak` 光晕 | 橙色旋转弧 | 橙色进度条 + 进度文字（`node.progress`） | 出边显示流动 |
| 等待中 waiting | `wait` 虚线 | 黄色暂停符 | "等待审批 · 2:13" | 审批按钮直接显示在节点上（`U.19.03`） |
| 已完成 done | `line-2` | 绿色对勾 | 收起，留 2px 绿线 1.2s 后淡出 | 头部显示耗时（mono 11） |
| 失败 failed | `danger` | 红色叉 | 红色错误摘要一行 | "重试""查看详情"按钮 |
| 已取消 cancelled | `line-2` | 灰色叉 | "已取消" | 透明度 0.7 |
| 已跳过 skipped | `line-1` | 灰色横线 | 隐藏 | 整个节点透明度 0.45 |
| 用缓存 cached | `line-2` | 灰色闪电 | 隐藏 | 头部显示"缓存" |

- **U.10.02-R1** 状态切换时外框和阴影过渡 `--hx-t-2`。
- **U.10.02-R2** 节点在**当前查看的运行**里的状态才显示；没有选择运行时，显示最近一次运行的终态，并整体降低饱和度（表示"这是上次的结果"），状态点旁加"上次"字样。
- **U.10.02-R3** 同一个节点在循环多轮、扇出多份里执行时，节点上显示**最新一次**执行的状态；状态脚显示汇总（"第 2 / 5 轮"、"3 / 4 份完成"）。点开右栏监控页可以看每一次。
- **U.10.02-R4** 悬停节点：外框变为 `line-3`，不加阴影，不放大。
