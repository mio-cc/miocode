## 1. 规则
| 编号 | 规则 |
|---|---|
| U.10.01-R1 | 背景色 `--hx-bg-1`，点阵网格，点间距 `--hx-grid` × 缩放倍率，点色 `--hx-grid-dot` |
| U.10.01-R2 | 缩放 < 0.5 时网格间距翻倍，避免点阵过密 |
| U.10.01-R3 | 网格用 CSS `background-image` 画；平移缩放时只改 `background-position` 和 `background-size`，不重建 DOM |
| U.10.01-R4 | 缩放过程中暂时关闭网格过渡，停止 120ms 后恢复 |
| U.10.01-R5 | 缩放范围 0.2–2.5；滚轮缩放以光标为中心，每格 ×1.1；触控板捏合同理；`Ctrl` + 滚轮也是缩放，普通滚轮在触控板上是平移 |
| U.10.01-R6 | 框选框：填充 `--hx-marquee`，描边 `--hx-marquee-line`（中性灰，不用模型色） |
| U.10.01-R7 | 对齐参考线：拖动节点和相邻节点的左边、右边、中线、顶边对齐时，显示 1px `--hx-line-3` 线 |
| U.10.01-R8 | 便签（`C.02.05` Note）：`bg-3` 底（有标记色时用对应 `-weak`），`r-md`，无阴影，文字 13；层级在连线之上、节点之下 |
