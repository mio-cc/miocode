## 1. 节点怎么读
```
            ┌─ Agent · 验收者 ─────────────────┐
 上下文 ●───┤● 上下文                            │
 大模型 ●───┤● 模型                              │
 提示词 ●───┤● 指令                    结果 ●────├──→
            │ ┌ 参数区（凹槽）───────────────┐   │
            │ │ 角色卡  [ 验收者@1      ▾ ] │   │
            │ │ 指令    由上游「提示词」提供 │   │
            │ │ 输出类型 [ 判定@1       ▾ ] │   │
            │ └──────────────────────────────┘   │
            └────────────────────────────────────┘
```
- 左边圆点是输入，右边圆点是输出；圆点颜色 = 数据类型（`U.03.03`），类型兼容才能连。
- 中间参数区是"常用"参数（`C.03.05` group=常用）；其余参数在右栏属性里。
- 端口名用中文（上下文、模型、指令、工具、结果……），英文键名只在悬停提示里出现。

## 2. 每个参数两种填法
| 状态 | 节点上显示 |
|---|---|
| 没接线 | 正常控件，直接填 |
| 接了线 | 斜纹底 + "由上游「X」提供"；不可编辑；值来自上游 |
| 断开线 | 恢复显示原来填的值 |

## 3. 提示词写在哪
| 情况 | 写在哪 |
|---|---|
| 这个 Agent 这次要做什么（最常见） | Agent 节点的**指令**框 |
| 要复用、要填变量、几个 Agent 共用 | **提示词节点**（节点库 › 智能体 › 提示词）：大文本框里写 `{{变量}}`，左边自动长出同名输入端口；输出接到 Agent 的"指令" |
| 长期不变的人设和规矩 | **角色卡**（资源库），Agent 上用下拉选 |

模型最终收到 = ① 角色卡 + ② 指令 + ③ 上下文 + ④ 可用工具 + ⑤ 输出格式。指令框右上角的眼睛按钮打开"预览最终提示词"：按 ①–⑤ 分段，变量用占位标出（`‹公司 ← 「报价表」运行时的输出›`），每段估算 tokens。

## 4. 规则
| 编号 | 规则 |
|---|---|
| U.10.07-R1 | 节点上的多行文本固定 3 行高，超出滚动；双击在右栏打开大编辑器（变量高亮、示例值预览、字数和 tokens、历史版本） |
| U.10.07-R2 | 文本框里的滚轮和按键不影响画布（不缩放、不触发快捷键）；Esc 失焦 |
| U.10.07-R3 | 提示词变量在失焦后才更新端口，编辑中显示"失焦后更新变量端口" |
| U.10.07-R4 | 变量端口的名字用等宽字体并带 `{{ }}` 淡色括号，和普通端口区分 |
| U.10.07-R5 | 工具节点有"连接"参数（widget=connection）；下拉里最后一项是"新建连接…"，选中后打开连接表单，保存后自动选中 |

## 5. 验收
1. 新用户不看文档，能在 1 分钟内回答"提示词写在哪"（可用性测试 5 人中 4 人通过）。
2. 预览里的内容与实际发给模型的请求逐段一致（`E.10` 记录对比）。

## 补充（demo v0.5.4）
- **U.10.07-R6** 节点上的端口只显示中文名称，不显示类型名（类型由圆点颜色表达，避免挤占名称位置，例如"工具"被挤成"工"）；鼠标悬停端口时提示"名称 · 类型 · 可接多根"。
