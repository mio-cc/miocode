# U.10.06 LOD 分级

| 项 | 内容 |
|---|---|
| 编号 | U.10.06 |
| 类型 | 规范 |
| 上级 | U.10 画布视觉 |
| 下级 | 无 |
| 状态 | 草稿 |
| 素材 | 设17 |
| 最后修改 | 2026-11-22 |

## 1. 细节分级（LOD）
| 级别 | 缩放 | 显示 |
|---|---|---|
| 1 | ≥ 0.75 | 完整节点：端口名、内联控件、状态文字、子图缩略图 |
| 2 | 0.45–0.75 | 隐藏端口名、内联控件、类型行、缩略图内容；保留端口圆点、标题、状态点、状态条 |
| 3 | < 0.45 | 节点只剩色块和大号标题（标题字号按缩放反向放大，保持屏幕上至少 12px）；连线变细为 1px；关闭连线流动动画 |

## 2. 规则
- **U.10.06-R1** 级别切换用 CSS 类（`.lod-2`、`.lod-3`）挂在视口容器上，隐藏用 `visibility` 不用 `display`（避免布局变化）。
- **U.10.06-R2** 级别只在缩放停止 120ms 后切换，缩放过程中不切换。
- **U.10.06-R3** 节点数 > 150 时开启视口裁剪：视口外的节点设 `content-visibility: hidden`，连线不画（`U.17`）。
- **U.10.06-R4** 预览浮层、父图位置卡、小地图、节点缩略图都用 canvas 绘制简化图（方块 + 线），不受 LOD 影响。
