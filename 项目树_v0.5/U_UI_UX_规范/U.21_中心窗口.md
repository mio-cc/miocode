## 1. 一个窗口，四个分区
`Ctrl+,`、左栏图标栏、账户菜单、命令面板都能打开。顶部分段切换四个分区，左侧是分区内的导航，右侧是内容；右侧还可以滑出表单。

| 分区 | 管什么 | 左侧导航 |
|---|---|---|
| **包** | 能力从哪来（`C.15`） | 内置（Harness 核心）· MCP 服务 · 扩展包 · 技能；底部"接入 MCP / 安装扩展包 / 导入技能" |
| **连接** | 账号和密钥（`C.16`） | 全部连接 · 模型（各提供方）· 代码托管 · 办公协作 · 数据库 · 邮件 · 搜索；底部"新建连接" |
| **资源库** | 可复用的资产 | 角色卡 · 上下文配方 · 数据类型 · 子图库 · 模板 |
| **设置** | 只放全局项 | 通用 · 外观 · 快捷键 · 默认模型 · 授权与安全 · 预算与用量 · 并发与限流 · 数据与存储 · 本机访问与命令行 · 关于与诊断 · **包的设置**（各包声明的设置项自动出现） |

## 2. 包详情页
从上到下：基本信息（类型、版本、状态、来源、签名）→ 待确认 / 出错提示（可直接操作）→ 带来的内容（节点 / 工具列表，工具可逐个开关，"在节点库中显示"）→ 带来的连接类型 → 需要的连接（没有就"新建连接"）→ 这个包的设置 → SKILL.md（技能）→ 权限。右上角：启用开关、更多（检查更新、编辑命令、日志、移除）。

## 3. 连接详情页
状态 → 字段（密钥只显示首尾）→ 模型列表（模型连接）→ 谁在用 → 断开 / 删除。"新建连接"先选类型（按分组列出，标明由哪个包提供），再填自动生成的表单，可以"测试"。

## 4. 规则
| 编号 | 规则 |
|---|---|
| U.21-R1 | 修改即时生效并自动保存，不设"保存"按钮（侧拉表单除外） |
| U.21-R2 | 左上搜索在当前分区内搜，命中到具体一行时滚动并高亮 |
| U.21-R3 | 旧入口自动跳转：模型 / 提供方 / 密钥 → 连接；工具 → 包 › 核心；MCP / 技能 / 扩展包 → 包 |
| U.21-R4 | 导航项右侧只在异常时显示标记（出错、待确认、未启用），正常不显示数字 |
| U.21-R5 | 页面内容由数据生成：包的贡献、连接类型的字段、包的设置都来自声明，新增一类东西不需要新做页面 |
| U.21-R6 | 授权与安全页包含：档位 × 动作矩阵（与 `C.09` §5 同一份数据）、外部内容不可信（锁定）、审批合并与时限、沙箱、网络白名单与允许目录、密钥存储位置、全局急停 |
| U.21-R7 | 预算与用量页：本月费用与预算进度、今天、tokens、运行次数、14 天柱状图、按模型占比、预算设置、最近运行 |
