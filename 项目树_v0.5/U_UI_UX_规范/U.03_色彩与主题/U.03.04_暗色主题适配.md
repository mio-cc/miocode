## 1. 规则
| 编号 | 规则 |
|---|---|
| U.03.04-R1 | 深色主题通过 `<html data-theme="dark">` 切换令牌值实现，组件不写主题分支（`G.06.03-R5`） |
| U.03.04-R2 | 明暗选项三种：浅色（默认）、深色、跟随系统；配色另选（`U.03.05`）。选择存 localStorage 的 `hx:theme-mode`、`hx:theme-palette`，同时写进配置 `ui.theme.mode`、`ui.theme.palette` |
| U.03.04-R3 | 首屏渲染前用 `index.html` 里的内联脚本读取主题并设置 `data-theme`，避免闪一下浅色 |
| U.03.04-R4 | 深色主题下表面按 `bg-0` → `bg-5` 逐级变亮；阴影减弱，改用 `--hx-highlight` 内高光表达层级 |
| U.03.04-R5 | 语义色和类型色在深色主题下提亮，保证 `U.02-R6` 对比度 |
| U.03.04-R6 | 画布缩略图（小地图、预览、父图位置卡、节点缩略图）用 canvas 绘制时，颜色每次从 CSS 变量读取；主题切换时重绘 |
| U.03.04-R7 | 主题切换不加过渡动画（避免整个界面闪烁），立即生效 |

## 2. 令牌表达不了、允许写主题分支的地方（登记表）
| 组件 | 原因 |
|---|---|
| `.hx-seg__thumb` 深色下加内高光描边 | 分段控件滑块在深色主题下与背景对比不足 |
（新增条目需要设计方同意。）

## 3. 验收标准
1. 4 套配色 × 浅色、深色共 8 种组合下所有界面截图，没有看不清的元素（`U.20`）。
2. 切换主题后，小地图和预览浮层的颜色同步变化。
