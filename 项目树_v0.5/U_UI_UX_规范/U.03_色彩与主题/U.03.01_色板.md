## 1. 表面层级
| 令牌 | 用途 |
|---|---|
| `--hx-bg-0` | 应用最底层：顶部条、左右侧栏的背景 |
| `--hx-bg-1` | 画布底 |
| `--hx-bg-2` | 浮在画布上的面板：停靠栏、小地图、对话框、预览浮层、父图位置卡、菜单 |
| `--hx-bg-3` | 节点主体、卡片 |
| `--hx-bg-4` | 输入框底色、悬停态 |
| `--hx-bg-5` | 按下态、分段控件选中项、节点图标格 |
| `--hx-bg-glass` | 玻璃材质的底色：浮在画布上的面板（停靠栏、小地图、父图位置卡、对话框、浮动回复、提议栏、提示）用它 + `--hx-blur-glass` 背景模糊（`U.23-R6`）；半透明的 `bg-2`，每套主题浅色 / 深色各一个值（新增，`P.09` K112） |

- **U.03.01-R1** 每往上浮一层，背景亮一档（深色主题）或保持白色但加阴影（浅色主题，`bg-2` 和 `bg-3` 同为白色）。不用阴影代替层级以外的含义。
- **U.03.01-R2** 只有浮动元素（面板、菜单、被拖起来的节点）有阴影（`U.06`）。

## 2. 线
| 令牌 | 用途 |
|---|---|
| `--hx-line-1` | 内部分区线 |
| `--hx-line-2` | 组件外框 |
| `--hx-line-3` | 悬停时的外框 |
| `--hx-highlight` | 表面顶部 1px 内高光（已写在阴影令牌里） |

## 3. 文字
| 令牌 | 用途 |
|---|---|
| `--hx-text-1` | 标题、数值、正文 |
| `--hx-text-2` | 次要信息、端口名、图标 |
| `--hx-text-3` | 标签、占位、辅助说明 |
| `--hx-text-inv` | 主按钮（橙底）上的文字 |

- **U.03.01-R3** 同一个组件里最多用两级文字颜色。

## 4. 标记色（新增）
用户给节点和便签设置的标记色（`C.02.05` 的 `ui.color`），只用于帮助用户自己分组，不表达系统含义。
| 令牌 | 色相 | 用途 |
|---|---|---|
| `--hx-mark-c1` … `--hx-mark-c6` | 灰蓝、青、绿、黄、橙褐、紫灰 | 节点头部左侧 3px 色条；便签底色（用对应的 `-weak` 变体） |

- **U.03.01-R4** 标记色饱和度低于语义色，不能和 `accent`、`ok`、`danger`、`wait`、`model` 混淆（色相和明度都要拉开，具体色值在 tokens.css 里定，需通过 `U.02-R6` 对比度检查）。
- **U.03.01-R5** 标记色只出现在节点头部色条和便签上，不能用在端口、连线、状态上。

### 实施卡
- 要改的文件：`design/tokens.css`（新增 `--hx-mark-c1…c6` 及 `-weak`，两个主题）。
- 测试用例：`U0301-T1`（对比度脚本通过）。
