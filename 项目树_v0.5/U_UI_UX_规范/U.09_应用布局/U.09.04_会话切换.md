## 1. 结论
**会话切换时，左侧栏的"结构"、画布、面包屑、对话、提议、运行信息都整体切换到那个会话。** 不同会话的图结构不同（有的只有一层，有的有三层嵌套），结构树永远显示**当前会话的当前图**。

## 2. 每个会话各自保存的"现场"
| 内容 | 保存在哪 | 切回来时 |
|---|---|---|
| 当前图（`active_graph_id`） | 服务端 Session（`C.10`） | 显示这张图 |
| 所在的层（面包屑路径） | 服务端 `Session.last_location.scope`：`root` 或容器节点 ID（`C.10-R3`） | 回到上次所在的层，父图位置卡同步 |
| 视图位置和缩放 | 浏览器 localStorage `hx:view:<图 ID>:<层>`，层写 `root` 或容器节点 ID（与 `C.10-R3`、路由同一写法；视图不进图文档，`P.09` K14、K75） | 恢复；没有记录时"适应画布" |
| 选中的节点 | 前端内存（`W.03.03`），只保留本次打开页面期间 | 恢复；节点已不存在则忽略 |
| 撤销 / 重做 | 服务端按"图 + 分支 + 操作者"记录（`B.04.02`），天然跟着图走 | 在这个会话里按 ⌘Z 只撤销这张图上自己的修改 |
| 授权档位 | 挂在会话上的授权书（`B.04.05`） | 档位胶囊显示这个会话的档位 |
| 对话记录、卡片块 | 服务端消息（`C.10`） | 对话页和浮动回复换成这个会话的内容 |
| 模型提议 | 服务端，按图（`B.04.02`） | 提议栏和幽灵节点只显示这张图的提议 |
| 运行 | 服务端 | 监控页显示这个会话的运行；正在运行的那个继续实时更新 |
| 输入框里没发出去的文字 | localStorage `hx:draft:<会话 ID>` | 恢复 |

**不随会话切换的**（全局）：主题、左右侧栏的开合和分区折叠、右栏当前标签页、节点库、设置。

## 3. 规则
| 编号 | 规则 |
|---|---|
| U.09.04-R1 | 切换会话不打断任何运行：其他会话正在跑的运行在后台继续，会话列表里显示"● 运行中"；等待审批的显示数字角标（`U.14.04`） |
| U.09.04-R2 | 会话列表每一项第二行显示图的结构摘要：`3 层 · 2 个子图 · 24 节点 · 刚刚`；只有一层时写"单层"；还没有图写"空白画布" |
| U.09.04-R3 | "结构"分区标题旁显示当前会话名（`结构  竞品定价调研`），让用户知道这棵树属于谁 |
| U.09.04-R4 | 一个会话挂了多张图时（`C.10-R1`），结构分区标题右侧出现图切换下拉框；结构树只显示当前图 |
| U.09.04-R5 | 切换时画布用"进入"转场（`U.07.02`，从中心放大），时长 `--hx-t-3`；减少动效模式下直接切换 |
| U.09.04-R6 | 切换后焦点移到画布（键盘可以直接操作）；读屏播报"已切换到会话「xxx」，当前图 3 层" |
| U.09.04-R7 | 路由随会话变化：`/c/:sessionId/g/:graphId?scope=`（`P.09` K27）；浏览器后退回到上一个会话 |
| U.09.04-R8 | 新建会话：列表顶部插入"新会话"，画布为空，显示空白画布空状态（`U.14.02`）：从模板开始 / 在对话框里描述 / 从节点库拖入；输入框获得焦点；默认 1 档（`S.04-R2`） |
| U.09.04-R9 | 从模板创建是一次可撤销的操作（`import_apply`，`B.06.05`）；会话还叫"新会话"时，自动改名为模板名 |
| U.09.04-R10 | 快捷键：`Alt+[` / `Alt+]` 切到上一个 / 下一个会话，`Alt+N` 新建会话；命令面板里也能搜会话名切换（`U.13.04`）。不用 `Ctrl+N`、`Ctrl+Shift+[ ]`，它们是浏览器的保留键 |

## 4. 原型
demo v0.5（`sj/配色demo_v0.5/`，模块 `32_sessions.js`）：5 个示例会话结构各不相同——竞品定价调研（3 层）、代码评审流水线（2 层，循环）、周报自动生成（单层）、客服工单分类（2 层，子图引用）、论文综述（3 层）。切换后再切回来，所在层、视图、撤销栈、对话、提议都恢复。

## 5. 验收标准
1. 在两个结构不同的会话之间切换，结构树、面包屑、画布内容、会话名、档位、对话都对应切换。
2. 在会话 A 的第 3 层停留后切到 B 再切回 A，回到第 3 层、视图位置不变。
3. 会话 A 运行中切到 B：A 的运行不中断，列表显示"● 运行中"；切回 A 看到最新进度。
4. 新建会话显示空白画布空状态；从模板创建后 ⌘Z 能撤销回空白。
