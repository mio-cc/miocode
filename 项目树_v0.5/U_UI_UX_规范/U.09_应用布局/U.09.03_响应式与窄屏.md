## 1. 断点
| 窗口宽度 | 变化 |
|---|---|
| ≥ 1180 | 完整布局 |
| < 1180 | 顶部条隐藏编排者模型胶囊（对话框上的模型标签仍在） |
| < 1100 | 右侧栏改为**覆盖式**：浮在画布上方，宽 340，带 `shadow-float`，点画布空白处关闭；对话框和浮动回复宽度改为"画布宽 − 24"；隐藏小地图 |
| < 900 | 左侧栏默认收成图标栏；面包屑只显示当前层和上一层，中间用"…"（点击展开完整路径） |
| < 760 | 显示提示"窗口太窄，建议加宽到 900 以上使用"（不阻止使用） |

- **U.09.03-R1** 最小支持宽度 760，最小支持高度 560。
- **U.09.03-R2** 断点值写成令牌之外的常量（媒体查询不能用 CSS 变量），集中定义在 `web/src/styles/breakpoints.css`，并在本文登记；不在别处另写断点。
- **U.09.03-R3** 浏览器缩放（Ctrl + / −）按 CSS 像素计算断点，不另做处理。
- **U.09.03-R4** 移动端、平板不支持（`P.02`）。

## 2. 验收标准
在 1440、1180、1100、900、760 五个宽度下截图，没有重叠、没有截断看不到的按钮（`U.20`）。
