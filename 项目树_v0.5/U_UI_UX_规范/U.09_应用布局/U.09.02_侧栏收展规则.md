## 1. 左侧栏
| 操作 | 结果 |
|---|---|
| 点顶部条左栏开关，或按 `[` | 在 264 展开和 56 图标栏之间切换 |
| 图标栏里点会话 / 结构 / 节点库图标 | 展开左栏并打开对应分区 |
| 按 `/` | 展开左栏、展开节点库并聚焦搜索框 |
| 分区标题点击 | 折叠 / 展开该分区 |

## 2. 右侧栏
| 操作 | 结果 |
|---|---|
| 点顶部条右栏开关，或按 `]` | 打开 / 关闭（打开时显示上次的标签页） |
| 按 `I` | 打开右栏并切到"属性" |
| 点浮动回复 | 打开右栏并切到"对话" |
| 点运行按钮旁的状态，或运行卡片 | 打开右栏并切到"监控"（`U.09.07`） |

- **U.09.02-R1** **选中节点时不自动打开右栏**（参数常用的已经内联在节点上，自动弹出会遮挡画布）。右栏收起而属性页有内容时，右栏开关上显示一个小圆点。
- **U.09.02-R2** 收展状态记住：左栏开合、左栏各分区折叠、右栏开合、右栏当前标签页，存 localStorage（`G.06.02-R7`）。
- **U.09.02-R3** 收展时画布的视图中心保持不变：画布宽度变化后，平移量补偿一半宽度差，节点不跳动（demo `lastLeft` 补偿）。

## 3. 专注模式
| 操作 | 结果 |
|---|---|
| 按 `F` | 两侧栏都收起；再按一次恢复到之前的状态 |
| 专注模式下按 `[` / `]` | 单独打开对应侧栏，并退出专注模式 |

- **U.09.02-R4** 专注模式不隐藏顶部条、对话框和画布浮动面板。
- **U.09.02-R6** 不设专注按钮（F 键保留，写在侧栏开关的悬停提示里）；右栏只有顶部条一个开关，右栏内不再放收起按钮。
- **U.09.02-R5** 设计规范 v0.3 里 `Tab` 隐藏所有浮动面板的功能取消；`Tab` 恢复为键盘焦点切换（`U.16`）。

## 补充（demo v0.5.4–v0.5.11）
| 编号 | 规则 |
|---|---|
| U.09.02-R7 | 侧栏是一个整体滚动区：新建会话、会话、结构、节点库都在里面，全部展开也能滚到底；底部一排（账户 · 包 · 连接 · 资源库 · 设置）固定在下方，不随内容滚动 |
| U.09.02-R8 | 收起后的图标栏和顶部的侧栏开关对齐在同一条中线上（开关左边距 = (56 − 30) / 2） |
| U.09.02-R9 | 侧栏、图标栏、底部一排、画布停靠栏的悬停高亮是一块共用的"流动"底块：在按钮之间移动时平滑滑过去，离开区域时淡出（`U.23-R21`） |
| U.09.02-R10 | 滚动条平时隐藏，鼠标移进区域才出现 6px 半透明细滑块（`U.23-R20`） |
