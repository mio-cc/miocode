## 2. 各区域
| 区域 | 位置与尺寸 | 内容 | 背景 |
|---|---|---|---|
| ① 顶部条 | 全宽，高 48（`--hx-top-h`） | 左：左栏开关、会话名（可点击重命名）、面包屑（`U.13.06`）、分支（草稿分支时显示"草稿 · 落后 N"）。右：编排者模型胶囊（模型正在编辑时显示呼吸点）、档位胶囊（5 格刻度，`U.12`）、运行 / 急停按钮、通知（铃铛，`U.09.05`）、主题菜单（配色 × 明暗，`U.03.05`）、右栏开关（右栏收起且有新内容时显示小圆点）。不设专注按钮（`U.09.02-R6`）；根图时不显示面包屑和分支（`U.23-R11`） | `bg-0`，底部 `line-1` |
| ② 左侧栏 | 宽 264（`--hx-ls-w`）；收起时 56 的图标栏 | 新建会话按钮；会话列表（第二行是结构摘要）；**结构**（当前会话当前图的结构树，`U.13.06`；切换会话时跟着切换，`U.09.04`）；节点库（分类树、收藏、最近，`U.22`）；底部一排：账户 · 包 · 连接 · 资源库 · 设置（`U.09.02-R7`）。会话、结构、节点库三区都可以折叠，折叠状态记住 | `bg-0` |
| ③ 画布 | 剩余全部空间 | 节点、连线、便签；画布上的浮动元素见下 | `bg-1` + 点阵网格 |
| ③a 停靠栏 | 画布左侧竖排、垂直居中（demo v0.5.3；原为顶部居中） | 工具：选择 V、平移 H、添加 A、打包为子图、整理布局 L、适应画布 1、撤销、重做；可拖动（R6） | `bg-2`，`r-xl` 胶囊 |
| ③b 小地图 | 画布左下，196×120 | 当前层缩略图和视口框；旁边是缩放比例和类型图例开关 | `bg-2` |
| ③c 父图位置卡 | 画布左上，宽 236 | 只在子图里出现（`U.13.06`） | `bg-2` |
| ④ 对话框 | 画布底部居中，距底 16；宽 `min(720, 画布宽 − 460)`，最小 `min(440, 画布宽 − 24)` | 按 `U.09.06`：`+` 附件与 @ 引用、`/` 命令、附带选中标签（有选中节点时）、上下文用量环、模型与思考强度按钮、发送；不放快捷指令（`U.09.06-R1`） | `bg-2`，`r-xl`，`shadow-float` |
| ⑤ 提议栏 | 对话框正上方 | "模型提议 N 处修改 · 逐条查看 · 全部采纳 · 全部拒绝"（`U.12`） | `bg-2`，模型色左边线 |
| ⑥ 浮动回复 | 对话框上方（有提议栏时在提议栏上方） | 只显示最近一条回复（最多 2 行）；点它打开右栏对话页；收拢 / 展开按 `U.09.06-R4` | 玻璃（`U.23-R6`） |
| ⑦ 右侧栏 | 宽 340（`--hx-rs-w`），默认收起 | 三个标签：**属性**、**对话**、**监控**（`U.09.07`，含日志、操作历史） | 浮起的圆角卡片（`U.23-R4`） |

## 3. 新增布局令牌
| 令牌 | 值（说明用） |
|---|---|
| `--hx-top-h` | 48 |
| `--hx-ls-w` / `--hx-ls-w-min` | 264 / 56 |
| `--hx-rs-w` | 340 |
| `--hx-comp-max` / `--hx-comp-min` | 720 / 440 |
| `--hx-comp-gutter` | 460（对话框宽度 = `min(comp-max, 画布宽 − comp-gutter)`，见 ②④ 行） |
| `--hx-float-inset` | 12（浮动面板距画布边） |

## 4. 规则
- **U.09.01-R1** "适应画布"计算可见区域时，要避开：左侧停靠栏（左 64；在子图里有父图位置卡时左 304）、底部对话框和浮动回复（下 = 对话框高度 + 浮动回复高度（最多 80，收拢时为 0）+ 44），上、右各留 28（demo v0.5 `40_tidy.js` 的 `fitTarget`）。
- **U.09.01-R2** 原运行抽屉（设计规范 v0.3 的底部抽屉）取消，内容并入右侧栏"监控"页（`U.09.07`）（`P.06`："运行抽屉"为废弃旧称）。
- **U.09.01-R3** 对话框、浮动回复、提议栏的水平中心始终是**画布**的中心，不是窗口中心。
- **U.09.01-R4** 浮动元素不能互相遮挡：小地图和对话框在窄画布下重叠时，小地图隐藏（`U.09.03`）。

## 补充（v0.5.10）
- **U.09.01-R6** 画布上的浮动面板（左侧停靠栏、小地图、父图位置卡）可以拖动换位置：拖面板上的抓手（⋮⋮）；拖动时在画布四边 12px 内吸附；位置按画布宽高的比例存 localStorage，窗口缩放后仍在画布内；双击抓手回到默认位置。对话框、提议栏不可拖。
