## 1. 结构
```
┌──────────────────────────────────────────────────────────┐
│ [附件标签…]                                              │
│ 让 AI 搭图、改图或运行……   / 命令 · @ 引用               │
│ [+] [附带 1 个节点]                ◔ 5%  ✦ 模型 · 高 ▾  (↑) │
└──────────────────────────────────────────────────────────┘
```
## 2. 元素
| 元素 | 行为 |
|---|---|
| `+` | 上传文件；附带画布选中；引用节点 / 文件 / 其他会话 / 技能 |
| 附带标签 | 只在画布有选中时出现："附带 N 个节点"；没有选中时什么都不显示 |
| 上下文环 | 这次发送约占模型窗口多少；点开看构成（系统、图、对话、选中、附件、正在输入），可"立即压缩"；超过 80% 自动压缩较早对话 |
| 模型按钮 | 当前会话的编排者模型（按连接分组、显示窗口和价格）+ 思考强度；"管理模型…"进连接 |
| 发送 | 圆形箭头；输入为空时是灰色，有字才亮 |
| `/` | 命令：运行、解释、优化、加审批、整理布局、模型、技能、模板、压缩、清空、设置 |
| `@` | 引用：当前图节点、允许目录的文件、其他会话、技能 |

## 3. 规则
| 编号 | 规则 |
|---|---|
| U.09.06-R1 | 不放常驻快捷指令 chips 和常驻说明文字（`U.23-R5`）；能力通过 `/` 发现 |
| U.09.06-R2 | 模型选择只影响当前会话，切换会话时恢复各自的选择（`U.09.04`） |
| U.09.06-R3 | 发送键可在"设置 › 通用"改为 Ctrl+Enter |
| U.09.06-R4 | 浮动回复只显示最近一条（最多 2 行）。浮动回复右上角有一个从边框上长出的小标签（▾，两侧内凹圆弧，和浮动回复同一块材质）。**收拢**：点标签（或 8 秒无操作、或 Esc）→ 浮动回复内容淡出，它的边框线像流水一样离开浮动回复，落到下面的输入框，沿输入框绕一整圈，收在输入框右上角，长出一个突出的小尾巴（▴，同样的标签造型）。**展开**：点小尾巴 → 线条倒着流回，浮动回复重新出现。收拢时有新回复：自动展开；动画中到达的新回复在小尾巴上亮一个模型色小点。没有回复时不显示小尾巴。减少动效时直接切换。线条用主色 1.6px + 7px 柔光，全程约 1.2 秒 |

## 4. 思考强度
参考主流做法：Codex 有 极低 / 低 / 中 / 高 / 超高 五挡（minimal–xhigh），日常推荐"中"；Claude 有 低 / 中 / 高 / 最高，部分模型可以关闭思考。

| 编号 | 规则 |
|---|---|
| U.09.06-R5 | 强度全集：关闭 off · 极低 minimal · 低 low · 中 medium · 高 high · 超高 xhigh · 最高 max。**每个模型只显示它支持的强度**（连接测试时从提供方读取，存在模型的 `effort` 字段，`C.16`）；不支持调节的模型显示"这个模型不支持调节思考" |
| U.09.06-R6 | 默认"中"（设置 › 默认模型 › 默认思考强度）；模型没有这一挡时取最接近的一级 |
| U.09.06-R7 | 选择按"会话 × 模型"记住：同一会话里换模型再换回来，强度不丢 |
| U.09.06-R8 | 每一级强度的悬停提示写适用场景（"日常任务（推荐）""质量优先，最慢最贵"……） |
