# U.09.05 通知中心

| 项 | 内容 |
|---|---|
| 编号 | U.09.05 |
| 类型 | 规范 |
| 上级 | U.09 应用布局 |
| 下级 | 无 |
| 状态 | 草稿 |
| 素材 | demo v0.5 |
| 最后修改 | 2026-11-22 |

## 1. 位置与形态
顶部条右侧铃铛。未读时显示一个 7px 小圆点：有错误红色，只有待审批黄色，其他主色。不显示数字（`U.23-R6`）。

## 2. 内容
| 来源 | 类别 | 可以直接做 |
|---|---|---|
| 人工节点、L2+ 工具等你审批 | 待我处理 | 批准 · 驳回 · 在画布上看 |
| 运行完成 / 失败 / 急停 | 动态 | 打开对应会话或监控 |
| MCP 连接失败、连接测试失败 | 动态 | 打开包或连接详情 |
| 预算达到阈值 | 动态 | 打开预算页 |

## 3. 规则
| 编号 | 规则 |
|---|---|
| U.09.05-R1 | 三个标签：全部 / 待我处理 / 动态；"全部已读"；齿轮进"设置 › 通用 › 通知" |
| U.09.05-R2 | 审批处理后条目自动移除；急停时所有待审批条目移除 |
| U.09.05-R3 | 每类通知能在设置里单独关闭；可开启系统桌面通知 |
| U.09.05-R4 | 数据来自会话事件流和 `/approvals`（`B.04.04`），刷新页面不丢 |
