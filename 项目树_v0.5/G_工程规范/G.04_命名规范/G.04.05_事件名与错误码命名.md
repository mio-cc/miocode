## 1. 规则
| 对象 | 规则 | 定义在 |
|---|---|---|
| 事件名 | `对象.动作`，全小写、下划线分词 | `C.06` §4 |
| Op 种类 | 动词开头 snake_case：`add_node`、`remove_nodes` | `C.05.02` |
| 授权动作名 | `组.动作`：`op.add_node`、`tool.L2` | `C.09` §4.2 |
| API 错误码 | snake_case，名词或"名词_状态"：`graph_conflict`、`node_locked` | `C.11` §3 |
| 失败类别 | snake_case 形容词或名词：`transient`、`format_invalid` | `C.11` §4 |
| 诊断码 | `V` + 两位数字 | `C.11` §5 |
| 指标名 | `hx_` 前缀 + snake_case + 单位后缀：`hx_llm_latency_ms`、`hx_tool_calls_total` | `E.09.04` |
| 日志 msg | 和事件名同风格，但不进事件流 | `G.12` |

- **G.04.05-R1** 同一个词在不同类别里含义要一致：`resolved` 永远表示"一个请求得到了答复"。
- **G.04.05-R2** 新增任何一类名字，先登记在"定义在"那一列的文档里。
