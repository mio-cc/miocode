## 1. 规则
| 编号 | 规则 |
|---|---|
| G.06.02-R1 | 状态分四类，各放各处：**服务器数据**（图、运行、会话、提议）→ 对应 zustand store；**视图状态**（平移、缩放）→ `viewStore`，只给画布引擎用；**界面状态**（侧栏开合、当前标签页、选中）→ `uiStore`；**组件内部临时状态**（输入框正在编辑的文字、悬停）→ `useState` |
| G.06.02-R2 | 每个画布实例有自己的一组 store：用 `createXxxStore()` 工厂函数创建，通过 Context 提供；不使用全局单例 store（主画布和预览浮层、父图位置卡要能同时存在） |
| G.06.02-R3 | React 组件订阅 store 时必须用选择器只取需要的字段（`useGraphStore(s => s.title)`），对象和数组用 `shallow` 比较；禁止订阅整个 store |
| G.06.02-R4 | 高频数据（节点运行状态、进度、连线流动、平移缩放）**不进 React**：由画布引擎通过 `store.subscribe` 或 RunBridge 直接写 DOM（`W.06.15`、`U.17`） |
| G.06.02-R5 | 修改图只能调用 `dispatch(op)`（`W.05`），不能直接改 graph store 的数据（INV-08） |
| G.06.02-R6 | 派生数据（类型推断结果、校验结果、结构树）用纯函数从 store 计算，并按版本号缓存；不把派生数据存成另一份状态 |
| G.06.02-R7 | 需要跨刷新保留的界面状态（主题、侧栏开合、左栏各区折叠）存 localStorage，键名统一 `hx:` 前缀（如 `hx:theme`、`hx:ls-open`）；不在 localStorage 存图数据 |
| G.06.02-R8 | URL 里只放可分享、可回退的状态：会话 ID、当前图 ID、当前层（容器节点 ID）。浏览器"后退"等于返回上一层（`U.13.06`） |

## 2. 检查方式
- ESLint 自定义规则：禁止 `useXxxStore()` 不带参数调用；禁止在 `canvas/core/` 里 import `react`。
- 性能测试（`Q.08`）：平移、拖动时 React Profiler 记录的提交次数为 0。
