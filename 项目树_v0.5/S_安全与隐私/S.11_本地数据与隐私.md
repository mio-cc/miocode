## 1. 存了什么、存在哪
| 数据 | 位置 | 内容 |
|---|---|---|
| 数据库 | `<DataDir>/harness.db` | 图、Op 历史、运行、事件、检查点、会话、消息、提议、审批、授权书、审计 |
| 工作区 | `<DataDir>/blobs/` | 大内容：模型请求和响应（已脱敏）、工具结果、上传的文件 |
| 日志 | `<DataDir>/logs/` | 运行日志（已脱敏，不含正文，`G.12`） |
| 配置 | `<DataDir>/harness.yaml` | 设置（不含密钥） |
| 密钥 | 系统密钥库或 `<DataDir>/secrets.enc` | 模型和工具的密钥 |
| 扩展 | `<DataDir>/extensions/` | 已安装的扩展包 |
| 浏览器本地存储 | localStorage（`hx:` 前缀） | 主题、侧栏状态等界面偏好 |

## 2. 规则
| 编号 | 规则 |
|---|---|
| S.11-R1 | 所有数据只存在本机；除了用户配置的模型提供方、MCP 服务和工具访问的地址，不向任何地方发送数据（`S.07`） |
| S.11-R2 | 用户的内容（消息、图、工具结果）会发送给用户选择的模型提供方——首次配置模型时明确告知 |
| S.11-R3 | 保留期：事件和图永久保留；工作区原文默认 30 天后清理（可设置），清理后运行详情里显示"原文已清理"（`P.09` Q8） |
| S.11-R4 | **导出**：设置 → 数据 → 导出，生成一个包含图、会话、运行记录的 zip；**不包含密钥**；可以选择是否包含工作区原文 |
| S.11-R5 | **删除单项**：删除会话、图、运行时，同时删除只被它引用的工作区内容 |
| S.11-R6 | **彻底删除**：设置 → 数据 → 删除所有数据，二次确认（输入"删除"），删除整个 DataDir 和系统密钥库里的 Harness 条目，然后退出 |
| S.11-R7 | 卸载时询问是否保留数据（`O.05`） |
| S.11-R8 | `<DataDir>` 目录权限设为仅当前用户可读写 |
