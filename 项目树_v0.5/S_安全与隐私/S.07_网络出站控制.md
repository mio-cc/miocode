## 1. 规则
| 编号 | 规则 |
|---|---|
| S.07-R1 | Anywhere Door 主动访问的外部地址只有四类：已配置的模型提供方地址、已配置的 MCP HTTP 服务地址、工具出站白名单里的地址、自动更新地址（`O.06`，可关闭） |
| S.07-R2 | 工具出站白名单 `tools.allowed_hosts` 默认为空；写法为主机名或 `*.域名`，可以带端口；不支持 IP 段通配 |
| S.07-R3 | 声明式 http 扩展节点的 URL 主机名在**首次启用扩展包时**列给用户确认，确认后加入白名单（`S.08`） |
| S.07-R4 | 工具访问白名单外的地址：转为审批（"「检索」想访问 example.com，是否允许？· 本次 · 以后都允许"），不直接拒绝 |
| S.07-R5 | 禁止访问本机和内网地址（`S.06` §2），白名单也不能覆盖这条，除非在设置的"高级"里逐个允许 |
| S.07-R6 | 所有出站请求记录事件（`tool.call`、`llm.call`），审计页可以按主机名查看 |
| S.07-R7 | 遥测默认关闭（`O.09`）；关闭时不发出任何统计请求 |

## 2. 验收标准
1. 新安装的 Anywhere Door 在不配置任何东西的情况下运行演示模式，抓包看不到任何出站连接（自动更新检查关闭时）。
2. HTTP 工具访问白名单外地址时产生审批，而不是失败。
