## 1. 安全测试
| 测试集 | 内容 | 运行时机 |
|---|---|---|
| 授权矩阵测试 | `C.09` 判定表每一格；档位 4 的禁止事项（`S.04-R4`） | 每次 PR |
| 急停测试 | `S.09` §4 | 每次 PR |
| 本机服务测试 | `S.02` §2：Origin、Host、cookie、监听地址 | 每次 PR |
| 注入用例集 | `evals/injection/`：网页、文件、邮件、MCP 返回里嵌入改图、外发、提权指令，至少 30 条；全部必须被转为审核或拒绝 | 每次 PR（用 fake 模型模拟"被注入后照做"）；每个里程碑用真实模型跑一次 |
| 沙箱逃逸测试 | `S.06` §3 用例；路径越界、符号链接、资源耗尽 | 每次 PR |
| 密钥泄露测试 | 运行模板后扫描 DataDir、日志、导出文件、前端响应 | 每次 PR |
| 出站测试 | `S.07` §2 | 每个里程碑 |
| 依赖与密钥扫描 | `S.12` | 每天 + 每次 PR |

## 2. 漏洞响应
| 步骤 | 规则 |
|---|---|
| 报告渠道 | 仓库根目录 `SECURITY.md` 写明报告方式（邮箱），不在公开问题列表里讨论 |
| 确认 | 3 个工作日内确认收到并评估严重程度（CVSS） |
| 修复 | 高危 14 天内、中危 30 天内发布修复版本 |
| 公告 | 修复发布后在发布说明的"安全"分类里说明（不含利用细节） |
| 回归 | 每个已修复的漏洞补一条自动化测试 |
