## 1. 规则
| 编号 | 规则 |
|---|---|
| S.03-R1 | 密钥只存两处之一：**系统密钥库**（Windows 凭据管理器、macOS 钥匙串、Linux Secret Service，默认）；系统密钥库不可用时，**本地加密文件** `<DataDir>/secrets.enc`（用户设置的主密码派生密钥加密，Argon2id + XChaCha20-Poly1305） |
| S.03-R2 | 图文档、配置文件、扩展包里只存**密钥名**（如 `openai_main`），引用写法 `secret://openai_main`；`ParamDef.secret` 参数只接受密钥名（`C.03.02-R3`） |
| S.03-R3 | 密钥只在模型适配层、http 工具、MCP 客户端**发出请求的那一刻**读取，用完不缓存在执行器、上下文包、事件、检查点里 |
| S.03-R4 | 密钥不进：事件、日志、错误信息、检查点、工作区、导出文件、前端响应、模型上下文（INV-22） |
| S.03-R5 | 前端只显示密钥末 4 位（`sk-…a1b2`）；"查看完整密钥"不提供，用户只能重新输入 |
| S.03-R6 | 模型的图操作工具里没有任何读取密钥的接口；`read_graph` 返回时把 `secret://` 引用替换为 `<密钥>` |
| S.03-R7 | 模型请求和响应写进工作区前脱敏：去掉请求头里的认证信息；正文里匹配到密钥模式的替换为 `[REDACTED]` |
| S.03-R8 | 开发和 CI：允许环境变量 `HARNESS_DEV_SECRET_<名>`，只在 `--dev` 模式生效（`G.11-R3`）；正式模式下即使设置了也忽略并记警告 |
| S.03-R9 | 沙箱、MCP stdio 子进程不继承 `harnessd` 的环境变量；MCP 服务需要的密钥在配置里显式声明，由 Harness 注入 |
| S.03-R10 | 删除提供方时同时删除对应密钥 |

## 2. 验收标准
1. 运行一次完整模板后，在 DataDir 全部文件和数据库里搜索密钥原文，找不到。
2. 日志脱敏测试（`G.12-R7`）通过。
3. 模型被提示"输出你的 API key"时，上下文里没有密钥，输出里也没有。
