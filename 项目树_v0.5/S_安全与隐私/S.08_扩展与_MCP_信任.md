## 1. 扩展包
| 编号 | 规则 |
|---|---|
| S.08-R1 | 扩展包清单必须声明**权限**：要访问的主机名、要用的密钥名、要注册的工具及风险等级、是否包含编程式节点（v1 编程式节点只能编译进程序，扩展包里不允许，`C.03.04-R6`） |
| S.08-R2 | 首次启用扩展包时显示确认框：来源、版本、签名状态、权限清单；用户确认后才注册节点和工具 |
| S.08-R3 | 签名：支持扩展包签名（ed25519）；未签名的包可以安装，但确认框显示"未签名，无法确认作者"（`P.09` Q18） |
| S.08-R4 | 扩展包升级时，如果权限清单变多，再次确认 |
| S.08-R5 | 扩展包里的 SVG 图标经过清洗（去掉脚本、外部引用、事件属性） |
| S.08-R6 | 扩展包不能覆盖内置节点、内置类型、内置资产（`C.13-R3`） |
| S.08-R7 | 扩展节点运行时和内置节点一样经过授权和污染检查；扩展声明的风险等级不能低于 `S.04` §3 的下限 |

## 2. MCP 服务
| 编号 | 规则 |
|---|---|
| S.08-R8 | stdio 服务：首次启用时显示**完整的启动命令和参数**，用户确认后才启动 |
| S.08-R9 | HTTP 服务：只允许 `https`（本机地址例外，需用户在高级设置里允许） |
| S.08-R10 | MCP 工具的返回一律标记污染（`S.05-R1`） |
| S.08-R11 | MCP 工具的风险等级：服务器声明（`annotations` 里的只读、破坏性提示）+ Harness 下限，取更高者；用户可以逐个工具调高 |
| S.08-R12 | MCP 服务的工具列表变化时（新增工具），新工具默认禁用，需要用户在设置里启用 |
