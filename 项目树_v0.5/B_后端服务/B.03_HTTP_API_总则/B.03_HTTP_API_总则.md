## 3. 中间件顺序
```
recover → request_id → 安全响应头（S.02-R8）→ Host 校验 → Origin 校验 → 鉴权 → 请求体大小限制 → 幂等键（POST）→ 处理函数
```
- 路由用标准库 `net/http.ServeMux`（Go 1.22+ 方法与路径模式），不引入路由库（`引01` §5）。
- 普通请求的处理时限 30 秒（`context.WithTimeout`）；SSE 和导入导出不设时限。
- 不对 SSE 压缩、不设写超时（`引15` §3）。
