## 1. v1 做什么
| 领域 | 包含 |
|---|---|
| 形态 | 单个可执行文件 `harnessd`，启动后在浏览器打开本机地址；Windows / macOS / Linux |
| 编排 | 画布编辑；13 个原子节点；子图嵌套与子图引用；模板 |
| 运行 | 数据流调度、并行、循环、人工审批、检查点续跑、fork 重跑、回放 |
| 模型 | OpenAI 兼容（含国内厂商和本地模型）、Anthropic、Gemini |
| 工具 | 检索、HTTP、文件读写、代码执行（沙箱）、MCP 工具、SKILL.md 技能 |
| AI 协作 | 底部对话框背后的编排者：用对话改图、提议 / 幽灵节点、按档位直接生效 |
| 安全 | 五档授权、工具风险等级、审批、污染标记、急停、哈希链审计 |
| 可观测 | 运行时间线、日志、token 与费用统计 |
| 扩展 | 声明式扩展节点（YAML）、编程式扩展节点（Go）、扩展包 |
| 界面语言 | 简体中文 ★（文案全部抽取，预留英文） |

## 2. 明确不做（非目标）
| 不做 | 原因 | 以后可能做吗 |
|---|---|---|
| 多用户、账号体系、权限分组 | v1 是本机单用户产品 | M5 之后再议 |
| 多人实时协同编辑 | 同上；Op 设计已预留 rebase，但不做界面 | 可能 |
| 云端托管、SaaS 版本 | 本地优先；数据留在用户电脑上 | 再议 |
| 把流程发布成对外 API 服务 ★ | v1 聚焦"自己用"；发布涉及鉴权、限流、计费 | 可能 |
| 移动端 / 平板适配 | 画布编排需要大屏和鼠标 | 不做 |
| 内置向量数据库 / 知识库管理 | 用工具或 MCP 接外部服务即可 | 可能做成扩展 |
| 模型训练、微调 | 不是编排的范畴 | 不做 |
| 插件市场（在线商店） ★ | v1 只支持本地安装扩展包 | 可能 |
| 图像、音频生成节点 | 不是核心场景；可用扩展实现 | 做成扩展 |
| 定时任务 / 触发器 ★ | v1 只支持手动运行和对话触发 | 可能（M5 后） |
| 和 ComfyUI / n8n 工作流互相导入 | 语义差异大 | 不做 |

## 3. 边界上的约定
- **Postgres**：接口留好，实现放 M5，v1 默认 SQLite。
- **桌面壳（Wails）**：M5 可选，不影响 v1 主线。
- **Docker 远程执行器**：可选，不是默认沙箱。
- 实施时遇到"顺手就能做"的非目标功能，**也不做**（见 `G.02.05`）。
