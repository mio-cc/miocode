## 1. 图与节点
| 标准名 | 代码名 | 定义 | 界面名 | 不要叫 |
|---|---|---|---|---|
| 图 | `Graph` | 由节点和连线组成的一份可运行文档 | 图 | 工作流、流程图、画布（画布是显示图的界面） |
| 根图 | `root` | 会话里打开的最外层图 | 根图 | 主图、顶层图 |
| 画布 | `Canvas` | 显示和编辑图的界面区域 | 画布 | 图（界面区域不叫图） |
| 节点 | `Node` | 图里的一块积木，是某个节点类型的一个实例 | 节点 | 积木（"积木"只用于产品介绍）、块、组件 |
| 节点类型 | `NodeDef` / `type` | 定义一类节点的端口、参数和执行器 | 节点类型 | 节点种类、模板 |
| 原子节点 | `atomic` | 内置的 13 种基础节点类型（INV-01） | — | 基础组件、内置组件 |
| 扩展节点 | `extension node` | 由扩展包注册的节点类型 | — | 插件节点、自定义组件 |
| 端口 | `Port` | 节点上的输入或输出接口 | 端口 | 插槽、接口、引脚 |
| 端口类型 | `PortType` | 端口能传的数据种类，8 类之一（见 `C.04.01`） | — | 数据类型 |
| 连线 | `Edge` | 从一个输出端口到一个输入端口的连接 | 连线 | 边（只在代码里用 edge）、链接 |
| 参数 | `params` | 节点上可以配置的值 | 参数 | 属性（"属性"是右栏面板名）、设置 |
| 端口提升 | `promoted` | 把子图内部的参数或端口提升到子图节点外面显示 | 提升到外层 | 暴露、导出 |
| 子图 | `Subgraph` / `children` | 包在一个容器节点里的完整图；对外表现为一块积木 | 子图 | 子系统、子流程、组、嵌套图 |
| 容器节点 | `container` | 带子图的节点：循环、子图引用，以及编组生成的节点 | — | 父节点、组节点 |
| 子图端口 | `子图端口` / `subport` | 子图里的边界节点，角色为入口 / 出口 / 摘要 / 升级 | — | 端口节点、IO 节点 |
| 子图引用 | `子图引用` / `subref` | 引用一份已封装、带版本的子图 | — | 子流程调用、组件引用 |
| 摘要端口 | `summary` | 子图向外报告进度和结论的端口 | — | 状态端口 |
| 升级端口 | `escalation` | 子图遇到处理不了的情况时，向外层求助的端口 | — | 异常端口、错误端口 |
| 编组 | `group` | 把选中的节点打包成一个子图 | 打包为子图 | 合并、成组 |
| 解组 | `ungroup` | 把子图展开回当前层 | 解散子图 | 拆分 |
| 嵌套 | `nesting` | 子图里再有子图的结构 | 嵌套 | 层级（"层级"只指 z-index） |
| 层 | `level` / `stack` | 当前正在查看的那一级图 | 层 | 级、页 |

## 3. 运行
| 标准名 | 代码名 | 定义 | 不要叫 |
|---|---|---|---|
| 运行 | `Run` | 对一份图快照的一次执行 | 执行（"执行"指单个节点）、任务、作业 |
| 图快照 | `graph_version` | 运行开始时冻结的那份图 | 版本快照、副本 |
| 节点执行 | `attempt` | 节点在一次运行里的一次执行，可能重试多次 | 任务、步骤 |
| 执行器 | `Executor` | 实现某个节点类型运行逻辑的代码 | 处理器、handler |
| 调度器 | `sched` | 决定哪个节点什么时候执行 | 引擎（"引擎"指整个内核） |
| 就绪 | `ready` | 节点的必填输入都到齐，可以执行 | 可运行 |
| 资源池 | `pool` | 某类资源（某个模型、某个工具）的并发配额 | 队列、线程池 |
| 作用域 | `scope` | 循环的一轮、扇出的一份、子图的一次进入 | 上下文（"上下文"另有含义） |
| 安全点 | `safepoint` | 作用域边界；运行中的改图只在这里生效 | 断点、同步点 |
| 检查点 | `checkpoint` | 在安全点保存的运行状态，用于续跑 | 存档、快照 |
| 续跑 | `resume` | 从检查点继续一次中断的运行 | 恢复运行、重跑 |
| 分叉 | `fork` | 从某个检查点开出一次新运行 | 分支（"分支"是节点类型）、复制运行 |
| 回放 | `replay` | 按事件日志重现一次运行，不调用模型 | 重放、录像 |
| 轮次 | `round` | 循环节点的第几次迭代 | 迭代次数、回合 |
| 份 | `item` / `shard` | 扇出产生的第几份并行执行 | 分片、副本 |
| 运行路径 | `path` | 嵌套 + 轮次 + 份号组成的定位，如 `根图/闭环迭代#r2/执行池/执行者#3` | 节点 ID（路径不是 ID） |
| 差距报告 | `gap report` | 验收不通过时写给下一轮的说明 | 失败原因、反馈 |
| 运行时展开 | `expansion` | 运行中由模型生成并插入的子图 | 动态节点 |

## 4. 修改与协作
| 标准名 | 代码名 | 定义 | 不要叫 |
|---|---|---|---|
| 操作 | `Op` | 修改图的唯一方式；每个操作都有逆操作 | 命令、动作、变更 |
| 逆操作 | `inverse` | 撤销一个操作所需的操作 | 回滚操作 |
| 操作者 | `actor` | 发起操作或事件的一方：`user` / `model` / `runtime` / `external` | 用户（`user` 只是其中一种）、主体（"主体"是授权里的 Principal） |
| 事件 | `Event` | 追加写入、不可修改的一条状态记录 | 日志（"日志"是 slog 的输出）、消息 |
| 事件日志 | `run_events` | 事件的有序集合；运行状态的唯一来源 | 流水、记录 |
| 草稿 | `draft` | 尚未提交的一组修改 | 临时版本 |
| GraphPatch | `GraphPatch` | 模型提交的一组操作 | 补丁包、diff |
| 提议 | `proposal` | 低档位下模型提交、等待人采纳的 GraphPatch | 建议、推荐 |
| 幽灵节点 | `ghost` | 提议里新增、尚未采纳的节点，半透明显示 | 预览节点、虚拟节点 |
| 采纳 / 拒绝 | `accept` / `reject` | 对提议的两种处理 | 同意 / 驳回（"驳回"用于审批） |
| AI 角标 | `ai` | 节点上标明"由模型改过"的标记 | AI 标签 |

## 6. 授权与安全
| 标准名 | 代码名 | 定义 | 不要叫 |
|---|---|---|---|
| 档位 | `Level` | 模型能改多少：0 只读 / 1 建议 / 2 部分 / 3 高度 / 4 完全 | 权限级别、自动化等级 |
| 授权书 | `Mandate` | 挂在会话、图、子图或节点上的授权文档，向下继承 | 权限配置、策略 |
| 判定 | `Decision` | `authz.Check` 的结果：允许 / 需审批 / 拒绝 | 鉴权结果 |
| 审批 | `approval` | 等待人批准或驳回的一次请求 | 确认、同意 |
| 批准 / 驳回 | `approve` / `deny` | 对审批的两种处理 | 同意 / 拒绝（"拒绝"用于提议） |
| 污染标记 | `taint` | 标明操作由外部内容引出 | 风险标记、可疑标记 |
| 急停 | `estop` | 立刻停止所有运行并把档位降到 0；只有人能解除 | 紧急停止按钮、熔断、kill |
| 审计日志 | `audit` | 记录所有授权判定的哈希链日志 | 操作日志 |

## 8. 契约层新增（C 批次）
| 标准名 | 代码名 | 定义 | 不要叫 |
|---|---|---|---|

| 业务类型 | — | 模板和扩展包定义的数据类型，如方案、任务卡 | 自定义类型 |
| 类型变量 | `$T` | NodeDef 端口上待推断的类型 | 泛型参数 |

| 参数锁 | `ParamDef.lock` | `def`（由节点类型定义）/ `kernel`（由内核规则决定） | 固定参数 |

| 编程式节点 | `impl.type: builtin` + `entry` | 用 Go 实现、编译进程序的扩展节点 | 代码节点、脚本节点 |
| 临时 ID | `tmp:N` | GraphPatch 里新增元素的占位 ID，应用时换成 ULID | 假 ID、草稿 ID |
| 判定结果 | `allow` / `propose` / `ask` / `deny` | 授权判定的四种结果；界面名：允许 / 提议 / 需审核 / 拒绝 | 权限结果 |
| 一次节点执行 | — | 节点在某个迭代位置的一次执行，由 node_id + 各层迭代号唯一确定 | 节点实例（"节点实例"指图里的节点） |
| 卡片块 | `MessageBlock` | 消息里的卡片：提议、已修改、审批、运行、看这里、错误 | 附件、富文本块 |
| 选中附带 | `Selection` | 发消息时自动附带的画布选中和当前层 | 上下文选择 |
| 演示模式 | `--fake-llm` | 没有配置模型时，用示例数据跑通模板 | 试用模式、离线模式 |
| 提议栏 | `proposal bar` | 对话框上方显示"模型提议 N 处修改"的条 | 建议栏 |
| 档位胶囊 | `level pill` | 顶部条上显示当前档位的 5 格刻度 | 权限按钮 |
| 标记色 | `ui.color` | 用户给节点、便签设置的分组颜色，不表达系统含义 | 标签色、节点颜色 |
| 类型图例 | `type legend` | 显示 8 个显示类别颜色和名称的说明 | 颜色说明 |
| 列表视图 | `list view` | 用列表代替画布查看和编辑当前层节点（可访问性替代） | 表格模式 |
| 信任来源 | `trust source` | 用户在审批时声明信任某个外部来源，本次运行内不再因它触发污染审核 | 白名单来源 |
| 以后都允许 | `scope: always` | 审批时允许这一个工具在这一层以后不再询问 | 永久批准、总是允许 |
| 急停横幅 | `estop banner` | 急停后顶部条下方的提示条，带"解除急停" | 警告栏 |
