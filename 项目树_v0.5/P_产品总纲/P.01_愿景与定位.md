## 1. 一句话
**Anywhere Door 是一个装在自己电脑上的"多 Agent 积木编排台"：像搭积木一样，把模型、工具、上下文、审批这些小积木拼成一个能自己跑、能自己迭代的 AI 工作系统；这些积木既可以人来拼，也可以让 AI 帮你拼。**

## 2. 要解决的问题
| 现状的痛点 | Anywhere Door 的做法 |
|---|---|
| 多 Agent 系统写在代码里，非程序员看不懂、改不动 | 画布上可视化搭建，每个积木做什么一目了然 |
| 现成的工作流工具大多是"一条线跑到底"，很难表达"做不好就再来一轮" | 循环是一等积木，带轮次、停止条件、差距报告 |
| AI 自己改流程时不可控，不知道它改了什么 | 模型和人用同一套"操作"（Op）改图，每一步都留痕、可撤销、受授权档位限制 |
| 跑到一半出错只能从头再来 | 事件日志 + 检查点，任意位置续跑、分叉重跑 |
| 系统一复杂就乱成一团 | 积木可以打包成子图，子图对外还是一块积木，可以无限嵌套 |
| 工具调用有风险（删文件、发邮件、花钱） | 五档授权 + 工具风险等级 + 人工审批 + 急停 |

## 3. 和同类产品的区别
> 下表只说定位差异，不评价好坏。详细参考见 `P.10`。

| 产品 | 它擅长 | Anywhere Door 不同在哪 |
|---|---|---|
| ComfyUI | 节点式图像生成流水线 | Anywhere Door 面向多 Agent 协作，循环、审批、授权、模型改图是核心 |
| n8n | 业务系统之间的自动化集成 | Anywhere Door 的核心是 Agent 之间怎么分工、怎么迭代，不是连接 SaaS |
| Dify | 快速搭 AI 应用、发布成服务 | Anywhere Door 本机运行，强调可审计、可回放、可嵌套组合 |
| LangGraph | 开发者用代码写状态图 | Anywhere Door 面向画布和对话，非程序员也能用；内核同样有检查点和回放 |
| Rivet | 可视化提示词图、可嵌入 | Anywhere Door 增加了授权、审批、事件溯源和"模型作为操作者" |

## 4. 产品气质
- **透明**：任何时候都能看到系统在做什么、为什么、花了多少。
- **可控**：AI 能做多少由人决定，随时可以停下。
- **可组合**：小积木拼成大积木，大积木还能继续拼。
- **安静**：界面克制，不抢注意力（视觉规范见 `U.01`）。

## 5. 成功标准（v1）
1. 一个不写代码的用户，第一次打开后 10 分钟内，能用模板跑通一次"闭环迭代"并看懂每一步发生了什么。
2. 用户只通过对话，就能让编排者在图上加一个审批节点；改动可见、可撤销。
3. 运行中途关掉程序，重新打开后能从断点继续，结果和不中断时一致。
4. 任意一次运行都能完整回放，回放过程不再调用模型、不再产生费用。
