## 1. 总览
| 里程碑 | 主题 | 一句话 |
|---|---|---|
| M0 | 地基 | 契约、代码生成、仓库骨架、能打出一个空的单二进制 |
| M1 | 最小闭环 | 能在画布上搭一张简单的图并真实跑起来 |
| M2 | 完整节点集 | 13 个原子节点全部可用，能续跑、能分叉，ComfyUI 这类多步 / 异步 API 能接 |
| M3 | 授权与安全 | 五档授权、审批、污染防护、急停、审计全部到位 |
| M4 | 模型编排 | 用对话改图，提议与幽灵节点，设置页 |
| M5 | 观测与打磨 | 时间线回放、成本、性能、安装包、首次引导 |
