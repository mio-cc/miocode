| 最后修改 | 2026-11-23 |

## 1. 目的
所有和模型打交道的代码（适配器、执行器、编排者、对话 Agent、模板）都要能测，但测试不能花钱、不能联网、结果必须每次相同。做不到这一点，要么测试不跑，要么 CI 账单和偶发失败一起失控。

## 2. 适用范围
`engine/llm/**`、`engine/exec/**`、`engine/orch/**`、`internal/app/**` 中调用模型的代码及其测试；内置模板的录放数据；前端端到端测试使用的 `--fake-llm`。

## 3. 规则

### 3.1 不调真模型
| 编号 | 规则 |
|---|---|
| Q.06-R1 | 任何测试都不调用真实模型 API（`G.02.05-R35`）；CI 不配置任何模型密钥（`O-R4`），这是最后一道保险 |
| Q.06-R2 | 测试二进制里（`testing.Testing()` 为真）三家适配器的 HTTP 传输层拒绝连接 `127.0.0.1` 以外的地址，返回明确的错误"测试中不允许调用真实模型"；只有带 `-record` 标志录制时放开（`E.10.08`，`P.09` K191） |

### 3.2 三种替身，各用在哪
| 替身 | 是什么 | 用在 |
|---|---|---|
| fake 脚本 | `fake.New(script)`：按顺序或按请求内容返回预先写好的回复，可以模拟坏 JSON、429、超时、工具调用、延迟（配合虚拟时钟）（`E.10.08`） | 执行器、编排者、对话 Agent 的单元测试；要断言"模型收到了什么"时用它记录的请求 |
| 录放 | `cassette.Replay(dir)`：按规范化请求的哈希回放真实录下的响应，找不到就报错（`E.10.08` §5、§7） | 三家适配器的契约测试（`E.10-R3`）；内置模板的整图运行；和真实厂商格式有关的测试 |
| 演示模式 | `anydoor --fake-llm`：fake 提供方设为默认，按模板名加载模板自带的录放（`B.02` §5、`E.10.08` §5） | 前端端到端测试（`W.12` §6.5）、首次引导的演示模式（`U.18-R5`） |

| 编号 | 规则 |
|---|---|
| Q.06-R3 | 每个调用模型的执行器至少用 fake 脚本覆盖：正常的结构化输出；坏 JSON 修复成功；修复失败后重试；429 退避重试；超时；多轮工具调用；输出不符合 schema 走升级端口；被取消。具体用例写在各执行器叶子的实施卡里（`E.14.*`） |
| Q.06-R4 | 三家适配器共用一套契约测试（结构化输出、工具循环、流式拼接、usage 映射、错误映射），全部用录放跑（`E.10-R3`）；同一组用例三家各有一份录放 |

### 3.3 录放数据
| 编号 | 规则 |
|---|---|
| Q.06-R5 | 存放（`G.03-R5`）：适配器契约测试的录放放 `engine/llm/<厂商>/testdata/cassettes/`；多个包共用的（编排者、对话 Agent）放仓库根 `testdata/cassettes/<套件>/`；内置模板自带的放 `templates/<名>/fixtures/`（`C.13.04`） |
| Q.06-R6 | 脱敏：写入时去掉认证头、正文里匹配到密钥模式的替换为 `[REDACTED]`（`S.03-R7`）；录制只用合成的输入，不用真实用户的数据；CI 的 `gitleaks` 扫描覆盖这些目录（`O.02` `security`） |
| Q.06-R7 | 录制只在开发者本机进行：`go test ./engine/llm/... -record`（`E.10.08` §5）；密钥按 `G.11-R3` 用 `ANYDOOR_DEV_SECRET_<名>` 提供，只在本机有效 |
| Q.06-R8 | 提示词或请求结构改了，导致回放找不到记录时：重新录制，把录放的变化随代码一起提交，在合并请求里写明为什么变；不允许为了让测试通过而改回放的匹配规则 |
| Q.06-R9 | 每个内置模板带一套能完整跑完的录放；CI 在演示模式下把每个模板跑完一次（`U.18-R5`、`E1008-T3`） |

### 3.4 与评测的边界
| 编号 | 规则 |
|---|---|
| Q.06-R10 | 要真实调用模型的只有评测（`Q.07`）：不在合并门禁里，按需或每晚在单独的环境里运行，有预算上限。评测用的密钥不放进代码仓库的 CI |

## 4. 检查方式
- 自动：`O.02` 的 `go-test` 在没有任何密钥、并有 Q.06-R2 守卫的环境里运行，任何真实调用都会失败；`security` 任务扫描录放目录里的密钥。
- 评审：新增的模型相关测试用的是哪种替身、是否符合 §3.2；录放变化是否有说明（R8）。

## 5. 例外
无例外。
