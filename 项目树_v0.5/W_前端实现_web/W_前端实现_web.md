## 1. 这一枝管什么
浏览器里运行的整个前端应用 `web/`：应用外壳与路由、状态层、和后端通信的协议层、前端 Op 层、自研的命令式画布引擎、画布以外的面板、基础组件、整页界面（中心窗口、首次引导、运行历史）、文案与格式化、性能实现、前端测试。

前端是 `harnessd` 的一个静态产物：Vite 构建出 `web/dist/`，由 `cmd/harnessd` 用 `go:embed` 打进单个可执行文件（ADR-003、ADR-004）。没有 SSR、没有 BFF，所有数据都来自本机 `/api/v1` 和三条 SSE 流。

**这一枝说"代码怎么写"；界面"长什么样、怎么交互"以 `U` 为准。** 两者冲突时以 `U` 为准；`U` 和 demo 冲突时以 `U` 为准并修改 demo（`U-R3`）。

## 4. 整枝共同约束
- **W-R1** 画布引擎 `web/src/canvas/core/` 是纯 TypeScript，不 import React、react-dom、任何 `use*` hook（`G.06-R3`、`G.02.05-R24`）。
- **W-R2** 平移、缩放、拖动、运行状态这类高频变化不进 React：由画布引擎订阅 store 后直接写 DOM，React 提交次数为 0（`G.06.02-R4`、`U.17-R10`）。
- **W-R3** 修改图只能调用 `dispatch(op)`（`W.05`）。组件、画布引擎、协议层都不能直接改 graph store 里的图数据（INV-08）。
- **W-R4** 授权以后端为准（INV-09）。前端的预检只用来提前给提示（拖线变红、按钮置灰）；后端返回"需审批 / 拒绝"时照后端处理，前端不自行放行。
- **W-R5** 浏览器发出的所有请求，操作者都是 `user`（`B-R2`）。前端不构造、不转发任何"模型 / 运行时"身份；模型的修改只通过事件流到达前端。
- **W-R6** 急停只能由用户在界面上明确点击解除（INV-10）。任何代码路径（重连恢复、撤销、批量操作、快捷键宏）都不能自动调用解除接口。
- **W-R7** 协议数据结构、事件名、Op 种类、错误码只用 `lib/protocol/generated/` 里生成的类型和常量（INV-17、`G.02.05-R1`–`R3`、`W.04.04`）。
- **W-R8** 颜色、尺寸、间距、圆角、阴影、动效时长、z-index 只用 `--hx-*` 令牌（INV-20、`G.06.03`）；画布引擎通过 JS 写样式时也只写令牌引用或几何值。
- **W-R9** 界面文案一律从 `lib/i18n` 取，用词以 `P.06` 为准（"子图"，不叫"子系统 / 嵌套系统"），`G.06-R4`、`U.15`。
- **W-R10** 密钥明文不进前端（INV-22）：前端只显示后端给的末 4 位；输入密钥的表单提交后立即清空，不存任何 store 或 localStorage。
- **W-R11** 每个画布实例有自己的一组 store（主画布、运行回放、子图库预览可以同时存在；预览浮层和父图位置卡是主画布引擎里的 canvas 简化图，不是画布实例，`P.09` K103），由工厂函数创建、Context 提供，不用全局单例（`G.06.02-R2`）。
- **W-R12** 只能使用 `G.10` §3.3、§3.4 登记的前端依赖（`G.02.05-R28`）。
- **W-R13** 时间从后端拿到的都是 UTC，只在展示时按本地时区格式化（INV-23、`W.10`）；ID 一律是 ULID：前端新建的节点、连线、便签和 Op 直接用 `newUlid()` 生成，提交成功后不换（`C.05.01` §3、`W.05`）；前端不使用临时 ID `tmp:N`，它只出现在模型的提议里，由服务端换成 ULID（`C.08`，`P.09` K177）。
- **W-R14** 每处由模型产生的修改、消息、提议在界面上都要能区分出来（AI 角标、模型色、操作历史里的操作者），数据来自事件里的 `actor`（INV-24、`U.12`）。

## 6. 本枝术语
本枝特有、已在 `P.06` §10 登记的名字（定义以 `P.06` 为准，这里只是摘录）：
| 名字 | 含义 |
|---|---|
| 画布引擎 `CanvasEngine` | `canvas/core` 里的命令式渲染与交互对象，一个画布实例一个 |
| 会话工作区 `SessionWorkspace` | 一个会话对应的一整套前端 store，切换会话时整体切换（`W.03`、`U.09.04`） |
| 运行桥 `RunBridge` | 把运行流的高频事件按帧合并后交给画布引擎（`W.06.15`） |
| 中心窗口 | `Ctrl+,` 打开的包 / 连接 / 资源库 / 设置窗口（`U.21`） |
| 浮动回复 | 对话框上方最近一条回复，可收拢到回复标签（`U.09.06-R4`） |
