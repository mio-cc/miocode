## 1. 这一枝管什么
前端、后端、内核三方共用的**全部数据格式**：图文档、节点定义、端口类型、操作（Op）、事件、运行状态机、GraphPatch、授权书、会话与消息、错误码、版本迁移、内置资产格式、代码生成映射。

**这一枝是数据格式的唯一事实来源（INV-17）。** 其他分支只能引用这里的定义，不能另写一份；需要新字段时，先改这里。

## 4. 整枝共同约束
- **C-R1** 每个数据结构只在一份 C 文档里定义正文；其他 C 文档引用它时写 `$ref` 和文档编号。
- **C-R2** C 文档里的 JSON Schema 片段就是 `schema/` 目录下文件的设计稿。两者不一致时以 C 文档为准，并修正 `schema/` 文件。
- **C-R3** 实施时不得修改本枝（`G.02-R2`）。修改流程见 `C.01` §5。
- **C-R4** 本枝所有命名遵守 `C.01` §3 的通用约定。

## 5. 本批次做出的决定
写契约层时，我把旧文档里互相冲突或没定的地方逐一定了下来。每一条都在对应文档里写明，并登记到 `P.09` 第 2 节：

| 决定 | 在哪 |
|---|---|
| 操作者统一为 `user / model / runtime / external` 四种；授权里不再单独有 `node` 主体 | `C.01` §4、`C.09` |
| 运行状态统一为 6 种：`pending running paused done failed cancelled` | `C.07` |
| 扇出必须带子图（body），每一份都是一次子图执行 | `C.02.04` |
| 嵌套层数：根图为第 0 层，超过 4 层给警告，超过 8 层报错 | `C.02.04` |
| 视口位置不再写进图文档，属于界面状态 | `C.02.05` |
| 节点实例锁改为 `none / user / frozen` | `C.03.03` |
| 声明式节点在冻结运行快照时展开成原子节点组成的子图，保证"只有 Agent 调模型"（INV-05） | `C.03.04` |
| 端口显示类别可以和数据类型分开声明：分支、人工的出口传递数据，但按"判定"类别显示 | `C.04.01` |
| 图结构修改需要审核时一律变成提议；运行时动作需要审核时变成审批 | `C.08`、`C.09` |
| 金额统一用整数 `*_micros`（百万分之一货币单位），时长统一用整数 `*_ms` | `C.01` §3 |
