## 1. 这一组管什么
Op 是**修改图的唯一方式**（INV-08）。人在画布上的每一次操作、模型提交的补丁、导入文件、版本迁移，最后都变成 Op，走同一条流水线：

```
结构校验 → 版本检查（必要时 rebase） → 授权检查 → 在副本上应用 → 增量图检查 → 写 Op 日志和新版本 → 广播 op.applied
```
流水线的实现在 `E.05.01`；本组只定义数据格式和语义。

## 3. 共同约束
- **C.05-R1** 逆操作由**服务器在应用时计算并保存**。客户端提交的 `from` 一类字段只用于冲突检测，不被信任。
- **C.05-R2** 复合 Op（`group`、`ungroup`、`apply_patch`、`import_apply`、`merge_branch`、`revert_to`）要么整个成功，要么整个失败。
- **C.05-R3** 一次用户动作或一个 GraphPatch 产生的多条 Op 共享同一个 `group_id`，撤销时一起撤销。
