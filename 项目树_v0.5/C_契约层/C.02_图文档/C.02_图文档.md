## 1. 这一组管什么
图文档 `graph.schema.json`：一张图存成什么样。图文档是**纯数据**：不含运行状态（运行状态在事件日志里，INV-11），不含密钥，不含视口位置。

## 2. 下级清单
| 编号 | 名称 | 定义 |
|---|---|---|
| C.02.01 | Graph 顶层结构 | `Graph` |
| C.02.02 | Node 节点 | `Node` |
| C.02.03 | Edge 连线 | `Edge`、`PortRef` |
| C.02.04 | 子图与嵌套 | `Subgraph`、`SubgraphRef`、容器规则、层数上限 |
| C.02.05 | 视图元数据 | `pos`、`ui`、`notes` |

## 3. 共同约束
- **C.02-R1** 节点 ID 在**整棵图树内唯一**（包括所有子图），这样 Op、事件、授权都能只用节点 ID 定位节点。
- **C.02-R2** 连线只能连接同一个子图里的两个节点；跨层传数据只能通过子图端口节点（INV-03）。
- **C.02-R3** 节点上不存端口列表。一个节点的端口 = NodeDef 声明的端口 + 被提升的参数 + 动态插口（由连线反推）。
- **C.02-R4** 图文档的每次修改都通过 Op（INV-08），每应用一个 Op，`version` 加 1（连续拖动合并的情况除外，见 `C.05.04`）。
