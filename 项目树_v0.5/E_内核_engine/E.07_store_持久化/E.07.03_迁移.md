## 1. 职责
规定数据库迁移的写法和执行方式。

## 2. 不做什么
- 不定义表结构（`E.07.02`）

## 3. 继承的上级约束
`G.04.03`（迁移文件命名）、`C.12` §3.4。

## 4. 接口
- 迁移文件：`engine/store/sqlite/migrations/NNNN_描述.sql`，goose 格式（`-- +goose Up` / `-- +goose Down`），用 `embed.FS` 打进二进制。
- 版本表：`hx_goose_db_version`。
```go
func Migrate(ctx context.Context, db *sql.DB) error   // 启动时调用：Up 到最新
```

## 5. 行为
- **只向前**：Down 段必须写（开发用），但产品里不执行降级；旧版本程序遇到更新的库：拒绝启动并提示升级（`C.01-R20`）。
- 每个迁移在事务里执行；大表变更（加列除外）先建新表、复制、改名。
- SQL 只用 SQLite 与 Postgres 都支持的语法（`引04` §10）。
- 启动迁移前自动备份数据库文件为 `anydoor.db.bak-<旧版本>`，保留最近 3 份（`O.07`）。

## 6. 不变量
- 迁移可重复执行（幂等）
- 迁移失败数据库回到迁移前状态

## 7. 错误处理
迁移失败：`anydoor` 启动失败，日志写明哪个迁移、哪条语句，提示从备份恢复。

## 8. 验收标准
1. 空库迁移到最新
2. 从每个历史版本迁移到最新（迁移链测试）
3. 更新的库被旧程序拒绝
