## 1. 职责
提供完全在内存里的 `Store` 实现，供内核测试和 `--fake-llm` 演示之外的单元测试使用。

## 2. 不做什么
- 不用于产品运行

## 3. 继承的上级约束
`E.07-R3`、`E-R5`。

## 4. 接口
```go
func New() store.Store   // engine/store/memstore
```

## 5. 行为
- 用 map + 一把 `sync.Mutex` 实现，`Tx` 通过复制修改集合实现回滚（简单优先，不追求性能）。
- 行为必须与 SQLite 实现在契约测试下完全一致（包括错误类型、分页顺序、seq 分配）。

## 6. 不变量
- 与 SQLite 实现通过同一套契约测试

## 7. 错误处理
与 SQLite 实现相同。

## 8. 验收标准
1. `storetest.Run(t, memstore.New)` 全部通过
