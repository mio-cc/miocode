## 1. 职责
循环节点：**唯一能形成环的节点**（INV-06）。环在它的子图内部：每一轮执行一次子图，上一轮的出口值经过筛选后成为下一轮的入口值。两种驱动方式：按轮次（闭环迭代）和按事件（长驻主脑）。

## 2. 端口与参数
| 端口 | 方向 | 类型 |
|---|---|---|
| `init` | 入 | $T |
| `final` | 出 | $T |
| `summary` | 出 | 简报@1 |

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `trigger` | enum：rounds / event | rounds | 内联 |
| `max_rounds` | integer 1–50 | 5 | 内联 |
| `exits` | expr | `achieved == true` | 退出条件 |
| `stall_metric` | expr | — | 无进展检测指标，如 `len(gap.gaps)` |
| `stall_rounds` | integer 1–10 | 2 | 连续几轮没变好就停 |
| `carry_fields` | 列表[string] | 全部 | 带进下一轮的字段 |
| `carry_budget` | number | 0.2 | 轮间携带内容占窗口比例上限 |
| `idle_timeout_ms` | integer | — | event 模式：多久没有事件就结束 |
| `queue` | object | — | event 模式：事件队列策略（优先级、合并键） |

## 4. 共同约束
- **E.14.09-R1** 至少一个有限出口（`max_rounds`、预算、`idle_timeout_ms` 之一），否则 V10；未配置时内核补 `max_rounds=10` 并给 warn（`引03` §5.9）。
- **E.14.09-R2** 每轮开始是**安全点**：运行中改图在这里生效（`E.16.02`，INV-12）。
- **E.14.09-R3** 每轮结束写检查点（含轮次、携带状态、无进展计数）。
