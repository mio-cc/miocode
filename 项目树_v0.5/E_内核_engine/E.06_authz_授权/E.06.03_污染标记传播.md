## 1. 职责
实现污染标记在数据流里的传播：工具结果 → 上下文包 → Agent 输出 → 由它引出的 Op 和工具调用。

## 2. 不做什么
- 不决定污染时的判定（`E.06.02` 第 8 步）

## 3. 继承的上级约束
INV-16、`S.05` §2。

## 4. 接口
```go
func Join(vs ...exec.Value) (taint bool, src []string)      // 多个输入合并：任一污染即污染，来源取并集（去重、最多 20 条）
func Mark(v exec.Value, src string) exec.Value              // 工具结果打标
type TrustList interface { Trusted(src string) bool }        // 本次运行的信任来源
```

## 5. 行为
| 环节 | 规则 | 实现位置 |
|---|---|---|
| 工具结果 | 检索、HTTP、文件读、浏览器、MCP：`Mark(v, 来源)` | `tools.Handle`（`E.11.01`） |
| 上下文装配 | 任一段污染 → 上下文包污染，记录段名和来源 | `E.13.02` |
| Agent | 上下文包污染 → 输出污染；工具调用的参数由污染的上下文生成 → 调用带污染 | `E.14.02` |
| 其他执行器 | 输出污染 = 输入污染的 `Join` | 调度器在节点完成时统一计算 |
| 编排者 | GraphPatch 由污染的上下文生成 → 批次 `Taint=true` | `E.17.01` |
| 账本 | 写入值的污染标记随值保存；读出时保留 | `E.14.10` |

## 6. 不变量
- 污染只累加，不会被执行器清除（`S.05-R4`）
- 不污染的来源（用户输入、图、角色卡、配方、模板）永远不会被标记

## 7. 错误处理
无。

## 8. 验收标准
1. 注入用例：网页内容 → 上下文 → Agent → 工具调用，最终调用带 `taint=true` 和正确来源
2. 用户输入不被标记
