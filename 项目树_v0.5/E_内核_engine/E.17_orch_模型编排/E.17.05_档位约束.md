# E.17.05 档位约束

| 项 | 内容 |
|---|---|
| 编号 | E.17.05 |
| 类型 | 实施 |
| 上级 | E.17 orch 模型编排 |
| 下级 | 无 |
| 状态 | 草稿 |
| 素材 | 引10 |
| 最后修改 | 2026-11-22 |

## 1. 职责
规定编排者在不同档位下能做什么，以及防失控的硬限制。

## 2. 不做什么
- 不重复 `C.09` 判定表的内容（这里只写编排特有的限制）

## 3. 继承的上级约束
`C.09` §5、`S.04-R4`、`R5`、`引10` §8。

## 4. 接口
| 风险 | 限制 | 默认 | 位置 |
|---|---|---|---|
| 图膨胀 | 单个 GraphPatch 最多新增节点数 | 30（内核上限 200） | 授权书 `overrides.max_nodes` |
| 图膨胀 | 一次运行里运行时展开生成的节点总数 | 300 | 运行级计数器 |
| 递归 | 子编排者嵌套深度 | 3（内核上限 8） | 授权书 `overrides.max_depth` |
| 烧钱 | 编排预算（含 `run_subgraph` 试跑） | 从父级划拨 | 预算账户 |
| 原地打转 | 重复补丁（fingerprint） | 同一会话或运行内重复即升级 | `E.17.01` |
| 原地打转 | 运行后优化：连续 N 次评测分数未提升 | 2 次即停 | 优化循环 |
| 自修改 | 修改编排者自身所在层或上层 | 档位 3 及以下需审核，4 档允许 | `orch.self_modify` |
| 自修改 | 修改授予自己的授权书 | 永远拒绝 | `E.06.02` 第 7 步 |
| 内部循环 | 单次编排的工具调用轮数 | 30 | Agent `max_turns` |
| 设计时 | 默认档位 | 1（建议） | 会话授权书（`S.04-R2`） |

## 5. 行为
档位对编排的效果：
| 档位 | 设计时（对话改图） | 运行时展开 |
|---|---|---|
| 0 | 只能读图和回答问题 | 不允许（编排者节点失败） |
| 1 | 只产生提议 | 生成的子图需要审批才能挂载 |
| 2 | `overrides.scope` 内直接生效，删除节点等需审核 | 范围内直接挂载 |
| 3 | 直接生效（`except` 除外）；写草稿分支 | 直接挂载 |
| 4 | 直接生效；可以写 main（授权书 `branch: main`） | 直接挂载 |

## 6. 不变量
- 任何档位都不能突破内核上限

## 7. 错误处理
超限：工具调用返回失败"超过单次修改上限（30 个节点）"，模型可以拆分或申请提权。

## 8. 验收标准
1. 每条限制一个用例
2. 档位表每格一个用例
