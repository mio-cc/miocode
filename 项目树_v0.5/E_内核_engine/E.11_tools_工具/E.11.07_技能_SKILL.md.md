## 1. 职责
支持 SKILL.md 技能：一个目录里放一份说明文档和若干工具声明，加载后成为一组工具和一段可以注入 Agent 提示词的使用说明。

## 2. 不做什么
- 技能不能包含可执行代码（只能引用已注册的工具或声明式 http / mcp 工具）

## 3. 继承的上级约束
`E.11-R1`、`X.07`。

## 4. 接口
目录结构：
```
skills/<名>/
├── SKILL.md        # 头部 YAML：name、description、tools（引用的工具 ID）、risk；正文为使用说明
└── examples/       # 可选：示例输入输出
```
```go
func LoadSkill(fsys fs.FS) (*Skill, error)
type Skill struct { Name, Description, Guide string; Tools []string }
```

## 5. 行为
- 技能注册为 `skill:<名>`，在节点库"工具"分组下显示；拖到画布上是一个工具节点，`endpoint` 输出带上技能里所有工具。
- 连到 Agent 时，技能的 `Guide` 进入提示词第 ④ 段（工具说明，`E.13.05`），按 token 计入预算。
- 技能引用的工具风险取其中最高者。

## 6. 不变量
- 技能不引入新的执行能力

## 7. 错误处理
引用不存在的工具：加载失败并指出行号。

## 8. 验收标准
1. 加载示例技能，Agent 提示词里出现使用说明
2. 引用不存在的工具时报错
