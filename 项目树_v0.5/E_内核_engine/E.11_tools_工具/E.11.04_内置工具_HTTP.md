## 1. 职责
内置 HTTP 工具：受白名单和风险等级约束的任意 HTTP 请求。

## 2. 不做什么
- 不支持 WebSocket、长连接

## 3. 继承的上级约束
`S.04` §3（GET L0 / 其他方法 L2）、`S.06` §2、`S.07`。

## 4. 接口
```go
// builtin:http
type Args struct { Method, URL string; Headers map[string]string; Body json.RawMessage; TimeoutMs int }
```

## 5. 行为
- 风险：GET / HEAD 在白名单内为 L0；其他方法 L2；白名单外一律转审批。
- 拒绝本机和内网地址（解析 DNS 后检查，每次重定向都检查，`S.06` §2）。
- 请求头里的 `{{secret=[REDACTED_PASSWORD] 在发出前替换（只用于声明式 http 扩展注册的工具）；普通 http 工具不允许模型填写认证头。
- 响应限 10MB，超出截断并标记。
- 声明式 http 扩展节点注册的工具复用这个实现，但 URL、方法、头由声明固定，模型只能填参数。

## 6. 不变量
- 任何情况下都不会访问 127.0.0.0/8、内网段（除非用户在高级设置里逐个允许）

## 7. 错误处理
4xx → user_input；5xx、网络 → transient；被拒地址 → auth_denied。

## 8. 验收标准
1. DNS 重绑定到 127.0.0.1 被拒
2. 重定向到内网被拒
3. POST 需要 L2 授权
4. 密钥不出现在 tool.call 事件里
