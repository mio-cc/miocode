## 1. 这一枝管什么
执行引擎 `engine/`：图模型、注册与校验、扩展包、Op、授权、存储、内容存储、可观测、模型适配、工具、MCP、上下文装配、13 个执行器、调度、运行生命周期、模型编排。

`engine/` 是一个**可以被别的 Go 程序 import 的库**：不依赖 HTTP 服务、不依赖产品层，所有外部能力（存储、密钥、时钟、模型、工具）都通过接口注入。

## 4. 整枝共同约束
- **E-R1** 依赖方向和禁止 import 的规则见 `E.01` §2，由 `tools/depcheck` 强制（INV-19）。
- **E-R2** 跨包的核心接口（`Executor`、`RunCtx`、`Store`、`Model`、`Tool`、`Checker`）**只在 `E.01` 定义一次**，其他文档只引用（`P.09` K2）。
- **E-R3** 内核里不使用全局可变状态；所有依赖通过 `engine.Deps` 注入（`G.05.03-R4`）。
- **E-R4** 内核产生的每一个状态变化都先写事件再生效（INV-11、`E.09.01`）。
- **E-R5** 内核所有包必须能在 `memstore` + `llm/fake` + 虚拟时钟下完整测试，不需要网络和磁盘（`Q.04`）。

## 5. 落实的不变量
INV-01–INV-19、INV-22–INV-24（几乎全部；INV-20、21 属于前端和服务层）。
