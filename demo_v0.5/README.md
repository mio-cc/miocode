# demo v0.5 说明

> 最新版本：v0.5.11（2026-11-23）。产物 `画布_demo_v0.5.html`，双击即可打开，也可以在 Quick 里预览。
> 规范以 `../项目树_v0.5/` 为准；本文件只说明 demo 本身。

## 1. 怎么构建
```
python build.py          # 生成压缩版（默认，约 565KB）
python build.py --full   # 生成不压缩版（便于调试，约 620KB）
```
- 模块来源：`../设计规范_v0.3/src/`（基础画布）、`../布局demo_v0.4/src/`（布局）、本目录 `src/`（v0.5 新增和替换）。
- **产物必须 ≤ 600KB**：超过后 Quick 的页面预览会显示空白（v0.5.9、v0.5.10 的"一片白"就是这个原因）。
