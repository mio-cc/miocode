01

速读与原则

整体气质是精密仪器面板，不是营销页。信息靠层级和留白来区分，颜色只用来表达含义。下面七条原则是所有取舍的依据。

#原则落地方式
P1内容是主角，界面退后面板浮在画布上方，不切割画布；工具栏和边框用最低对比度
P2颜色 = 含义一个颜色只表达一种含义，不用颜色做装饰
P3状态一眼可读每种状态同时用颜色、图形和文字表达，不能只靠颜色
P4模型的行为永远可见模型做的事带 --hx-model 标记和理由，并且可以撤销
P5直接操作优先能在节点上改的就不进检查器，能拖的就不用点，常用操作都有快捷键
P6流畅是功能拖拽、缩放、连线保持 60fps，任何操作 100ms 内要有视觉反馈
P7渐进披露缩小时只显示标题，悬停才出类型，选中才出完整参数

禁止清单：错误与正确对比

左边是常见的"AI 味"做法，右边是本规范的做法。左栏用的是裸色值，属于故意违反规范的反例。

错误 · 渐变按钮加彩色投影
渐变和发光投影会抢走画布的注意力，也无法表达任何状态。
正确 · 实色主按钮 + 1px 内高光
橙色只出现在主按钮和运行状态上，所以用户一眼就知道"这里会让东西跑起来"。
错误 · 玻璃拟态卡片
模糊背景上的半透明卡片，文字对比度不稳定。
正确 · 表面层级加一档亮度
检查器
浮起来的东西背景亮一档，阴影用 --hx-shadow-float。
错误 · 彩虹配色 + 全大写标签
NODE LIBRARY
正确 · 中性灰 + 类型色只在端口上
节点库

  • 其他禁止项：emoji 图标；每张卡片都加悬停动画；每个区块都加入场动画；所有元素套同一个圆角和阴影；装饰性图标；同一个颜色表达两种含义。
02

令牌

所有数值都来自 tokens.css，命名统一为 --hx-类别-名称。页面和组件里不允许出现裸色值。点击下面的色块可以复制 var(--token)。

表面层级

每往上浮一层，背景亮一档。层级靠亮度区分，不靠阴影；只有浮动元素才有阴影。

线：line-1 用于内部分区，line-2 用于组件外框，line-3 用于悬停。表面顶部另加 1px 内高光 --hx-highlight。
文字：同一个组件里最多使用两级文字颜色。

语义色

每个颜色只对应一种含义。蓝紫色 --hx-model 是"模型做的事"的专用身份色，其他地方不能使用。

端口类型色

只用于端口和连线。连线颜色等于源端口的类型色。新增数据类型必须归入这 8 类之一，不能再新增颜色。

字体与字号

UI 字体是 Geist，中文回退到 Noto Sans SC 和微软雅黑；数值、类型名、路径和快捷键用 Geist Mono。字号只允许 8 档，界面基准是 13。字重只用 400、500、600，数字统一开启 tabular-nums。

间距、圆角、阴影

间距一律取 4 的倍数。
嵌套圆角：内层圆角 = 外层圆角 − 内边距，最小取 xs。例如节点（lg 10）内边距 5，里面的图标格就用 sm 5。

动效

动画只用于 transform、opacity、stroke-dashoffset 和颜色类属性，禁止对宽、高、位置属性做动画。点「重放」可以看到每种组合的实际效果。开启系统的"减少动态效果"后，所有时长会归零。

/* 选中、状态变化 */
transition: border-color var(--hx-t-2) var(--hx-ease), box-shadow var(--hx-t-2) var(--hx-ease);
/* 面板进入 / 离开 */
.panel.is-open { transition: transform var(--hx-t-3) var(--hx-ease-out); }
.panel         { transition: transform var(--hx-t-2) var(--hx-ease-in); }
03

节点

节点是画布上的基本单元。所有节点结构相同：头部、端口区、内联控件区、状态脚。13 种原子节点只用图标和标题区分，不用颜色区分类别。

结构解剖

  1. 图标格20×20，--hx-bg-5 底，内放 1.5px 线宽的单色 SVG，图标颜色不随类别变化
  2. 头部高 --hx-node-head（38）。标题 14/600；类型行用 mono 10.5；右侧是状态点；整块是拖动热区
  3. 端口行每行高 --hx-node-row（24）。圆点直径 --hx-port，圆心落在边框上，外加 2px 底色描边形成细缝
  4. 内联控件每行高 --hx-node-widget（28），最多 3 行，和检查器双向同步
  5. 状态脚只在运行、失败、挂起时出现；进度条用 scaleX 变化

子图与循环

子图节点右侧和底部各多一道 4px 叠层边，节点内显示内部缩略图。循环节点头部显示轮次环，运行时环形进度随轮次推进。

细节分级（LOD）

画布缩小后要减少细节，否则会糊成一片。分级的切换点写死在规范里。

节点图标

20×20 的视框，1.5px 线宽，圆头线帽，单色 currentColor。图形只取最能代表这个节点职责的那个比喻。点击图标可以复制 SVG 代码。

04

连线

连线是两端切线都保持水平的三次贝塞尔曲线，颜色等于源端口的类型色，线宽 1.75。所有连线放在同一个 SVG 里，运行流动的动画只加在当前活跃的连线上。

控制点公式

控制点水平偏移 off = clamp(|dx| × 0.5, 48, 180)。终点在起点左侧（回连）时，偏移固定为 120，让曲线绕出去。

function edgePath(x1, y1, x2, y2) {
  const dx = x2 - x1;
  const off = dx >= 0 ? Math.min(180, Math.max(48, dx * 0.5)) : 120;
  return `M${x1},${y1} C${x1 + off},${y1} ${x2 - off},${y2} ${x2},${y2}`;
}
// 端口坐标用布局常数计算，不读 DOM：
// y = node.y + HEAD(38) + PAD(4) + rowIndex * ROW(24) + ROW / 2

模型作为操作者

模型和人编辑的是同一张图，所以界面必须让人随时分清"这是谁做的"。模型相关的所有界面元素只使用 --hx-model 这一种颜色。

编辑中的提示与模型光标

模型正在编辑…
AI · 编排者
模型操作时，顶部条显示「模型正在编辑…」，左侧的点持续呼吸。画布上的 AI 光标平滑移动到它正在操作的节点，移动使用 --hx-ease-out，时长 700ms。

1 档：提议栏

模型提议 5 处修改 · 在验收者后加人工审批，执行池并发 3 → 5

2 档及以上：直接修改并闪光

改动立即生效，节点用 600ms 的模型色光环闪一下，并带上 AI 签；通知里提供「撤销」。

授权档位胶囊

放在顶部条右侧，用 5 格刻度表示档位。0–2 档用中性色，3 档用等待色，4 档用强调色。点击胶囊展开授权面板。

急停态

根图 / 闭环迭代 main 运行中 · 第 2/5 轮
急停后顶部条变为危险色底，所有运行中的节点转为取消态，授权档位降到 0。急停开关只属于用户，模型即使拿到 4 档也关不掉。

性能与代码结构

流畅是功能，不是优化项。验收标准：200 个节点、300 条连线时，拖动和缩放保持 60fps。

代码结构约定

state = {
  graph:   { nodes: Map<id, Node>, edges: Map<id, Edge> },   // 数据，唯一事实来源
  view:    { x, y, k },                                      // 视口：平移与缩放
  ui:      { selection: Set<id>, hover, tool, panels },
  run:     { status, nodeStatus: Map<id, Status>, progress },
  history: { past: Op[], future: Op[] },
  actor:   'user' | 'model',
  level:   0..4                                              // 当前授权档位
}

dispatch(op)        // 唯一修改入口：校验 → 授权 → apply → 写入历史 → 增量渲染
  op = { kind, actor, reason?, payload, inverse }

renderView()        // 只改世界容器 transform、网格、小地图视口框
renderNode(id)      // 按 id 复用 DOM，只切换 class 和文字
renderEdges(ids?)   // 只重算指定连线的 path d
// 拖动节点：pointermove 只记录坐标，rAF 里每帧最多处理一次
let pending = null;
el.addEventListener('pointerdown', e => el.setPointerCapture(e.pointerId));
el.addEventListener('pointermove', e => {
  if (!pending) requestAnimationFrame(flush);
  pending = { x: e.clientX, y: e.clientY };
});
function flush() {
  const p = pending; pending = null;
  node.x = toWorldX(p.x); node.y = toWorldY(p.y);
  el.style.transform = `translate3d(${node.x}px, ${node.y}px, 0)`;
  renderEdges(edgesOf(node.id));   // 只更新相关连线
}
