# 11 面板与应用布局

> 版本 v0.3.1 · 默认浅色 · 令牌来源 `tokens.css`
> 规定 harness 的整体布局、画布的三种嵌入形态，以及展开态里每个浮动面板的位置、尺寸和行为。

## 11.1 harness 整体布局

```
┌────────┬───────────────────────────────────────────────┬──────────┐
│ 左侧栏 │                 对话中间栏                     │ 右侧栏   │
│ 232    │   内容最大宽 880，居中                         │ （可选， │
│        │                                               │ harness  │
│ 模式   │   消息 …                                       │ 自有）   │
│ 会话   │   AI 消息里嵌入 [画布卡片]                     │          │
│ 设置   │                                               │          │
│        │   ─────────────────────────────────────────    │          │
│        │   对话输入框（固定在底部）                      │          │
└────────┴───────────────────────────────────────────────┴──────────┘
```

| 区域 | 宽 | 背景 | 说明 |
|---|---|---|---|
| 左侧栏 | 232（可收成 56 的图标栏） | `--hx-bg-0` | harness 自有：运行模式、会话列表 |
| 对话中间栏 | 弹性 | `--hx-bg-0` | 消息列最大宽 880；卡片形态的画布宽 = 消息列宽 |
| 右侧栏 | 0 / 360 | `--hx-bg-2` | harness 自有（文件预览等）；画布展开时自动收起 |

### 与 harness 其他运行模式共存
- 「积木编排」是一种**运行模式**，和「对话」「深度研究」等并列，在左侧栏切换。切换模式**不销毁**画布状态，切回来时恢复视口和选中。
- 在「对话」模式下，模型也可以在回复里插入画布卡片（只读）；用户点「打开」才进入编辑。
- 一个会话可以有多张图，每张图是一个独立文档（`graph_id`），卡片上显示图名。
- 编排模式下的对话输入框就是 harness 原有的输入框，只是上方多一行「画布快捷建议」芯片，并且发送时自动附带当前选中的节点作为上下文。

## 11.2 三种嵌入形态

### 11.2.1 卡片

```
┌───────────────────────────────────────────────────────────┐
│ ▣ 闭环迭代 · 竞品定价调研          ● 运行中 2/5 轮   [打开]│ ← 头部 44
├───────────────────────────────────────────────────────────┤
│                                                           │
│         只读缩略画布（自动适应视图，LOD 随缩放）           │ ← 高 360
│                                                           │
├───────────────────────────────────────────────────────────┤
│ 14 节点 · 19 连线 · 用时 1:24 · 82k tokens    当前：执行池 │ ← 状态行 36
└───────────────────────────────────────────────────────────┘
```

| 项 | 规格 |
|---|---|
| 尺寸 | 宽 = 消息列宽（最大 880），总高 440 |
| 外观 | 背景 `--hx-bg-1`，外框 1px `--hx-line-2`，圆角 `--hx-r-xl`，`--hx-shadow-node` |
| 显示内容 | 图名、运行状态徽标、缩略画布（状态色实时更新，连线流动保留）、状态行 |
| 允许的交互 | 滚轮**不**缩放（交给消息列滚动）；悬停节点显示名称与状态；单击节点 = 打开画布并聚焦该节点；审批按钮可直接点；「打开」按钮 |
| 不允许 | 拖动、连线、改参数、删除 |
| 多张卡片 | 同一张图在会话里出现多次时，只有**最新**那张是实时的，旧卡片变成快照并标「历史版本 v3」；不同的图互不影响。最多同时 3 张卡片保持实时渲染，滚出视口的卡片暂停渲染（IntersectionObserver） |
| 性能 | 简化渲染：节点只画头部，不画内联控件，不挂交互监听 |

### 11.2.2 展开

占满对话中间栏，**对话输入框保留在底部**，消息列暂时隐藏。顶部条的「对话」按钮可以拉出一个右侧 360 宽的对话侧板，查看历史消息。

**FLIP 过渡步骤**（时长 `--hx-t-4`，曲线 `--hx-ease-out`）：
1. **First**：记录卡片画布区域的 `getBoundingClientRect()`（整个过程中唯一允许读布局的时机），以及当前视口 `{x,y,k}`。
2. **Last**：把画布容器挂到展开态位置（中间栏全区），按最终尺寸完成布局，记录最终矩形。
3. **Invert**：给容器设置 `transform: translate(dx,dy) scale(sx,sy)`，`transform-origin: 0 0`，让它在视觉上回到卡片的位置。
4. **Play**：下一帧移除 transform，开启过渡。同时消息列 `opacity 1→0`（`--hx-t-2`）；过渡结束后浮动面板依次淡入（节点库、检查器、停靠栏各延迟 40ms）。
5. **视角衔接**：过渡期间画布内容保持卡片里的视觉位置；结束后再做一次视图过渡，调整到「适应视图」，或用户点击的那个节点。
6. **退回卡片**（`Esc` 或顶部条「收起」）：按相反顺序执行；收起前把当前视口写回卡片。

**上下文衔接**：
- 展开时对话里自动插入一条系统小记「已打开画布：闭环迭代」；收起时插入「画布修改 6 处（查看）」。
- 展开态在输入框里发送的内容照常进入会话历史；模型的回复以小气泡浮在输入框上方（最多 2 条，展开对话侧板可看全部）。

### 11.2.3 全屏
- 按 `F` 键或顶部条按钮进入；覆盖整个应用（包括左侧栏），对话输入框仍在底部，可用 `⌘/Ctrl+J` 收起。
- 浏览器 Fullscreen API 是可选的；默认只做应用内全屏（`position: fixed; inset: 0`）。
- `Esc` 退回展开态；如果有弹层打开，第一次 `Esc` 先关闭弹层。

## 11.3 展开态浮层布局

```
┌───────────────────────────────────────────────────────────────────┐
│ ① 顶部条  根图 / 闭环迭代 ▾ · ⎇ main  │ ▮▮▮▯▯ 2档 · ● 运行中 · ▶ · ■ │ 48
├──────────────────────────────────────────────────────────────────┤
│┌────────┐                                         ┌──────────────┐│
││②节点库  │      ⑨通知区（右上，检查器左侧）          │ ④ 检查器     ││
││ 260     │                                         │ 320          ││
││         │                画布                      │              ││
│└────────┘         ⑧提议栏（停靠栏上方）              │              ││
│┌──────┐┌───┐      ┌──── ③停靠栏 ────┐               └──────────────┘│
││⑥小地图││⑦缩放│      └─────────────────┘                              │
│└──────┘└───┘                                                        │
├──────────────────────────────────────────────────────────────────┤
│ ⑤ 运行抽屉（时间线 · 日志 · 操作历史）                             │ 0–40%
├──────────────────────────────────────────────────────────────────┤
│ 对话输入框                                                         │
└──────────────────────────────────────────────────────────────────┘
```

浮动面板（②④⑥⑦③⑧）的通用规则：
- 距画布边缘 12px；背景 `--hx-bg-2`；`--hx-shadow-float`；圆角 `--hx-r-lg`（停靠栏用 `--hx-r-xl`）。
- **事件隔离**：面板根元素上的 `wheel`、`pointerdown` 调用 `stopPropagation()`。所以在面板上滚轮只滚动面板，不会缩放画布；在面板上按下也不会开始框选。
- 面板内容超高时由**面板自身**滚动（`overflow: auto`），滚动条宽 6px，颜色 `--hx-line-3`。
- 面板之外的区域始终属于画布。
- 计算「适应视图」时扣除可见面板占用的区域，保证节点不会被面板盖住。

## 11.4 各面板规格

### ① 顶部条 `hx-topbar`
| 项 | 规格 |
|---|---|
| 位置 / 尺寸 | 画布区最上方，贴边，高 48；背景 `--hx-bg-2`，底部 1px `--hx-line-2`，无阴影 |
| 左侧 | 面包屑（每级可点击；末级可改名；超过 4 级时中间折叠成「…」下拉）→ 分支选择 `⎇ main ▾`（草稿分支前加 `--hx-wait` 圆点） |
| 中间 | 模型状态胶囊（见 12 号文档；空闲时不显示） |
| 右侧 | 授权档位胶囊 → 运行状态徽标 → 运行/暂停（主按钮）→ 急停（危险图标按钮）→ 主题切换 → 收起 / 全屏 |
| 显示时机 | 展开、全屏时常驻；Tab 专注模式下也保留，只隐藏次要按钮 |
| 急停态 | 整条背景变为 `--hx-danger-weak`，左侧显示「已急停 · 所有运行已取消 · [解除]」 |

### ② 节点库 `hx-library`
| 项 | 规格 |
|---|---|
| 位置 / 尺寸 | 左上，宽 260；高 = 画布高 − 24 − 底部小地图区 132 |
| 显示 / 收起 | 默认展开；头部「«」收成左边缘 36 宽的竖条（只显示类别图标）；按 `Tab` 时全部隐藏 |
| 结构 | 头部（标题 + 收起）→ 搜索框（`/` 聚焦）→ 按类别分组的列表（组标题可折叠）→ 底部 Tab「原子 · 子图库 · 扩展包」 |
| 列表项 | 高 32：`[20 图标格] 名称 / 一行描述（--hx-text-3）`；悬停底 `--hx-bg-4` |
| 拖入画布 | 按下后移动 4px 开始拖动；跟随光标显示节点的半透明预览（`opacity .8`，尺寸 = 实际尺寸 × 当前缩放）；在画布外松开即取消 |
| 单击 | 在视口中心添加节点并选中 |
| 滚动 | 只有列表区滚动，头部和搜索框固定 |

### ④ 检查器 `hx-inspector`
| 项 | 规格 |
|---|---|
| 位置 / 尺寸 | 右上，宽 320（拖动左边缘可调到 280–480），高 = 画布高 − 24 |
| 显示时机 | 有选中时滑入（`translateX(12px)→0` + 淡入，`--hx-t-3`），无选中时滑出；可「钉住」常显（此时显示图本身的属性） |
| 结构 | 头部 → 参数分组（折叠面板）→ 端口 → 运行信息 → 模型记录 |
| 头部 | 图标格 + 可编辑标题 + mono 类型行 + 状态徽标 + 「⋯」菜单 |
| 多选 | 「已选 5 个节点」+ 共同参数（值不一致显示「混合」）+ 批量操作（封装、对齐、删除） |
| 选中连线 | 显示源端口 → 目标端口、类型；可删除，可在中点插入节点 |
| 滚动 | 头部固定，其余整体滚动；滚动位置按节点 id 记住 |

**检查器分组（按节点类型）**：

| 节点 | 分组（按顺序；带 * 的默认展开） |
|---|---|
| 资源 | 基本*（kind、source、pin）· 值*（随 kind 切换的表单）· 使用情况（被哪些节点引用） |
| Agent | 基本*（output_schema、output_mode、lifecycle）· 角色卡*（引用 + 六段拼装预览入口）· 限制（tool_calls、inner_turns、timeout）· 修复与记忆（repair、memory_policy）· 采样（sampling） |
| 上下文装配 | 配方*（recipe 引用 + 段列表）· 预算*（ratio、max_ratio、on_overflow，附 token 条）· 透传（inherit 字段，锁定展示）· 装配预览 |
| 工具 | 工具*（tool、mode、config）· 风险与策略*（risk、policies、trim；keep_pointer 锁定）· 调用记录 |
| 扇出 | 分发*（items/n、concurrency、isolation）· 差异化（vary 表）· 收集（collect）· 预算分配 · 内部子图（缩略图 + 进入） |
| 汇合 | 汇合*（shape、wait、k、timeout、on_fail）· 插口列表 |
| 聚合 | 运算*（op、key）· 分级（levels 表）· 确定性（锁定说明） |
| 分支 | 条件*（cases 列表，可拖动排序）· 匹配（match、default） |
| 循环 | 循环*（trigger、max_rounds、exits）· 携带（carry 及其策略）· 停滞检测 · 事件（event 模式）· 预算 · 检查点 |
| 账本 | 存储*（store、scope）· 操作*（op、path）· 权限（字段 ACL，只读展示） |
| 人工 | 请求*（mode、assignee、channel）· 展示（view、form）· 超时 |
| 子图端口 | 端口*（role、name、type）· 摘要 / 升级（随 role 显示） |
| 子图引用 | 引用*（ref、pin、版本对比）· 暴露参数* · 覆盖（overrides）· 权限与预算（grant、budget、max_depth） |

所有节点末尾都固定两组：**运行信息**（状态、用时、tokens、最近一次输入/输出信封的折叠查看）和**模型记录**（模型对这个节点做过的操作，含理由与撤销）。

### ⑥ 小地图 `hx-minimap`
| 项 | 规格 |
|---|---|
| 位置 / 尺寸 | 左下，180×120 |
| 绘制 | `<canvas>`。节点画成 `--hx-line-3` 小方块；运行中 `--hx-accent`，失败 `--hx-danger`，选中 `--hx-text-1`；视口框 1px `--hx-text-2`，内部填 `--hx-line-1` |
| 交互 | 点击：视口中心移到该处（视图过渡）；拖动视口框：实时平移 |

### ⑦ 缩放控件
在小地图右侧，按钮组 `− | 87% | +`。点百分比弹出菜单：适应视图（1）、聚焦选中（2）、50%、100%、200%。

### ③ 停靠栏 `hx-dock`
| 项 | 规格 |
|---|---|
| 位置 | 底部居中，距运行抽屉 12；高 44，圆角 `--hx-r-xl` |

### ⑤ 运行抽屉 `hx-rundrawer`
| 项 | 规格 |
|---|---|
| 位置 | 画布底部、对话输入框上方，贴边；高 0–40%（默认 200，收起后 32） |
| Tab | 时间线 · 日志 · 操作历史 · 通道（数据/控制/升级/事件，P1） |

### ⑧ 提议栏 `hx-proposal`
只在有未处理的模型提议时出现，位于停靠栏正上方 8px，宽 ≤ 560。详见 12 号文档 §12.4.2。

### ⑨ 通知区
画布右上角；检查器可见时位于检查器左侧 12px。样式见 10 号文档 §10.22。

## 11.6 Tab 专注模式

- 焦点不在输入框时按 `Tab` 切换。
- 隐藏：节点库、检查器、小地图、缩放控件、停靠栏；运行抽屉收成 32px 标签条。
- 保留：顶部条、通知、提议栏、模型光标、对话输入框。
- 隐藏动画：各面板向最近的边缘 `translate` 12px 并淡出，`--hx-t-2`。
- 专注模式下选中节点，检查器**不会**自动出现；按 `I` 临时呼出。

| 画布区宽度 | 节点库 | 检查器 | 小地图 | 停靠栏 | 其他 |
|---|---|---|---|---|---|
| ≥ 1440 | 展开 260 | 320，可拖宽 | 显示 | 完整 | — |
| 1280–1439 | 展开 240 | 300 | 显示 | 完整 | — |
| 1024–1279 | 默认收成竖条 | 280，覆盖在画布上 | 收起 | 去掉撤销重做 | 主题按钮移入「⋯」菜单 |

画布在任何宽度下都满铺，降级只影响面板。

## 11.8 面板之间的关系与冲突

| 情况 | 处理 |
|---|---|
| 检查器与通知区重叠 | 通知区移到检查器左侧 |
| 节点库和小地图在同一侧 | 节点库高度扣除小地图区 |
| 运行抽屉拉高 | 停靠栏、提议栏、小地图随抽屉上移（用 `transform`，不重新布局画布） |
| 弹层与面板重叠 | 弹层在上（z 70） |
| 拖动节点经过面板 | 节点在面板下方继续移动；因为使用了 pointer capture，面板不会截获拖动中的指针 |
| 适应视图 | 计算可视区域时扣除可见的面板 |
