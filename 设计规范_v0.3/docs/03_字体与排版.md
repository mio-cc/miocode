# 03 · 字体与排版

## 1. 字体栈

| 令牌 | 栈 | 用途 |
|---|---|---|
| `--hx-font-ui` | Geist → Noto Sans SC → PingFang SC → Microsoft YaHei → system-ui | 所有界面文字 |
| `--hx-font-mono` | Geist Mono → JetBrains Mono → SFMono-Regular → Consolas | 数值、类型名、路径、快捷键、YAML、日志 |

Latin 用 Geist（几何感、数字清晰），中文回退到思源黑体（Noto Sans SC）。浏览器按字符逐个回退，所以中英混排时英文是 Geist、中文是 Noto Sans SC。

## 2. 加载方式

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet"
  href="https://fonts.googleapis.com/css2?family=Geist:wght@400;500;600&family=Geist+Mono:wght@400;500&family=Noto+Sans+SC:wght@400;500;600&display=swap">
```

- `display=swap`：先用回退字体渲染，加载后替换，不出现空白文字。
- 只加载 400 / 500 / 600 三个字重。
- **离线回退**：harness 是桌面应用时，字体文件应打包到本地（`/assets/fonts/`），用 `@font-face` + `font-display: swap` 声明，Google Fonts 作为 Web 版来源。无网时退到 PingFang / 微软雅黑，界面必须仍然整齐（尺寸基于行高令牌，不依赖具体字体宽度）。
- 节点宽度、端口行高都是固定值，**不随字体加载完成而跳动**。

## 3. 字号档位

只允许这 8 档。行高为推荐值，字距对中文为 0。

| 令牌 | 字号 | 行高 | 字重 | 字距（Latin） | 用途 |
|---|---|---|---|---|---|
| `--hx-fs-10` | 10.5 | 14 | 500 | +0.02em | 端口类型标签、徽标、AI 签 |
| `--hx-fs-11` | 11 | 16 | 400/500 | +0.01em | 微标签、快捷键键帽、时间戳 |
| `--hx-fs-12` | 12 | 18 | 400 | 0 | 端口名、控件标签、说明文字、日志 |
| `--hx-fs-13` | 13 | 20 | 400 | 0 | **基准**：正文、控件值、菜单项、检查器 |
| `--hx-fs-14` | 14 | 20 | 600 | -0.005em | 节点标题、面板内小标题 |
| `--hx-fs-16` | 16 | 24 | 600 | -0.01em | 面板标题、弹窗标题 |
| `--hx-fs-20` | 20 | 28 | 600 | -0.015em | 区块标题、空状态标题 |
| `--hx-fs-28` | 28 | 36 | 600 | -0.02em | 展示（只在总览页、规范页） |

规则：
- 同一屏最多出现 4 档字号。
- 字重只用 400 / 500 / 600。禁止 700 以上。
- 层级优先用**字号和颜色**区分，其次才是字重。
- 浅色下正文用 `--hx-text-1` 400；深色下同样，不需要调字重补偿。

## 4. 中英文混排

| 规则 | 示例 |
|---|---|
| 中文与英文单词之间**不加空格**，靠字体本身的间距（界面文字短，加空格反而松散） | `调用Agent`、`打开YAML视图` |
| **例外**：数值与单位、数值与中文之间加一个普通空格，便于扫读 | `并发 3`、`62%`、`2.4k tokens`、`第 2 / 5 轮` |
| 标点用中文全角：，。：；？！（） | `等待审批：付费数据 API` |
| 代码、类型名、路径用等宽并保留英文原样 | `方案@1`、`根图/闭环迭代#r2/执行池` |
| 括号内是英文或代码时用半角括号 | `输出类型 (output_schema)` |
| 不使用全大写英文标签 | 写"运行中"，不写"RUNNING" |

## 5. 数字

- 所有会变化的数字（tokens、耗时、进度、并发、轮次、坐标、费用）使用 `font-variant-numeric: tabular-nums`，防止跳动时左右抖动。
- 等宽场景直接用 `--hx-font-mono`。
- 格式见 15 号文档：`1.2k`、`3.4M`、`02:15`、`¥3.30`。
- 进度百分比不带小数：`62%`。

```css
.hx-num { font-variant-numeric: tabular-nums; }
.hx-mono { font-family: var(--hx-font-mono); font-variant-numeric: tabular-nums; }
```

## 6. 等宽字体使用场景

| 用 | 不用 |
|---|---|
| 类型名（`上下文包`、`方案@1`） | 节点标题 |
| 节点类型行（`Agent · resident`） | 按钮文字 |
| 数值、时间、tokens | 菜单项 |
| 层级路径 ID、幂等键、版本号 | 正文说明 |
| 快捷键键帽 | 状态文字（"运行中"） |
| YAML、JSON、日志 | 通知正文 |

## 7. 截断与换行

| 位置 | 规则 | 最大 |
|---|---|---|
| 节点标题 | 单行，末尾省略号；悬停显示完整标题 | 节点宽 − 图标格 − 状态区 |
| 节点类型行 | 单行省略 | 同上 |
| 端口名 | 单行省略；输入在左对齐、输出右对齐；左右两列各占 50%，被挤压时**先截断类型标签，再截断端口名** | — |
| 内联控件标签 | 单行省略，宽度固定 40% | — |
| 层级路径 | **中间省略**：保留首段和末两段，`根图/…/执行池/执行者#3` | 面包屑、运行条 |
| 文件路径 | 中间省略 | — |
| 状态脚文字 | 单行省略 | — |
| 检查器参数标签 | 允许换行至 2 行 | — |
| 通知、对话消息 | 正常换行 | — |
| 日志行 | 不换行，横向滚动 | — |

中间省略实现：

```ts
function midEllipsis(path: string, keepTail = 2) {
  const p = path.split('/');
  if (p.length <= keepTail + 1) return path;
  return [p[0], '…', ...p.slice(-keepTail)].join('/');
}
```

CSS 单行省略：

```css
.hx-truncate { min-width: 0; overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }
```

## 9. 常见错误

- 用 15px、17px 等不在档位里的字号 → 改到最近的档位。
- 粗体 700 做标题 → 用 600。
- 节点标题换行把节点撑高 → 单行截断。
- 中文里夹全大写英文标签 → 改中文。
- 数值用比例字体，运行时跳动 → 加 `tabular-nums`。
