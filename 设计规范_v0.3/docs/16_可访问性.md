# 16 可访问性

> **v0.3.2 已采纳**：1.2 节建议的 5 个浅色令牌新值已写入 tokens.css（text-3 #6b6f78、accent-strong #9a5c00、ok #1d8250、wait #94700a、type-ctx #9f7a0e）。表中"当前值"一栏因此与建议值相同。

> 目标：符合 WCAG 2.2 AA。画布是高度视觉化的界面，但所有核心操作（选择、连线、改参数、运行、审批）必须能只用键盘完成，并能被屏幕阅读器理解。

---

## 1. 对比度要求

| 用途 | 最低对比度 | 说明 |
|---|---|---|
| 正文、控件值（< 18px） | 4.5:1 | `--hx-text-1`、`--hx-text-2` |
| 大字（≥ 18px 或 ≥ 14px 加粗） | 3:1 | — |
| 标签、占位、次要信息 | 4.5:1（目标），不低于 3:1 | `--hx-text-3` 只用于 ≥ 12px 的非关键文字 |
| 图形元素：端口圆点、图标、连线、状态点、焦点环 | 3:1 | 对相邻背景 |
| 禁用控件 | 无要求 | 但必须能看出是禁用 |

## 2. 焦点环

- 所有可聚焦元素使用 `:focus-visible`，鼠标点击不显示，键盘操作显示。
- 样式：`outline: 2px solid var(--hx-focus); outline-offset: 2px;`，圆角跟随元素。
- 节点被键盘聚焦时，外观与“选中”相同，用同一个环，不叠加第二种环。焦点位置由屏幕阅读器播报。
- 输入框聚焦：外框 `--hx-text-2` + `0 0 0 3px` 15% 同色光晕（已在控件规范中定义），同时满足 3:1。
- 焦点环不能被 `overflow:hidden` 裁掉：面板内列表项用 `outline-offset:-2px`。
- 禁止 `outline: none` 而不提供替代。

## 3. 键盘可达性

### 3.1 全局焦点顺序
```
顶部条（面包屑 → 分支 → 档位 → 运行 → 急停）
→ 节点库（搜索 → 分组 → 项）
→ 画布（节点按 阅读顺序：先按列 x，再按行 y）
→ 检查器
→ 运行抽屉
→ 对话输入框
```
- `F6` / `Shift+F6` 在这几个区域之间跳转（区域内用 Tab）。
- 每个区域有 `role="region"` 和 `aria-label`。

### 3.2 画布内的键盘方案

画布作为一个复合控件：只占一个 Tab 停靠点，进入后用方向键在内部移动（roving tabindex）。

| 键 | 作用 |
|---|---|
| Tab 进入画布 | 聚焦上次聚焦的节点；没有则聚焦第一个节点 |
| `←↑→↓` | 按空间方向移动焦点到最近的节点（不是移动节点） |
| `Shift + 方向` | 加选方向上的节点 |
| `Enter` | 打开检查器并把焦点移进去；子图节点则进入子图 |
| `Esc` | 从检查器回到节点；从子图回到上一层 |
| `M` 然后方向键 | 移动模式：方向键移动节点 1 格，Shift 5 格，Enter 确认，Esc 取消 |
| `P` | 端口模式：Tab 在当前节点端口间切换 |
| 端口模式下 `Enter` | 开始连线；方向键在**兼容端口**之间跳转（播报“上下文包 → 决策者.context，可连接”）；Enter 建立，Esc 取消 |
| `Delete` | 删除，焦点移到最近的节点 |
| `A` | 快速添加，新节点放在焦点节点右侧并自动连线 |
| `?` | 显示键盘帮助 |

所有快捷键都在命令面板（⌘K）里可搜到，作为不记快捷键用户的入口。

### 3.3 拖放的键盘替代
| 鼠标 | 键盘 |
|---|---|
| 从节点库拖入 | 在节点库项上按 Enter，节点加到视口中心或焦点节点右侧 |
| 拖动节点 | `M` 移动模式 |
| 拖线 | `P` 端口模式 |
| 框选 | `Shift + 方向` 或 ⌘A |
| 拖动数字调值 | 方向键 ±1，Shift ±10，PageUp/PageDown ±步长×10 |

## 4. 屏幕阅读器

### 4.1 画布 ARIA 结构
```html
<div role="application" aria-label="画布：竞品定价调研，7 个节点，8 条连线"
     aria-roledescription="节点画布" aria-describedby="hx-canvas-help">
  <div role="group" aria-label="节点">
    <div role="button" tabindex="0" id="n-12"
         aria-roledescription="节点"
         aria-label="Agent 节点 决策者，运行中 62%，2 个输入已连接，1 个输出"
         aria-selected="true">…</div>
  </div>
  <svg aria-hidden="true">…连线…</svg>
</div>
<p id="hx-canvas-help" hidden>方向键在节点间移动，Enter 打开设置，P 进入端口模式，? 查看全部快捷键</p>
```
- 用 `role="application"`，是因为画布内的方向键有自定义含义。
- 连线 SVG 对读屏隐藏，连接关系放进节点的 label 和“端口模式”的播报里。
- 提供一个**列表视图**替代（视图切换：画布 / YAML / 列表）：按拓扑顺序列出节点和连线，是完全可读的表格。

### 4.2 aria-label 模板
```
节点：  {类型}节点 {标题}，{状态}{进度}，{已连输入数}/{输入数} 个输入已连接，{输出数} 个输出{，模型修改过}{，提议中}
端口：  {输入|输出}端口 {名称}，类型 {类型}，{已连接到 X.y | 未连接}{，必填}
连线：  从 {A}.{端口} 到 {B}.{端口}，类型 {类型}
子图：  子图 {标题}，{N} 个节点，按 Enter 进入
```
模板放在 `T['a11y.node.label']` 等 key 中。

### 4.3 live region 播报
页面有两个常驻区域：
```html
<div aria-live="polite"  id="hx-live-polite"  class="sr-only"></div>
<div aria-live="assertive" id="hx-live-alert" class="sr-only"></div>
```

| 事件 | 区域 | 播报 |
|---|---|---|
| 节点完成 | polite（合并，最多每 2 秒一次） | 「决策者 已完成，耗时 4 秒」 |
| 一轮结束 | polite | 「第 1 轮结束，未达成，进入第 2 轮」 |
| 节点失败 | assertive | 「检索 失败：超时」 |
| 需要审批 | assertive | 「人工审批 等待你批准」 |
| 模型修改了图 | polite | 「模型修改了 3 处，按 ⌘Z 撤销」 |
| 急停 | assertive | 「已急停，所有运行已停止」 |
| 撤销/重做 | polite | 「已撤销：删除连线」 |

**节流**：运行时状态事件可能每秒上百次，播报只取关键事件，同类合并（「3 个节点已完成」）。

## 5. 不只靠颜色

| 信息 | 颜色之外的冗余编码 |
|---|---|
| 节点状态 | 状态点图标（弧、勾、叉、暂停、横线、闪电）+ 状态脚文字 |
| 端口类型 | 悬停/聚焦显示类型名；端口模式下播报 |
| 连线类型 | 悬停显示类型标签；选中后检查器显示 |
| 兼容 / 不兼容 | 兼容端口放大 + 光环；不兼容变暗 + 预览线变虚线 + 原因文字 |
| 模型操作 | 「AI」文字签；幽灵节点用虚线；理由文字 |
| 失败 | 红色 + 叉图标 + 「失败」文字 |
| 授权档位 | 刻度格数 + 数字 + 名称 |
| 急停 | 顶部横幅文字 |
| 日志级别 | 前缀文字 INFO / WARN / ERROR |

检查方法：把页面切成灰度（DevTools → Rendering → Emulate vision deficiencies → Achromatopsia），以上信息都必须仍可分辨。

## 6. 减少动效

`prefers-reduced-motion: reduce` 时：
- tokens 里所有 `--hx-t-*` 为 0。
- 连线流动改为**静态**的橙色实线（不再流动）。
- 旋转弧改为静态圆环 + 状态文字。
- 骨架屏去掉扫光。
- 视图过渡（适应视图、进入子图、展开画布）直接跳转。
- AI 光标不做移动动画，直接出现在目标处。
- 模型闪光改为 1.5 秒的静态描边。
- 不影响任何功能。

另在设置里提供“减少动效”开关，优先级高于系统设置。

## 7. 缩放到 200%

- 浏览器缩放 200%（相当于 1280 宽变 640 CSS 像素）时：
  - 左侧栏折叠为图标栏；节点库、检查器改为抽屉，默认收起。
  - 顶部条次要项收进「更多」菜单。
  - 画布内容不受浏览器缩放影响画布自身的缩放倍率（画布缩放独立）。
  - 文字不截断到不可读：节点标题最多截断到 8 个字符并提供悬停全称。
- 不得出现横向滚动条（画布区域除外）。
- 所有尺寸用 px 令牌，但字号随浏览器缩放生效；不要用 `vw` 定义字号。

## 8. 目标尺寸

| 元素 | 最小可点击区域 |
|---|---|
| 按钮、图标按钮 | 28×28（标准），24×24（紧凑，WCAG 2.2 下限） |
| 端口 | 视觉 10px，热区 18×18；画布缩放 < 0.75 时热区保持屏幕尺寸 18px 不随缩放变小 |
| 连线 | 14px 宽透明热区 |
| 节点上的内联控件 | 24px 高 |
| 菜单项 | 28px 高 |
| 相邻目标间距 | 至少 4px，或热区不重叠 |
