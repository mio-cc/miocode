# 19 交付验收清单

> 每次交付（原型、组件、正式版本）都按本清单逐条检查。每条写了**检查方法**。全部通过才算交付完成；有不通过项须在交付说明里列出并给出计划。
> 图例：【必】必须通过；【P1】本阶段可以暂缺，但要在交付说明里写明。

---

## A. 视觉与令牌（12）

- [ ] A1【必】页面中没有裸色值。方法：在 CSS 和行内样式中搜索 `#[0-9a-f]{3,8}`、`rgb(`、`hsl(`，结果只能出现在 tokens.css。
- [ ] A2【必】字号只用 8 档令牌。方法：搜索 `font-size:`，所有值都应是 `var(--hx-fs-*)`。
- [ ] A3【必】间距是 4 的倍数。方法：DevTools 抽查 10 个组件的 padding、gap。
- [ ] A4【必】圆角按层级使用：徽标 xs、输入 sm、按钮 md、节点和面板 lg、卡片 xl。方法：抽查。
- [ ] A5【必】嵌套圆角为外层减去内边距。方法：检查节点内的控件、面板内的列表项。
- [ ] A6【必】只有浮起的元素有阴影（面板、菜单、被拖动的节点、节点本身）。方法：搜索 `box-shadow`。
- [ ] A7【必】一个颜色只表达一种含义：橙=运行和主路径、绿=完成、红=失败和危险、黄=等待、蓝紫=模型。方法：逐屏检查，没有装饰性用色。
- [ ] A8【必】没有禁止项：渐变、玻璃拟态、emoji、全大写标签、到处悬停放大。方法：目视 + 搜索 `gradient`、`backdrop-filter`。
- [ ] A9【必】数字使用等宽数字。方法：检查用时、tokens、版本号、端口类型等处的 `font-variant-numeric`。
- [ ] A10【必】字体按栈正确加载，离线时回退到系统中文字体也不错位。方法：断网刷新。
- [ ] A11【P1】图标统一 20px 网格、1.5px 线宽、圆角端点。方法：并排查看全部图标。
- [ ] A12【必】一个组件内文字颜色不超过两级。方法：抽查节点、检查器、通知。

## B. 主题（8）

- [ ] B1【必】首次打开默认浅色。方法：清除本地存储后打开。
- [ ] B2【必】切换主题后刷新，保持用户的选择。方法：切到深色，刷新。
- [ ] B3【必】切换主题不需要重新加载页面，所有元素即时更新，包括 canvas 绘制的小地图。方法：切换后检查小地图、图表。
- [ ] B4【必】两套主题下没有看不清的元素。方法：逐屏切换对照。
- [ ] B5【必】两套主题都满足 16_可访问性 的对比度表。方法：axe DevTools 扫描。
- [ ] B6【必】JS 里需要的颜色（canvas、SVG 属性）在渲染时读取令牌，不缓存。方法：切换主题后检查。
- [ ] B7【P1】“跟随系统”选项可用，且默认关闭。方法：设置里开启后，切换系统主题。
- [ ] B8【必】主题切换时没有闪烁（FOUC）。方法：在 `<head>` 里同步读取主题设置，刷新时观察。

## C. 画布（12）

- [ ] C1【必】滚轮以光标为中心缩放，范围 0.2–2.5。方法：把光标放在某个节点上缩放，节点保持在光标下。
- [ ] C2【必】空白拖动、Space 加拖动、H 工具都能平移。
- [ ] C3【必】点阵网格随缩放变化，缩放低于 0.5 时密度翻倍。
- [ ] C4【必】LOD 三档切换正确，切换时不闪烁。方法：缓慢缩放观察。
- [ ] C5【必】单选、Shift 或 ⌘ 加减选、Shift 加拖动框选都正常。
- [ ] C6【必】节点吸附网格，按住 Alt 时不吸附。
- [ ] C7【必】按 1 适应视图、按 2 聚焦选中，都有过渡动画。
- [ ] C8【必】双击子图进入、Esc 返回、面包屑跳转都正常。
- [ ] C9【必】空画布显示空状态和引导。
- [ ] C10【必】小地图可以点击或拖动来导航，视口框位置与画布一致。
- [ ] C11【P1】按 L 自动布局，节点带位移动画。
- [ ] C12【P1】拖动时显示对齐参考线。

## D. 节点（10）

- [ ] D1【必】节点结构符合 08_节点：头部、端口行、内联控件、状态脚。方法：对照尺寸令牌测量。
- [ ] D2【必】13 种原子节点的端口布局都正确。方法：逐个拖入并对照文档。
- [ ] D3【必】8 种状态都有颜色、图形、文字三重表达。方法：运行模拟，并开灰度模式检查。
- [ ] D4【必】内联控件和检查器双向同步。
- [ ] D5【必】标题过长时截断，悬停显示全称。
- [ ] D6【必】子图节点有叠层边，循环节点显示轮次。
- [ ] D7【必】参数转端口后出现新的输入端口，并带 ⇢ 标记。
- [ ] D8【必】内核锁定的参数显示锁图标，不能修改。
- [ ] D9【必】节点悬停时外框变化，但不放大、不加阴影。
- [ ] D10【P1】人工节点挂起时，审批按钮直接显示在节点上。

## E. 端口与连线（12）

- [ ] E1【必】端口圆心压在节点边框上，圆点外有底色描边形成缝隙。
- [ ] E2【必】连线颜色等于源端口的类型色。
- [ ] E3【必】拖线时兼容的端口放大发亮，不兼容的变暗。
- [ ] E4【必】在 18px 范围内会吸附到端口。
- [ ] E5【必】类型不兼容时预览线变成红色虚线，并附原因。方法：把列表拖到上下文包端口。
- [ ] E6【必】连出非法环时被拒绝并提示。
- [ ] E7【必】在空白处松开时，弹出按类型过滤的快速添加面板，选中后自动连线。
- [ ] E8【必】从已连接的输入端口能拔下连线，重新接到别处或删除。
- [ ] E9【必】按住 Alt 点击端口，断开该端口的全部连线。
- [ ] E10【必】悬停连线时线变粗，中点出现「+」「×」。
- [ ] E11【必】运行中有数据流动的连线显示流动光点，其余连线静止。
- [ ] E12【必】连线点击热区为 14px。方法：在线旁 6px 处点击，能选中。

## F. 控件（8）

- [ ] F1【必】所有控件都有完整的状态矩阵：默认、悬停、按下、聚焦、禁用。方法：对照 10_控件库。
- [ ] F2【必】数字步进可以左右拖动调值，Shift 加速，可以用滚轮，双击可以输入。
- [ ] F3【必】下拉选择可以输入过滤，并能用键盘上下选择。
- [ ] F4【必】分段控件的选中背景有滑动动画。
- [ ] F5【必】按钮文案符合 15_文案 的动词规范，不出现“确定”。
- [ ] F6【必】危险操作的确认对话框默认聚焦在“取消”。
- [ ] F7【必】通知最多显示 3 条，带撤销的通知停留 8 秒。
- [ ] F8【必】按 ⌘K 打开命令面板，可以搜索节点和命令。

## G. 交互与快捷键（10）

- [ ] G1【必】13_交互模式 的快捷键表全部可用，Windows 和 Mac 都要测。
- [ ] G2【必】焦点在输入框里时，画布快捷键不触发。
- [ ] G3【必】撤销重做覆盖全部 Op 种类。方法：每种操作都做一次，撤销到底，图恢复原样。
- [ ] G4【必】连续拖动只产生一条历史记录。
- [ ] G5【必】复制粘贴，包括跨子图粘贴，粘贴位置正确。
- [ ] G6【必】右键菜单按目标显示不同的条目：节点、多选、连线、空白、端口。
- [ ] G7【必】按 Tab 隐藏或显示全部面板。
- [ ] G8【必】卡片和展开之间的 FLIP 过渡连贯，展开后视角保持不变。
- [ ] G9【必】按 Esc 逐层退出：弹层 → 子图 → 展开态。
- [ ] G10【P1】快捷键可以自定义。

## H. 运行与反馈（8）

- [ ] H1【必】运行时节点状态按拓扑顺序变化，时间线实时绘制。
- [ ] H2【必】失败节点显示错误摘要、「重试」和「查看日志」，下游节点标为未运行。
- [ ] H3【必】审批在节点、对话、通知三处同步，任一处处理后另外两处更新。
- [ ] H4【必】急停后所有运行立即停止，顶部条变为危险色，档位降为 0。
- [ ] H5【必】断网时出现横幅，修改保存在本地；重连后同步，并给出提示。
- [ ] H6【必】长任务运行超过 20 秒后显示预计时间，数字不来回跳动。
- [ ] H7【必】空状态的文案和操作符合 14_状态反馈。
- [ ] H8【必】反馈形式符合决策表：同一件事只用一种主要形式。

## I. 模型操作者（10）

- [ ] I1【必】模型做的每一处修改都有 AI 签、理由，并且可以撤销。
- [ ] I2【必】1 档下只生成幽灵节点和提议栏，支持逐条查看、全部采纳、全部拒绝。
- [ ] I3【必】2 档及以上直接修改，节点闪模型色光环，通知里可以撤销。
- [ ] I4【必】模型编辑时顶部显示「模型正在编辑…」胶囊，AI 光标移动到目标节点。
- [ ] I5【必】超出授权时变为审批，并说明需要什么权限、为什么需要。
- [ ] I6【必】有污染标记的操作即使在 4 档也会先停下等确认，除非用户关闭了污染标记。
- [ ] I7【必】模型不能关闭急停，也不能修改自己的授权书。方法：模拟模型发出这两种 Op，都应被拒绝。
- [ ] I8【必】操作历史里人和模型的条目可以区分，模型条目显示理由。
- [ ] I9【必】人和模型同时编辑同一个节点时，人的修改保留在主线，模型的修改放进草稿。
- [ ] I10【必】对话里提到的节点可以点击，点击后画布定位到该节点。

## J. 性能（6）

- [ ] J1【必】200 节点、300 连线下，平移、缩放、拖动、拖线都保持 60fps。方法：17_性能 第 8 节。
- [ ] J2【必】平移和拖动时没有 Forced reflow。
- [ ] J3【必】拖动单个节点时，每帧脚本耗时小于 1ms。
- [ ] J4【必】运行事件每秒 100 条时，帧率不低于 55fps。
- [ ] J5【必】反复创建、删除 200 个节点 10 次，内存不持续增长。
- [ ] J6【P1】1000 节点时帧率不低于 30fps（混合渲染）。

## K. 可访问性（6）

- [ ] K1【必】不用鼠标也能完成：添加节点、连线、改参数、运行、审批、撤销。
- [ ] K2【必】读屏能读出节点类型、标题、状态、连接数量。
- [ ] K3【必】失败、审批、急停用 assertive 播报。
- [ ] K4【必】开启减少动效后没有移动动画，功能完整。
- [ ] K5【必】浏览器缩放到 200% 时没有横向滚动。
- [ ] K6【必】焦点环在所有可聚焦元素上都看得见。

## L. 文案（5）

- [ ] L1【必】术语与 15_文案 的术语表一致，没有出现禁用的同义词。方法：在 T.ts 里搜索禁用词。
- [ ] L2【必】组件代码里没有中文字面量，文案全部在 T 对象中。
- [ ] L3【必】错误信息都包含“发生了什么”和“怎么办”。
- [ ] L4【必】数字、时间、tokens、费用的格式符合规范。
- [ ] L5【必】模型的理由不超过 40 字，先写目的。

## M. 浅色主题专项检查（10）

项目默认使用浅色主题，下面这些问题在浅色下最容易出现：

- [ ] M1【必】琥珀色作为文字或细线时，用的是 `--hx-accent-strong`，不是 `--hx-accent`。方法：在浅色下搜索 `color: var(--hx-accent)`，应当只出现在大面积填充的场景。
- [ ] M2【必】白色面板浮在浅灰画布上时，外框和阴影能分辨出层级。方法：把屏幕亮度调到最高，节点边缘仍然清晰。
- [ ] M3【必】节点阴影细腻，不发灰、不发脏。方法：放大到 200% 观察节点下沿。
- [ ] M4【必】点阵网格看得见，但不抢节点的注意力。方法：远看画布，主要看到的是节点而不是点阵。
- [ ] M5【必】8 种端口类型色在白底上对比度不低于 3:1，上下文包类型的颜色在输入框底色上也要达到 3:1。方法：16_可访问性 1.1 表。
- [ ] M6【必】状态色在浅色下用作小号文字时，加粗且不小于 12px，或改用 text-1 文字配状态色图标。
- [ ] M7【必】弱色底（如 `--hx-ok-weak`）上的文字对比度不低于 4.5:1。方法：先与白色合成，再计算对比度。
- [ ] M8【必】幽灵节点在浅色下仍能一眼和正式节点区分开（透明度加虚线）。方法：放一个幽灵节点和一个正式节点做对比。
- [ ] M9【必】选中环（`--hx-focus` 深色）和运行中外发光同时出现时不打架。方法：选中一个运行中的节点。
- [ ] M10【必】打印或导出 PNG 时使用浅色主题，背景为白色。方法：导出画布截图。
