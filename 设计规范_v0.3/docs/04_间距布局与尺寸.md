# 04 · 间距、布局与尺寸

## 1. 间距体系

基数 4px。只用下列令牌，禁止出现 5、7、10、13px 等非体系值（`--hx-s-3` 的 6px 与 `--hx-s-1` 的 2px 是例外的半档，用于紧凑场景）。

| 令牌 | 值 | 典型用途 |
|---|---|---|
| `--hx-s-1` | 2 | 图标与徽标之间、状态点与文字的极小间隙 |
| `--hx-s-2` | 4 | 徽标内边距、图标按钮内图标与边缘、列表项之间 |
| `--hx-s-3` | 6 | 节点内端口名与圆点、紧凑控件内边距 |
| `--hx-s-4` | 8 | 控件内水平内边距、节点头部图标与标题、菜单项内边距 |
| `--hx-s-5` | 12 | 节点左右内边距、面板内容内边距、浮动面板距画布边缘 |
| `--hx-s-6` | 16 | 面板分组之间、检查器左右内边距、弹窗内边距 |
| `--hx-s-7` | 20 | 区块之间 |
| `--hx-s-8` | 24 | 弹窗内边距（大）、空状态内容间距 |
| `--hx-s-9` | 32 | 页面级区块 |
| `--hx-s-10` | 48 | 空状态上下留白、总览页区块 |

## 3. 圆角

| 令牌 | 值 | 用于 |
|---|---|---|
| `--hx-r-xs` | 3 | 徽标、类型标签、键帽、AI 签 |
| `--hx-r-sm` | 5 | 输入框、小按钮、菜单项、节点图标格、紧凑控件 |
| `--hx-r-md` | 7 | 按钮、分段控件、图标按钮 |
| `--hx-r-lg` | 10 | 节点、浮动面板、菜单容器、通知 |
| `--hx-r-xl` | 14 | 停靠栏、对话中的画布卡片、命令面板、弹窗 |
| `--hx-r-full` | 999 | 状态胶囊、开关、端口圆点 |

**嵌套规则**：内层圆角 = 外层圆角 − 内边距，结果小于 `--hx-r-xs` 时取 `--hx-r-xs`，大于等于外层时取外层减一档。

| 外层 | 内边距 | 计算 | 内层取值 |
|---|---|---|---|
| 停靠栏 14 | 4 | 14 − 4 = 10 | `--hx-r-lg` |
| 节点 10 | 2（选中底贴近外框） | 10 − 2 = 8 → 取较小档 | `--hx-r-md` |
| 分段控件 7 | 2 | 7 − 2 = 5 | `--hx-r-sm` |
| 菜单 10 | 4 | 10 − 4 = 6 → 最接近 | `--hx-r-sm` |
| 命令面板 14 | 4（结果项选中底） | 14 − 4 = 10，但结果项高 36 | 受高度上限约束，取 `--hx-r-md` |

补充规则：
- 嵌套规则只对**贴着外框**的内层生效；不贴边的内部元素（如节点头部的图标格）按自身尺寸取档，图标格用 `--hx-r-sm`。
- 结果落在两档之间时取**较小**的一档。
- 元素高度 ≤ 36 时，圆角不超过 `--hx-r-md`。

## 4. 尺寸令牌

| 令牌 | 值 | 说明 |
|---|---|---|
| `--hx-node-w` | 236 | 标准节点宽：Agent、上下文装配、工具、扇出、汇合、聚合、循环、账本、人工、子图引用 |
| `--hx-node-w-sm` | 184 | 紧凑节点：资源、分支、子图端口 |
| `--hx-node-head` | 38 | 节点头部（含 1px 底分隔线） |
| `--hx-node-row` | 24 | 端口行高；端口圆心 y = 行中心 |
| `--hx-node-widget` | 28 | 内联控件行高（控件本身 24） |
| `--hx-port` | 10 | 端口圆点直径（另加 2px 底色描边） |
| `--hx-ctl-h` | 28 | 标准控件高 |
| `--hx-ctl-h-sm` | 24 | 紧凑控件高（节点内、密集表格） |
| `--hx-grid` | 20 | 画布网格间距 = 吸附步长 |

**节点高度计算**（不测 DOM，用于端口坐标）：

```ts
const H = 38 + 4 + rows * 24 + 4                 // 头部 + 端口区
        + (widgets ? 4 + widgets * 28 + 8 : 0)   // 内联控件区
        + (running ? 28 : 0);                    // 状态脚（运行时）
// 端口 i 的圆心（输入在左，输出在右）
const portY = node.y + 38 + 4 + i * 24 + 12;
const portX = side === 'in' ? node.x : node.x + width;
```

节点宽度**固定**，不允许用户拖宽（理由：端口坐标、布局算法、小地图都依赖固定宽；长标题靠截断+悬停）。

其他固定尺寸：

| 元素 | 尺寸 |
|---|---|
| 顶部条 | 高 48 |
| 节点库面板 | 宽 260，可收起为 44 的图标列 |
| 检查器 | 宽 320 |
| 小地图 | 180 × 120 |
| 停靠栏 | 高 40 |
| 运行抽屉 | 高 0–40% 中间栏，默认 220，最小 120 |
| 对话卡片中的画布 | 高 440 |
| 命令面板 | 宽 560，最大高 420 |
| 菜单 | 宽 220 |
| 通知 | 宽 320 |
| 提示框 | 最大宽 280 |

## 5. 画布网格与吸附

- 网格间距 `--hx-grid`（20px），点直径 1px（缩放 ≥ 1 时 1.2px）。
- 缩放 `k < 0.5` 时显示间距翻倍（40），`k < 0.25` 时再翻倍（80）。
- 节点**左上角**吸附到网格；拖动时按住 `Alt` 关闭吸附。
- 吸附公式：`x' = Math.round(x / 20) * 20`。
- 新建节点放在光标位置并吸附；从快速添加面板创建的节点，左边缘对齐到源端口 x + 60 再吸附。

## 6. 应用级布局

```
┌──────┬──────────────────────────────────────────────┐
│侧栏   │  中间栏（对话或展开的画布）                     │
│ 240  │  卡片形态：内容列最大宽 880，居中               │
│可收为 │  展开形态：占满中间栏                           │
│ 56   │                                              │
└──────┴──────────────────────────────────────────────┘
```

- 对话内容列最大宽 880，左右留白 ≥ 24。
- 画布卡片宽 = 内容列宽（最大 880），高 440，圆角 `--hx-r-xl`。
- 展开态画布占满中间栏；对话输入框固定在底部（高 56–120 自适应），画布底边在输入框上方。

## 7. 响应式断点

| 断点 | 侧栏 | 节点库 | 检查器 | 小地图 | 运行抽屉 |
|---|---|---|---|---|---|
| ≥ 1920 | 240 展开 | 260 展开 | 320 浮动 | 显示 | 默认 220 |
| 1440–1919 | 240 | 260 | 320 | 显示 | 220 |
| 1280–1439 | 默认收起为 56 | 260，可收起 | 320，覆盖画布右侧 | 显示 | 200 |
| 1024–1279 | 收起 56 | 默认收起为 44 图标列，点击浮出 | 300，选中时浮出，覆盖画布 | 隐藏，可在缩放控件里打开 | 180 |
| < 1024 | 隐藏，汉堡菜单 | 抽屉式 | 底部抽屉 | 隐藏 | 合并到底部抽屉 Tab |

规则：画布永远满铺；面板只是覆盖。窄屏下面板变为"点击才出现、点画布即收起"。

## 8. z-index 层级

只用下面这些值，不随手写 9999。

| 层 | z-index | 内容 |
|---|---|---|
| 画布底 | 0 | 背景、网格 |
| 连线层 | 10 | SVG 连线 |
| 节点层 | 20 | 普通节点 |
| 选中节点 | 21 | 选中的节点（压在相邻节点上） |
| 连线交互层 | 25 | 正在拖的预览线、连线中点按钮 |
| 拖动中的节点 | 30 | 被拖起的节点 |
| 模型光标 | 35 | AI 光标、框选矩形 |
| 浮动面板 | 100 | 节点库、检查器、小地图、停靠栏、提议栏 |
| 顶部条 | 110 | 顶部条 |
| 运行抽屉 | 120 | 底部抽屉 |
| 菜单 / 下拉 / 提示框 | 200 | 右键菜单、下拉、tooltip |
| 遮罩 + 弹窗 / 命令面板 | 300 | 确认对话框、命令面板 |
| 通知 | 400 | toast |
| 急停条 | 500 | 急停横幅（任何时候都在最上） |

```css
:root{
  --hx-z-canvas:0; --hx-z-edge:10; --hx-z-node:20; --hx-z-node-sel:21; --hx-z-edge-ui:25;
  --hx-z-drag:30; --hx-z-cursor:35; --hx-z-panel:100; --hx-z-top:110; --hx-z-drawer:120;
  --hx-z-menu:200; --hx-z-modal:300; --hx-z-toast:400; --hx-z-estop:500;
}
```

> 这组 z-index 令牌将在下一版并入 `tokens.css`；在此之前实现者可以先在本地样式中声明，命名保持一致。
