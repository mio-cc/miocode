### 1.1 DOM

```html

  <div class="hx-node__head">

    <span class="hx-node__name">
      <span class="hx-node__title">聚类员</span>

    </span>
    <span class="hx-node__meta">
      <span class="hx-ai-tag" hidden>AI</span>
      <span class="hx-node__status"><svg class="hx-icon hx-icon--xs">…</svg></span>
      <span class="hx-node__time">1.2s</span>
    </span>
  </div>
  <div class="hx-node__ports">
    <div class="hx-port-row">
      <span class="hx-port hx-port--in hx-type-ctx" data-port="context"><i class="hx-port__dot"></i><b class="hx-port__name">context</b></span>
      <span class="hx-port hx-port--out hx-type-gen" data-port="result"><b class="hx-port__name">result</b><i class="hx-port__dot"></i></span>
    </div>
    …
  </div>
  <div class="hx-node__widgets">…参数行（紧凑控件）…</div>
  <div class="hx-node__foot"><i class="hx-node__bar" style="transform:scaleX(.62)"></i><span class="hx-node__foot-text">生成中 62%</span></div>
</div>
```

- 位置只用 `transform: translate3d()`，不用 left/top（17_性能.md R1、R4）。
- 状态只切换 class（`is-*`），不重写 innerHTML（R5）。
- 节点的总高度 = 38 + 端口区（8 + 行数 × 24）+ 控件区（有控件时 8 + n × 28 + 1）+ 状态脚（24 + 1，运行过才有）。**状态脚不在 idle 时出现，第一次运行时节点会变高 25**：这个变化用 0.16s 的高度过渡反而会让连线跟着抖，所以**直接出现**，连线同一帧重算。

### 1.2 端口行数

端口行数 = max(输入端口数, 输出端口数)。输入从第 0 行开始往下排，输出也从第 0 行开始往下排。分支节点的出口另有规则（见 3.8）。

## 2. 宽度、截断与自适应

| 规则 | 结论 |
|---|---|
| 宽度 | 只有两档：标准 236、紧凑 184。**不允许手动拖宽**：宽度固定才能保证端口坐标可以用常数算出来，也让整张图看起来整齐。文字放不下就截断，完整内容在悬停提示和检查器里看 |
| 高度 | 随端口数和控件数自动增长，没有上限。端口超过 8 行时，建议用户把它们收进一个子图 |
| 标题 | 1 行，末尾省略号。用户可以在检查器里改名，不限长度 |
| 类型行 | 1 行，**中间省略**（保留开头的节点类型和结尾的版本号），例如 `Agent · 执行结…果@1` |
| 端口名 | 输入和输出在同一行时，各占一半宽度减 8，末尾省略号；只有一边时可以占 70% |
| 端口类型标签 | 只在悬停时出现，不截断 |
| 控件里的值 | 下拉框中的值末尾省略号；数字不截断（宽度按最长值预留） |
| 状态脚文字 | 1 行，末尾省略号，tokens 数靠右，不截断 |

截断一律用 CSS（`text-overflow: ellipsis`），中间省略用 JS 预先算好，在节点渲染时计算一次。

## 3. 13 个原子节点逐个规格

端口色类：`hx-type-any / ctx / ref / list / tool / gen / ctrl / state`，分别对应 `--hx-type-*`。端口标注里的 `*` 表示必填，`[多]` 表示可以接多根，`[+]` 表示动态插口。

### 3.1 资源（紧凑 184）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `resource` / 按 kind 显示：「模型」「提示词」「列表」「常量」 |
| 输入 | 无 |
| 输出 | `ref` (ref) |
| 内联控件 | ① `kind` 分段/下拉 ② `value`：模型时为下拉（模型名），提示词时显示角色卡名并带「编辑」，列表时显示「3 项」 |
| 特殊外观 | 类型行显示具体值，例如 `模型 · gpt-x-large`；**没有状态脚**（资源节点不运行） |

### 3.2 Agent（标准 236）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `agent` / 「Agent」 |
| 输入 | `context*` (ctx)、`model*` (ref)、`prompt*` (ref)、`tools` (tool) [多] |
| 输出 | `result` (gen)。类型行显示 output_schema，例如 `Agent · 方案@1` |
| 内联控件 | ① `output_schema` 下拉 ② `lifecycle` 分段（用完即弃 / 长驻） |
| 特殊外观 | `lifecycle=resident` 时，类型行末尾加「· 长驻」，图标格加 1px `--hx-line-3` 内框 |

### 3.3 上下文装配（标准）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `context` / 「上下文装配」 |
| 输入 | `in_*` (any) [+]、`target_model*` (ref)、`summarizer` (ref) |
| 输出 | `context` (ctx)、`dropped` (list) |
| 内联控件 | ① `recipe` 下拉 ② `budget` 滑块（窗口比例 0.02–0.5，显示 `10% 窗口`） |
| 特殊外观 | 运行后状态脚显示 `装入 3.2k / 预算 4k`，接近上限时数字变为 `--hx-wait` |

### 3.4 工具（标准）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `tool` / 工具名，例如「检索」 |
| 输入 | `request` (any)；只在 `mode=direct` 时显示 |
| 输出 | `endpoint` (tool)，只在 endpoint 模式时显示；`result` (gen)，只在 direct 模式时显示 |
| 内联控件 | ① `tool` 下拉 ② `mode` 分段 ③ `risk` 徽标（只读，L0 中性、L1 中性、L2 `--hx-wait`、L3 `--hx-danger`） |
| 特殊外观 | L3 工具前面没有接人工节点时，节点外框显示 `--hx-danger` 虚线，头部显示 `warning` 图标；悬停提示「L3 工具前必须接人工节点」 |

### 3.5 扇出（标准，复合外观）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `fanout` / 「扇出」 |
| 输入 | `items` (list) 与 `n` 二选一（未使用的一个变暗）、`shared_*` (any) [+] |
| 输出 | `results` (list) |
| 内联控件 | ① `n` 数字步进 ② `concurrency` 数字步进 ③ `isolation` 开关 |
| 特殊外观 | 有内部子图，所以带**叠层边**（见 3.13）；运行时状态脚显示 `2 / 3 完成`，进度条分成 n 段 |

### 3.6 汇合（紧凑）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `join` / 「汇合」 |
| 输入 | `in_1, in_2, …` (any) [+]：已连接的插口数 + 1 个空插口 |
| 输出 | `collected` (list) |
| 内联控件 | ① `wait` 下拉（全部 / k 个 / 最先 / 超时） |
| 特殊外观 | 等待中时，状态脚显示 `收到 2 / 3` |

### 3.7 聚合（标准）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `aggregate` / 按 op 显示，例如「按比例分级」 |
| 输入 | `items*` (list) |
| 输出 | `result` (gen) |
| 内联控件 | ① `op` 下拉 ② `key` 文本（mono） |
| 特殊外观 | 头部 meta 区显示一个小的「确定」标记（mono 10.5，`--hx-text-3`），提示这个节点不调用模型、结果可以缓存 |

### 3.8 分支（紧凑）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `branch` / 「分支」 |
| 输入 | `value*` (gen)，位于第 0 行 |
| 输出 | 每个 case 一个出口 (ctrl)，**每个出口独占一行，从第 0 行起排**，出口名就是 case 名；最后一行是 `default`，用 `--hx-text-3` 显示 |
| 内联控件 | 无。条件表达式显示在每个出口行的悬停提示里，在检查器中编辑 |
| 特殊外观 | 运行后，**被选中的出口**端口点外加一圈 `--hx-accent` 光环，其他出口的端口名变为 `--hx-text-3`；从未被选中的出口连出的线进入"跳过"样式 |

### 3.9 循环（标准，复合外观）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `loop` / 「循环」 |
| 输入 | `init*` (gen) |
| 输出 | `final` (gen)、`exit` (ctrl) |
| 内联控件 | ① `max_rounds` 数字步进 ② `trigger` 分段（按轮 / 按事件） |
| 特殊外观 | 叠层边加内部缩略图；头部 meta 区的状态点换成**轮次环**：直径 16，2px 环，底色 `--hx-line-2`，已完成部分 `--hx-accent`（完成后 `--hx-ok`），环右侧显示 `2/5`（mono 11）。按事件触发时显示「事件 · 3」 |

### 3.10 账本（紧凑）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `ledger` / 「账本 · 读」或「账本 · 写」 |
| 输入 | `value` (state)，op 为 write / append / cas 时出现 |
| 输出 | `value` (state)；op=watch 时多一个 `changed` (ctrl) |
| 内联控件 | ① `op` 下拉 ② `path` 文本（mono） |
| 特殊外观 | 写入操作完成后状态脚显示 `v12 → v13`（版本号） |

### 3.11 人工（标准）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `human` / 「人工审批」 |
| 输入 | `request*` (any) |
| 输出 | 每种处理结果一个出口 (ctrl)，默认是 `通过`、`驳回` |
| 内联控件 | ① `mode` 下拉 ② `assignee`（文本） |
| 特殊外观 | **挂起时**状态脚换成审批条：左边显示「等待你的审批 · 2 分钟」，右边是「通过」（主按钮，紧凑）和「驳回」（次按钮，紧凑）。审批条的高度为 32，覆盖原来的状态脚。点按钮的效果和在对话里、在通知里审批完全一样，三处同步（见 12_模型操作者界面.md） |

### 3.12 子图端口（紧凑）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `port` / 按 role 显示：「入口」「出口」「摘要」「升级」 |
| 输入 | role 为 exit / summary / escalation 时有 `in` (any) |
| 输出 | role 为 entry 时有 `out` (any) |
| 内联控件 | ① `type` 下拉（端口类型） |
| 特殊外观 | 外框改为 1px `--hx-line-3` 虚线（表示这是边界）；入口节点固定在子图左侧，出口固定在右侧，不能删除，只能移动 |

### 3.13 子图引用（标准，复合外观）

| 项 | 规格 |
|---|---|
| 图标 / 默认标题 | `subgraph` / 子图名 |
| 输入 / 输出 | 根据子图内的子图端口自动生成，类型色与之对应 |
| 内联控件 | 子图暴露出来的参数，最多 3 个 |
| 特殊外观 | **叠层边**：节点后面错开叠两层同样大小的圆角矩形，分别向右下偏移 (4,4) 和 (8,8)，填充 `--hx-bg-3`，外框 `--hx-line-2`，透明度 1 和 0.6。在端口区和控件区之间插入一块 **缩略图**：高 64，背景 `--hx-bg-1`，用 canvas 画内部节点的小方块（`--hx-line-3`），右下角显示「12 个节点」（mono 10.5）。头部类型行显示 `子图 · 闭环迭代@v1.3`；使用 link 引用时显示 `@最新`，前面加一个 `--hx-model` 小点 |

叠层边的实现：

```css
.hx-node--stack::before, .hx-node--stack::after {
  content: ""; position: absolute; inset: 0; border-radius: inherit;
  background: var(--hx-bg-3); border: 1px solid var(--hx-line-2); z-index: -1;
}
.hx-node--stack::before { transform: translate(4px, 4px); }
.hx-node--stack::after  { transform: translate(8px, 8px); opacity: .6; }
```

## 4. 八种运行状态

| 状态 class | 外框 | 阴影 | 头部状态点（12px，见 06_图标.md 3.1） | 状态脚 | 头部附加 | 其他 |
|---|---|---|---|---|---|---|
| `is-idle` | `--hx-line-2` | `--hx-shadow-node` | 无 | 不显示 | — | — |
| `is-queued` | `--hx-line-3` | 同上 | 空心圆，`--hx-text-3` | 「排队中 · 第 3 位」，`--hx-text-3` | — | — |
| `is-running` | `--hx-accent-line` | `--hx-shadow-node` 加上 `0 0 0 3px var(--hx-accent-weak)` | 旋转圆弧，`--hx-accent-strong` | 进度条 `--hx-accent`，文字「生成中 62%」或「2 / 3 完成」，右侧 tokens 数 | 已运行时间，每秒刷新 | 出边进入流动样式 |
| `is-done` | `--hx-line-2` | `--hx-shadow-node` | 对勾，`--hx-ok` | 进度条变为 `--hx-ok`，1.2s 后淡出成 2px 绿线留在底边；文字显示「完成 · 1.2k tok」 | 总耗时 | — |
| `is-failed` | `--hx-danger` | 同上 | 叉，`--hx-danger` | `--hx-danger-weak` 底，一行错误摘要，右侧「重试」幽灵按钮 | 耗时 | 悬停摘要显示完整错误，点击打开日志 |
| `is-waiting` | 1px `--hx-wait` 虚线（`4 3`） | 同上 | 暂停符，`--hx-wait` | 「等待审批 · 2 分钟」或「等待外部回调」；人工节点换成审批条（3.11） | 已等待时间 | — |
| `is-skipped` | `--hx-line-1` | 无 | 横线，`--hx-text-3` | 不显示 | — | 整个节点 `opacity: .45`，入边和出边为跳过样式 |
| `is-cached` | `--hx-line-2` | `--hx-shadow-node` | 闪电，`--hx-text-3` | 「缓存命中」，`--hx-text-3` | 「0 ms」 | — |

浅色主题下的要点：运行中的外发光 `--hx-accent-weak` 在白底上比较淡，这是有意为之，不要加深；主要靠 `--hx-accent-line` 外框和旋转圆弧来表达。失败状态的状态脚是 `--hx-danger-weak` 浅红底配 `--hx-danger` 字。

### 4.1 状态转换

```
            ┌────────── 缓存命中 ──────────┐
            │                              ▼
 idle ──▶ queued ──▶ running ──▶ done    cached
            │          │  │  ▲
            │          │  │  └──── 继续 ────┐
            │          │  └──▶ waiting ─────┘
            │          ├──▶ failed ──(重试)──▶ queued
            │          └──▶ cancelled（显示为 failed 样式 + 「已取消」文字，`--hx-text-3`）
            └──▶ skipped（上游分支没有走到这里）
 任何状态 ──(重置 / 新一次运行)──▶ idle
```

### 4.2 过渡动画

| 变化 | 动画 |
|---|---|
| 外框颜色、阴影 | `transition: border-color, box-shadow var(--hx-t-2) var(--hx-ease)` |
| 状态点切换 | 新图标从 `scale(.6) opacity 0` 变到 `scale(1) opacity 1`，`--hx-t-2` |
| 进度条 | `transform: scaleX()`，`transition: transform 120ms linear`；`transform-origin: left` |
| 完成后绿条淡出 | 1.2s 后 `opacity` 从 1 到 0.35，`--hx-t-3` |
| 进入 skipped | `opacity` 过渡 `--hx-t-3` |
| 失败 | 外框颜色瞬间变化，不抖动、不闪烁 |

高频状态更新（每秒很多次）时，只在 rAF 中处理最后一个状态（见 17_性能.md）。

## 5. 模型相关标记

### 5.1 AI 签（模型创建或修改过）

```css
.hx-ai-tag { height: 16px; padding: 0 5px; border-radius: var(--hx-r-xs);
  font: 600 var(--hx-fs-10)/16px var(--hx-font-mono);
  color: var(--hx-model); background: var(--hx-model-weak); }
```

位于头部 meta 区最左侧。悬停时弹出提示框：

```
模型 · 2 分钟前 · 凭授权 M-12（2 档）
把执行池并发从 3 改为 5：上一轮执行池排队 38 秒，是最大的瓶颈。
[查看操作]  [撤销]
```

第一次出现时，节点外加一圈 `0 0 0 3px var(--hx-model-weak)` 光环，持续 600ms 后淡出。

### 5.2 幽灵节点（模型提议，尚未采纳）

| 属性 | 值 |
|---|---|
| 主体 | `opacity: .78`；背景 `--hx-bg-3` |
| 外框 | 1.5px `--hx-model-line` 虚线（`5 4`） |
| 阴影 | 无 |
| 提议条 | 头部下方插入一行，高 28，背景 `--hx-model-weak`：左边 `ai` 图标加一句理由（末尾省略），右边「采纳」「拒绝」两个紧凑小按钮（幽灵样式，`--hx-model` 字） |

浅色主题下 `opacity` 用 0.78（深色用 0.72），因为白底上太淡会看不清。

### 5.3 提议删除

节点保持原样，外框改为 1.5px `--hx-danger` 虚线，标题加删除线，提议条背景改为 `--hx-danger-weak`，文字为「模型提议删除 · 理由」；它的连线变为 `--hx-danger` 虚线，透明度 0.6。

## 6. 交互状态

| 状态 | 表现 | 规则 |
|---|---|---|
| 悬停 | 外框变为 `--hx-line-3` | 不加阴影、不放大、不改背景 |
| 选中 | `outline: 1.5px solid var(--hx-focus); outline-offset: 2px` | 不改变节点尺寸；选中的节点 z 方向提高一层 |
| 多选 | 同上 | — |
| 框选预览 | 同选中，透明度 0.6 | — |
| 拖动中 | 阴影换成 `--hx-shadow-node-drag`；`cursor: grabbing` | **不放大、不旋转**；松手后阴影恢复，时长 `--hx-t-2` |
| 键盘聚焦 | 同选中，外加 `0 0 0 4px var(--hx-model-weak)` | 只在键盘导航时显示（`:focus-visible`） |
| 禁用（bypass，不参与运行） | 整个节点 `opacity: .5`；头部类型行末尾加「· 已停用」；斜纹背景 `repeating-linear-gradient(135deg, transparent 0 6px, var(--hx-line-1) 6px 7px)` | 连线照常显示，运行时直接把输入传给输出 |
| 锁定（不能移动或编辑） | 头部 meta 区显示 `lock` 图标（`--hx-text-3`） | 可以选中、查看，不能拖动、删除、改参数；尝试操作时，在节点附近弹出提示「这个节点已锁定」 |
| 内核锁定的参数 | 参数行显示 `lock` 图标，控件为只读样式 | 见 10_控件库.md |

## 7. 浅色主题专项说明

| 问题 | 规范 |
|---|---|
| 白色节点放在浅灰画布上，层次靠什么区分 | 1px `--hx-line-2` 外框，加上 `--hx-shadow-node` 的两层柔和阴影。不要只用阴影、不画外框，否则节点边缘会发虚 |
| 节点内部分区 | 只用 1px `--hx-line-1` 分隔线，不要给头部换背景色 |
| 图标格 | 固定用 `--hx-bg-5`（浅灰），和白色主体形成对比 |
| 端口点的缝隙 | 2px 描边的颜色用 `--hx-bg-3`（白），否则端口点会和节点外框粘在一起 |
| 琥珀色文字 | 任何琥珀色**文字或细线**都用 `--hx-accent-strong`；`--hx-accent` 只用于面积较大的填充（进度条、主按钮） |
| 选中描边 | `--hx-focus` 在浅色下是近黑色，对比足够，不要改成蓝色 |
| 拖动阴影 | `--hx-shadow-node-drag` 在浅色下更明显，这是给出"被拿起"反馈的主要手段 |
