# 14 状态反馈与异常

> 本文规定：系统在什么情况下用哪种形式告诉用户发生了什么，以及出错后用户怎么恢复。
> 相关文档：08_节点（节点状态）、10_控件库（通知、对话框）、12_模型操作者界面、15_文案与术语。

---

## 1. 六种反馈形式

| 形式 | 位置 | 持续 | 打断程度 | 典型内容 |
|---|---|---|---|---|
| **行内提示** | 出问题的控件下方或旁边 | 直到问题解决 | 无 | 参数超出范围、YAML 第 12 行语法错误 |
| **节点状态** | 节点外框、状态点、状态脚 | 跟随运行状态 | 无 | 运行中、失败、等待审批 |
| **通知 toast** | 展开态右上角，堆叠 | 4 秒，悬停暂停；带操作的 8 秒 | 低 | 已撤销、已连接、模型修改了 3 处 |
| **对话消息** | 对话中间栏 | 永久 | 低 | 运行完成摘要、需要审批、模型的解释 |
| **顶部横幅** | 顶部条下方，全宽 32px | 直到状态解除 | 中 | 离线、急停中、正在回放旧版本 |
| **弹窗** | 居中模态 | 直到用户选择 | 高 | 删除含 12 个节点的子图、合并有冲突 |

### 1.1 决策表：该用哪一种

按顺序判断，命中第一条即停止：

| # | 条件 | 用 |
|---|---|---|
| 1 | 操作不可撤销，且影响超过一个节点或外部世界 | 弹窗 |
| 2 | 影响整个会话的持续状态（离线、急停、回放、只读） | 顶部横幅 |
| 3 | 问题绑定在某个具体控件或输入上 | 行内提示 |
| 4 | 问题绑定在某个节点的运行上 | 节点状态 + （失败或挂起时）对话消息 |
| 5 | 需要用户之后回看，或是一次运行的结论 | 对话消息 |
| 6 | 一次性的操作结果，用户可能想撤销 | 通知（带「撤销」） |
| 7 | 以上都不是 | 不提示。成功的常规操作不需要反馈 |

**规则**：
- 同一件事只用一种主形式。节点失败时，节点变红是主形式，对话里补一条可以，但不再弹通知。
- 审批是例外，必须**三处同步**：节点上、对话里、通知里。任意一处处理后，另外两处立刻变为“已处理”。
- 通知最多同时显示 3 条，多出的合并成「还有 N 条」。

### 1.2 严重级别与令牌

| 级别 | 图标 | 底 | 字/图标 | 用于 |
|---|---|---|---|---|
| 信息 | info | `--hx-bg-2` | `--hx-text-1` | 中性结果 |
| 成功 | check | `--hx-ok-weak` | `--hx-ok` | 只在有意义时用，如“运行完成” |
| 注意 | pause | `--hx-wait-weak` | `--hx-wait` | 挂起、等待、预算接近上限 |
| 错误 | x | `--hx-danger-weak` | `--hx-danger` | 失败、拒绝 |
| 模型 | ai | `--hx-model-weak` | `--hx-model` | 模型做了什么 |

浅色主题下，弱色底上的文字一律用实色令牌；琥珀色用作文字时必须用 `--hx-accent-strong`。

## 2. 加载状态

| 等待时间 | 表现 |
|---|---|
| < 150ms | 什么都不显示（避免闪烁） |
| 150ms – 1s | 旋转弧：14px，2px 线宽，`--hx-text-3`，按钮内则替换文字 |
| 1s – 10s | 骨架屏（结构已知时）或确定进度条（进度已知时） |
| > 10s | 进度条 + 预计剩余时间 + 「在后台继续」 |

### 2.1 骨架屏
- 用于：节点库首次加载、检查器加载参数 schema、运行抽屉加载历史。
- 形状与真实内容一致，圆角同真实组件。底色 `--hx-bg-4`，上面一道 `--hx-bg-5` 的扫光，1.2s 循环，用 `transform: translateX` 实现。
- reduced-motion 下去掉扫光，只留静态块。
- 骨架最多显示 6 行，不要铺满整个面板。

### 2.2 旋转弧
```html
<svg class="hx-spin" viewBox="0 0 16 16" aria-hidden="true">
  <circle cx="8" cy="8" r="6" fill="none" stroke="currentColor" stroke-width="2"
          stroke-dasharray="28 10" stroke-linecap="round"/>
</svg>
```
`.hx-spin{animation:hx-rot .8s linear infinite}`。节点运行中的状态点使用同一组件，颜色 `--hx-accent`。

### 2.3 进度条
- 高 4px（节点状态脚为 3px），轨道 `--hx-bg-5`，填充 `--hx-accent`（运行中）或 `--hx-ok`（完成瞬间）。
- 用 `transform: scaleX(p)`，`transform-origin:left`，过渡 `--hx-t-2`。
- 进度未知时用不确定进度：30% 宽的块左右往返，1.4s。
- 进度只能前进，后端回报的值小于当前值时忽略。

## 3. 空状态

所有空状态由三部分组成：一行标题（`--hx-fs-14` / 500）、一行说明（`--hx-fs-12` / `--hx-text-2`）、至多两个操作。**插图规则**：只用 06_图标 里的线性图标放大到 32px，颜色 `--hx-text-3`，不使用彩色插画。

| 场景 | 标题 | 说明 | 操作 |
|---|---|---|---|
| 空画布 | 从一个节点开始 | 从左侧拖入节点，按 A 快速添加，或者在下面告诉模型你想做什么 | 「载入模板」「快速添加 A」 |
| 空子图 | 这个子图还是空的 | 入口和出口已经放好，把节点拖到它们之间 | 「返回上一层」 |
| 节点库搜索无结果 | 没有找到「{q}」 | 试试按类别浏览，或者让模型帮你写一个自定义节点 | 「清除搜索」「让模型起草」 |
| 无运行记录 | 还没有运行过 | 按 ⌘Enter 运行，时间线和日志会出现在这里 | 「运行」 |
| 无选中（检查器） | 检查器默认隐藏，不显示空状态 | — | — |
| 操作历史为空 | 还没有修改 | 你和模型的每一步修改都会记录在这里，可以撤销 | — |
| 无待审批 | 没有需要你处理的事 | — | — |

空画布的提示居中显示，画布仍可正常平移缩放；一旦有节点就立即消失（淡出 `--hx-t-2`）。

## 4. 错误：呈现与恢复

每种错误都写清四项：**触发**、**呈现**、**文案**、**恢复路径**。

### 4.1 连线错误
| 项 | 内容 |
|---|---|
| 触发 | 拖线到不兼容端口；连出不经过循环节点的环；连到自身 |
| 呈现 | 拖线过程中预览线变为 `--hx-danger` 虚线，光标旁 8px 处浮出原因标签；松开后不建立连线，不弹通知 |
| 文案 | 「列表 不能接到 上下文包」「环只能通过循环节点形成」「不能连到自己」 |
| 恢复 | 无需恢复，线自动消失。类型不兼容时，若存在适配节点，标签末尾显示「按 Enter 插入转换节点」 |

### 4.2 参数校验错误
| 项 | 内容 |
|---|---|
| 触发 | 输入超出 range、类型不对、必填为空 |
| 呈现 | 控件外框变 `--hx-danger`；下方 `--hx-fs-12` 红字；节点头部出现红色小三角，悬停显示 |
| 规则 | 失焦或回车时校验，不在每次按键时报错；数字步进越界时直接夹到边界并抖动 2px（reduced-motion 下不抖） |
| 恢复 | 改正即消失；「恢复默认」链接 |

### 4.3 YAML 解析错误
| 项 | 内容 |
|---|---|
| 呈现 | 出错行行号变红，行背景 `--hx-danger-weak`；编辑框底部一条错误栏：「第 12 行：缩进不一致」；「应用」按钮禁用 |
| 规则 | 解析错误时画布保持上次有效的状态，不部分应用 |
| 恢复 | 改正；「放弃修改」回到画布当前状态 |

### 4.4 运行失败
| 项 | 内容 |
|---|---|
| 呈现 | 节点进入 failed：外框 `--hx-danger`，状态脚显示一行错误摘要（最多 40 字）和「重试」「查看日志」；运行抽屉对应行变红；对话里一条消息：哪个节点、什么原因、建议 |
| 下游 | 下游节点保持 idle，并以 0.45 透明度显示“因上游失败未运行” |
| 恢复 | 「重试」只重跑该节点（带同一幂等键）；「从此处重跑」；「让模型诊断」 |

### 4.5 网络断开 / 离线
见第 6 节。

### 4.6 模型调用失败
| 场景 | 呈现 | 恢复 |
|---|---|---|
| 限流 429 | 节点状态脚：「模型限流，12 秒后自动重试（第 2/3 次）」，倒计时 | 自动重试；「立即重试」；「换模型」 |
| 超时 | 状态脚：「模型 60 秒无响应」 | 自动重试一次，之后失败 |
| 输出格式不合格 | 先自动修复，不提示；修复失败重试；仍失败则节点 failed：「输出不符合 方案@1：缺少 core_approach」 | 「查看原始输出」「重试」 |
| 编排模型失败 | 顶部「模型正在编辑…」胶囊变红：「模型编辑失败」，对话里说明 | 「重试」，已做的修改保留并可撤销 |

### 4.7 授权不足
| 项 | 内容 |
|---|---|
| 触发 | 模型的操作超出当前档位或授权书范围 |
| 呈现 | 不是错误，按 12_模型操作者界面 处理：1 档变为提议；2–3 档变为待审批卡片；运行中则节点 waiting |
| 文案 | 「模型想新增 L2 工具“发邮件”，当前授权最高 L1」 |
| 恢复 | 「仅本次批准」「提升档位」「拒绝」 |
| 人遇到 | 人的操作不会被授权拦截。只读回放中人试图编辑时，顶部横幅「正在查看历史版本，编辑前请返回最新」 |

### 4.8 版本冲突
| 项 | 内容 |
|---|---|
| 触发 | 人和模型（或两个模型）同时修改同一节点，基础版本号不一致 |
| 呈现 | 后到的修改不直接应用，进入草稿分支；通知：「你和模型同时改了“执行池”，你的修改已保留，模型的修改放到了草稿」 |
| 恢复 | 「查看差异」→ 合并对话框，逐项选择保留哪一方 |
| 规则 | 人的修改永远优先保留在主线 |

## 5. 确认对话框

### 5.1 什么时候用
只在同时满足“**不能撤销**”或“**影响面大**”时使用。能撤销的操作一律直接执行，用通知提供撤销。

| 操作 | 是否确认 |
|---|---|
| 删除单个节点、连线 | 否（可撤销） |
| 删除含 ≥10 个节点的子图 | 是 |
| 清空当前层 | 是 |
| 运行中修改授权到 4 档 | 是 |
| 关闭污染标记 | 是 |
| 批准 L3 工具调用 | 是（且需要再次点击，不能回车默认确认） |
| 合并分支 | 是（显示差异） |
| 解除急停 | 否 |

### 5.2 文案结构
```
标题：动作 + 对象          删除「执行池」子图？
正文：后果，一到两句       里面的 12 个节点和 18 条连线会一起删除。运行记录保留。
按钮：[取消]  [删除子图]   主按钮写具体动词，不写“确定”
```
- 危险操作的主按钮用危险样式，放在右侧，**默认焦点在“取消”**。
- 不写“你确定吗”。不用双重否定。

## 6. 离线与重连

| 阶段 | 呈现 | 行为 |
|---|---|---|
| 连接抖动 < 3s | 不提示 | 后台重试 |
| 断开 ≥ 3s | 顶部横幅（`--hx-wait-weak`）：「连接已断开，正在重连… 修改会保存在本地」 | 编辑照常，Op 进入本地队列；运行中的节点显示“状态未知”灰色虚线 |
| 重连中 | 横幅显示重试倒计时和「立即重试」 | 指数退避 1s、2s、4s… 上限 30s |
| 重连成功 | 横幅变为成功色 2 秒后收起：「已重新连接，同步了 7 处修改」 | 按序回放本地 Op；从引擎拉取运行事件补齐 |
| 同步冲突 | 按 4.8 版本冲突处理 | — |
| 引擎侧运行继续 | 引擎是持久化执行，断网不影响后台运行；重连后时间线补全 | — |

## 7. 长任务的进度与预计时间

- 运行总进度 = 已完成节点权重 / 总权重；循环节点按 已完成轮次 / 最大轮数 计入，但一旦达成即视为 100%。
- 预计时间只在已运行 ≥ 20 秒且已完成 ≥ 3 个节点后显示，否则显示“估算中”。格式「约 3 分钟」，小于 1 分钟显示「不到 1 分钟」。数值变化超过 20% 才更新，避免跳动。
- 顶部条显示：`运行中 · 第 2/5 轮 · 约 3 分钟 · 128k / 500k tokens`。
- 超过 2 分钟的运行，在对话里每个里程碑（每轮结束、审批、失败）发一条简短消息，不按时间刷屏。
- 用户离开页面后再回来：对话顶部显示「你离开期间：完成 2 轮，1 项待审批」。
