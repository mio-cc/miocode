# 02 · 色彩系统与主题

> **默认主题是浅色。** 深色是可选项。所有设计稿、截图、验收都以浅色为基准，再检查深色。

## 1. 总体思路

- 浅色下，**层级靠"白面板浮在浅灰底上"+ 外框 + 阴影**，而不是靠颜色变亮。
- 颜色分三类：**中性**（表面、线、文字）、**语义**（状态与身份）、**类型**（端口与连线）。三类互不借用。
- 页面里禁止裸色值，全部引用 `tokens.css`。

## 3. 浅色下的表面层级

```
--hx-bg-0  应用底（侧栏、对话）      ░░░░░░░░░░░░░░░░░░░░░░░░
--hx-bg-1  画布底 + 点阵              ▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒▒
--hx-bg-3  节点：白 + line-2 + shadow-node   ┌──────┐
--hx-bg-2  浮动面板：白 + shadow-float        ┌──────────┐
           菜单/命令面板：白 + shadow-pop      ┌────────┐
```

规则：
1. 浅色下 `--hx-bg-2` 与 `--hx-bg-3` 同为白色，**区分靠阴影**：节点用 `--hx-shadow-node`，面板用 `--hx-shadow-float`。
2. 白色元素放在白色元素上（例如面板里的卡片）时，内层用 `--hx-bg-4` 底或 `--hx-line-1` 分隔，不再叠阴影。
3. 禁止为了"分层"把面板改成淡灰色。浅灰只用于底层与输入框。
4. 深色下反过来：越往上越亮，阴影辅助。

## 4. 语义色使用规则

| 颜色 | 可以用于 | 禁止用于 |
|---|---|---|
| accent | 运行中状态、主按钮底、流动光点、当前主路径连线 | 普通链接、装饰、选中态 |
| accent-strong | 浅色下的琥珀文字、细线、图标（如"运行中 62%"） | 大面积底色 |
| ok | 完成状态点、通过徽标、验收通过 | 普通成功提示以外的装饰 |
| danger | 失败、删除按钮、急停条、不兼容连线 | 仅为吸引注意 |
| wait | 挂起、等待审批、需要人处理 | 警告以外的强调 |
| model | **只用于模型相关**：AI 签、幽灵节点、模型光标、模型日志、框选 | 普通按钮、链接、品牌色 |
| focus | 选中环、键盘焦点环 | 文字 |

**accent 与 accent-strong**：浅色背景下 `--hx-accent`（亮琥珀）对白只有约 2:1，不能作文字或 1px 线。凡是琥珀色作为**前景**（文字、图标、细线、进度百分比），浅色下必须用 `--hx-accent-strong`；作为**底色**（主按钮、进度条填充、光点）用 `--hx-accent`。深色下两者相同。

主按钮写法：

```css
.hx-btn--primary { background: var(--hx-accent); color: var(--hx-text-inv); }
.hx-node.is-running .hx-node__status { color: var(--hx-accent-strong); }
.hx-node.is-running { border-color: var(--hx-accent-line); box-shadow: var(--hx-shadow-node), 0 0 0 3px var(--hx-accent-weak); }
```

## 5. 状态组合表（弱底 + 实色字）

| 状态 | 底 | 字 / 图标 | 外框 |
|---|---|---|---|
| 运行中 | `--hx-accent-weak` | `--hx-accent-strong` | `--hx-accent-line` |
| 完成 | `--hx-ok-weak` | `--hx-ok` | — |
| 失败 | `--hx-danger-weak` | `--hx-danger` | `--hx-danger` |
| 挂起 | `--hx-wait-weak` | `--hx-wait` | `--hx-wait`（虚线） |
| 模型 | `--hx-model-weak` | `--hx-model` | `--hx-model-line` |
| 中性 / 跳过 | `--hx-bg-4` | `--hx-text-2` | `--hx-line-2` |

徽标、状态胶囊、通知图标都按这张表取色，不自行组合。

## 6. 端口类型色规则

- 连线颜色 = **源端口**类型色。
- 新增数据类型时，**必须映射到上面 8 类之一**，不允许新增颜色。映射依据：它在流程中扮演什么角色（引用 / 列表 / 上下文 / 工具 / 控制 / 状态 / 泛型 / 任意）。
- 映射写在类型定义里：`color_class: list`。
- 类型色只用于端口圆点、连线、类型标签文字，不用于节点头部或背景。

## 7. 主题切换

```html
<html data-theme="light">  <!-- 默认 -->
```

```ts
const KEY = 'hx-theme'; // 'light' | 'dark' | 'system'
function applyTheme(pref = localStorage.getItem(KEY) ?? 'light') {
  const dark = pref === 'dark' ||
    (pref === 'system' && matchMedia('(prefers-color-scheme: dark)').matches);
  document.documentElement.dataset.theme = dark ? 'dark' : 'light';
}
matchMedia('(prefers-color-scheme: dark)').addEventListener('change', () => applyTheme());
```

- 默认值是 `light`；"跟随系统"是用户主动选择的选项，不是默认。
- 选择写入 `localStorage`，在 `<head>` 里内联执行，避免首屏闪烁。
- 切换时不做全局颜色过渡动画（避免所有元素同时渐变造成卡顿），直接切换。
- 画布里用 JS 绘制的内容（小地图 canvas、连线颜色缓存）必须在主题切换时重新读取 CSS 变量。

## 8. 对比度检查

| 内容 | 最低对比度 |
|---|---|
| 正文、数值、端口名 | 4.5:1 |
| 大字（≥ 16px 或 14px 粗体）、图标、状态点 | 3:1 |
| 外框、分隔线 | 不要求，但选中环必须 ≥ 3:1 |

方法：DevTools 颜色选择器的对比度提示；或用脚本读取计算样式批量检查。两套主题都要测。

## 9. 常见错误

| 错误 | 正确做法 |
|---|---|
| 浅色下用 `--hx-accent` 写"运行中"文字，看不清 | 用 `--hx-accent-strong` |
| 给面板加灰底来区分层级 | 白底 + `--hx-shadow-float` |
| 节点头部按类别涂色 | 中性头部，用图标区分 |
| 用 `--hx-model` 做普通按钮 | 模型色只给模型 |
| 写 `color: #333` | 用 `--hx-text-1/2/3` |
| 深色下调好的阴影直接用到浅色 | 两套阴影令牌不同，不要混用 |
| 新类型加了第 9 种颜色 | 映射到现有 8 类 |
