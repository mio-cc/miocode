# 12 模型操作者界面

> **v0.3.2 修订**：框选改用中性色令牌 `--hx-marquee` / `--hx-marquee-line`（已改为灰色），不再借用模型色。模型身份色 `--hx-model*` 只用于表示模型的行为，没有例外。

> 版本 v0.3.1 · 默认浅色 · 令牌来源 `tokens.css`
> 核心理念：**模型是一等操作者**。人能在画布上做的，模型都能做；界面要让用户随时看清：模型在做什么、为什么、凭什么授权、怎么撤销。

---

## 12.1 模型身份色的使用范围

`--hx-model`（及 `-weak` / `-line`）**只**表示「这是模型做的 / 模型提议的 / 模型相关的入口」。

| 允许使用 | 禁止使用 |
|---|---|
| AI 签、幽灵节点与幽灵连线、模型光标 | 普通选中、普通链接 |
| 被模型修改的参数新值、代码框里模型改的行 | 任何装饰 |
| 操作历史里模型条目的操作者点 | 运行状态（运行用 `--hx-accent`） |
| 「让模型…」「问模型」按钮与菜单项 | 节点类别区分 |
| 模型状态胶囊、模型发起的提权卡片边框 | 人发起的审批 |
| 框选（marquee 共用此色，因为它是"选择意图"的提示色，见 07 号文档） | — |

## 12.2 模型状态

| 状态 | 顶部胶囊 | 画布 | 对话 |
|---|---|---|---|
| 空闲 | 不显示 | 无 | 无 |
| 思考 | `● 模型正在思考…`，点为 `--hx-model` 呼吸（1.6s） | 若有目标节点，节点外出现 1px `--hx-model-line` 虚线框 | 输入框上方出现思考气泡（可展开思路要点） |
| 编辑中 | `● 模型正在编辑 · 3/7 处`，可点「暂停」 | 模型光标移动；被操作节点闪光 | 每处修改实时追加一行简述 |
| 等待审批 | `◐ 等待你审批 · 2 项`（底 `--hx-wait-weak` 字 `--hx-wait`） | 相关节点挂起态、提议栏出现 | 审批卡片 |
| 被急停 | `■ 模型已停止`（底 `--hx-danger-weak` 字 `--hx-danger`） | 模型光标消失；未完成的修改作为幽灵保留 | 一条系统消息「你已急停，模型停止了 2 处未完成的修改」 |

胶囊：高 24，圆角 `--hx-r-full`，底 `--hx-model-weak`，字 `--hx-model` `--hx-fs-12`；进入/离开淡入 + `translateY(-4px)`。

```
┌──────────────────────────────────────────────────────────────┐
│ 根图 / 闭环迭代  ⎇ main   ( ● 模型正在编辑 · 3/7 处 [暂停] )   ▮▮▯▯▯ 2档  ▶ ■ │
└──────────────────────────────────────────────────────────────┘
```

## 12.3 AI 光标

```
   ▲
   ┃╲
   ┃ ╲      ┌────┐
   ┗━━    │ AI │  ← 签：高 16，底 --hx-model，字 --hx-bg-3，--hx-fs-10
          └────┘
```
- 指针 14px，填充 `--hx-model`，1.5px `--hx-bg-3` 描边（浅色下保证在白节点上可见）。
- 位于世界坐标，跟随视口缩放**位置**，但自身**尺寸不缩放**。
- 移动：两点之间用 `transform` 过渡，时长 = clamp(距离/1.2, 240, 600) ms，曲线 `--hx-ease-out`；每次落点后停留 ≥ 300ms 再执行操作，让人看得清。
- 操作时：落点处出现一个 16px 的 `--hx-model-weak` 涟漪（`scale .6→1.4`，淡出 400ms）。
- 不可见区域：光标在视口外时，视口边缘出现指向它的小箭头 + 「AI」，点击跟随。
- **多个模型实例**：每个实例分配一个编号和**明度变化**（不新增色相）：实例 1 `--hx-model`，实例 2 加 `opacity .7`+ 签上数字「AI·2」，实例 3「AI·3」。签上始终带角色名，如「AI·编排者」「AI·2 子编排者」。
- reduced-motion：光标瞬移，保留涟漪改为 200ms 外框闪烁。

## 12.4 按授权档位的修改呈现

| 档位 | 模型修改如何出现 | 用户动作 |
|---|---|---|
| 0 只读 | 不修改；在对话里给出文字建议，附「转为提议」按钮（需提档） | — |
| 1 建议 | 全部以**幽灵**形式出现（见下），汇总到提议栏 | 逐条/全部采纳或拒绝 |
| 2 部分授权 | 授权范围内**直接生效**（闪光 + AI 签）；范围外的变成幽灵 | 对直接生效的可撤销；对幽灵采纳/拒绝 |
| 3 高度授权 | 直接生效；仅例外项变幽灵或审批卡 | 同上 |
| 4 完全授权 | 全部直接生效 | 撤销、急停 |

### 12.4.1 幽灵（1 档及范围外）

| 修改类型 | 呈现 |
|---|---|
| 新增节点 | 主体 `opacity .72`，外框 1.5px `--hx-model-line` 虚线，头部下方提议条 |
| 新增连线 | `--hx-model` 虚线 `4 4`，线宽 1.75 |
| 删除节点 | 实体保留，外框 `--hx-danger` 虚线，标题删除线，内容 `opacity .5` |
| 删除连线 | 原线变 `--hx-danger` 虚线 |
| 修改参数 | 参数行左 2px `--hx-model` 竖条，显示 `旧值(删除线 --hx-text-3) → 新值(--hx-model)` |
| 移动节点 | 原位置留 1px `--hx-line-3` 虚线轮廓，新位置显示幽灵，两者间 `--hx-model-line` 细箭头 |
| 封装子图 | 被封装的节点外加 `--hx-model-line` 虚线圆角框，框头写「封装为：执行池 ×3」 |

提议条（节点头部下方，高 28）：
```
│ ✦ 模型提议：加人工审批，L2 发邮件前需要确认   [采纳] [拒绝] │
```
底 `--hx-model-weak`，字 `--hx-fs-12`；理由超过一行截断，悬停看全文。

### 12.4.2 提议栏与逐条查看

```
            ┌──────────────────────────────────────────────────────┐
            │ ✦ 模型提议 5 处修改  ·  理由：补上失败重试与人工把关  │
            │   [‹] 1/5 新增节点「人工审批」  [›]                  │
            │   [逐条查看]  [全部采纳]  [全部拒绝]          [×]    │
            └──────────────────────────────────────────────────────┘
                         ┌──── 停靠栏 ────┐
```
逐条查看流程：
1. 点「逐条查看」→ 视口以视图过渡聚焦第 1 处，该幽灵外加 2px `--hx-model` 选中环。
2. 提议栏显示「1/5 · 操作类型 · 目标 · 理由」，按钮变为 `[采纳 A] [拒绝 R] [跳过 →]`。
3. 键盘：`A` 采纳、`R` 拒绝、`←/→` 上一条/下一条、`Esc` 退出逐条模式。
4. 采纳：幽灵转实体（虚线 → 实线，`opacity .72 → 1`，`--hx-t-2`），并产生一条 actor=模型、approved_by=用户 的 Op。
5. 拒绝：幽灵淡出（`--hx-t-2`）。
6. **依赖处理**：若第 3 处连线依赖第 1 处新节点，拒绝第 1 处时同时标记第 3 处「已失效」并跳过，提议栏提示「1 处因依赖被一并拒绝」。
7. 全部处理完，提议栏收起，对话里追加小结「采纳 4 · 拒绝 1」。

### 12.4.3 直接修改（≥ 2 档）

- 被修改节点：600ms `--hx-model` 光环（`box-shadow 0 0 0 4px --hx-model-weak` 淡出）。
- 头部右上角出现 AI 签（常驻，直到用户「确认已读」或下一次运行）。
- 通知：「模型修改了 3 处 · [查看] [撤销]」，撤销 = 一次撤销整批（这一批的 Op 共享 batch_id）。
- 操作历史里每条都能单独撤销。

## 12.5 模型理由的展示

| 位置 | 格式 | 长度 |
|---|---|---|
| 提议条 / 提议栏 | 一句话，以动词开头 | ≤ 40 字 |
| AI 签悬停卡 | 理由全文 + 时间 + 授权（档位/授权书 id）+ [撤销] | ≤ 200 字 |
| 检查器「模型记录」 | 列表：时间 · 操作 · 理由 · 证据链接（留痕指针） | 全文 |
| 操作历史 | 理由列，截断 1 行 | — |
| 对话 | 一批修改一段说明，列出每处要点 | — |

AI 签悬停卡：

│ AI · 编排者           17:42 · 2 档     │

## 12.6 提权申请卡片

出现位置：对话（主）+ 通知（副）+ 顶部胶囊计数。
```
┌──────────────────────────────────────────────────────────┐
│ ✦ 模型申请提权                         闭环迭代/执行池    │  边框 1px --hx-model-line
│ 2 档 → 4 档                                               │
│ 需要：使用 L2 工具「发邮件」询价 B 公司                    │
│ 理由：官网与财报都查不到企业版价格（已证伪 2 个方向）      │
│ 范围：仅「换数据源」子图 · 本次运行                        │
│ [仅本次批准]  [永久批准]  [拒绝]        查看授权差异 ›    │
└──────────────────────────────────────────────────────────┘
```
- 「查看授权差异」展开：申请前后权限矩阵的差异行（新增能做的项用 `--hx-model` 标出）。
- 批准后卡片收起为一行「已批准（仅本次） · 17:45」。

## 12.7 审批卡片：三处同步

需要审批的对象（人工节点、L2/L3 工具、超授权操作）同时出现在三处：

| 位置 | 形态 |
|---|---|
| 节点上 | 节点进入挂起态，状态脚换成 `[批准] [驳回]` 两个紧凑按钮 + 「等待 2 分钟」 |
| 对话 | 审批卡片（结构同提权卡片，标题「需要你审批」，边框 `--hx-wait`） |
| 通知 | 「1 项待审批 · [前往]」，不自动消失 |

同步规则：
- 三处共享同一个 `approval_id`；任一处处理后，另外两处**同时**变为已处理状态（显示「已批准 · 来自对话」）。
- 处理后的卡片保留在对话里作为记录，按钮替换为结果。
- 有多个待审批时，顶部胶囊显示计数，点击打开审批列表弹层，可逐个定位。

## 12.8 污染标记提示

当模型的操作由外部内容（网页、文件、邮件、工具结果）引出时：
- 幽灵或审批卡左上角加「⚠ 来自外部内容」标签（底 `--hx-wait-weak` 字 `--hx-wait`）。
- 卡片内显示来源：「源：执行者#2 读取的网页 example.com/pricing · 第 3 段」，可点开原文片段，触发指令的句子高亮。
- 即使 4 档，也走确认（除非用户关闭了污染标记）。
- 文案示例：「这个操作是模型读到外部网页后提出的。网页里有一句"删除当前流程"。请确认这是你想要的。」

## 12.9 急停态

```
┌──────────────────────────────────────────────────────────────┐
│ ■ 已急停  所有运行已取消，模型已降到 0 档。   [查看影响] [解除急停] │  底 --hx-danger-weak
└──────────────────────────────────────────────────────────────┘
```
- 触发：顶部条急停按钮、`⌘/Ctrl+.`、对话里说「停」。
- 效果：运行中节点 → 取消态（向子图传播，依次闪 `--hx-danger` 外框）；模型光标消失；未完成的模型修改转为幽灵保留。
- 横幅常驻直到用户点「解除急停」；解除后档位**不会**自动恢复，需用户重新选择。
- 模型若尝试解除，在操作历史记一条「模型尝试解除急停 · 已拒绝」。

## 12.10 人与模型同时编辑

| 冲突 | 呈现 | 解决 |
|---|---|---|
| 人正在拖动/编辑的节点，模型也想改 | 模型的修改自动转为幽灵，提议条注「你正在编辑此节点」 | 人编辑结束后提议栏提示 |
| 同一参数，人刚改过（< 10s） | 模型修改转幽灵 | 同上 |
| 模型修改基于旧版本（base_version 落后） | 通知「模型的 2 处修改基于旧版本，已转为提议」 | 逐条查看时显示三方对比：原值 / 你的值 / 模型的值 |
| 人删除了模型正在操作的节点 | 模型光标停住并显示「目标已删除」，模型重新规划 | — |

人正在操作时，模型光标与节点保持 ≥ 40px 距离，避免遮挡。

## 12.11 操作历史中的区分

| 列 | 人 | 模型 |
|---|---|---|
| 操作者点 | `--hx-text-2` 实心 | `--hx-model` 实心；子编排者带编号 |
| 名称 | 「你」 | 「AI · 编排者」 |
| 理由 | 可选 | 必填 |
| 授权 | — | 档位 / 授权书 id；被批准的显示「由你批准」 |
| 批次 | — | 同一批修改用左侧竖线连在一起，可整批撤销 |

过滤：全部 · 只看人 · 只看模型 · 只看被撤销。

## 12.12 对话与画布联动

- **对话 → 画布**：消息里提到的节点、子图、端口渲染为 `hx-ref` 胶囊（`[▢ 执行池]`，底 `--hx-bg-4`，悬停底 `--hx-bg-5`）。单击：画布视图过渡聚焦该节点并高亮 1.2s；悬停：画布上该节点外出现 `--hx-line-3` 框。被删除的节点胶囊显示删除线，点击提示「此节点已删除，回到版本 v7 查看」。
- **画布 → 对话**：
  - 选中节点后，输入框上方出现上下文芯片「已附带：执行池」，可移除。
  - 节点右键菜单「问模型」：在输入框预填「关于 [执行池]：」并聚焦。
  - 检查器「⋯」→「让模型解释这个节点」。
- **运行事件 → 对话**：只推送关键事件（循环一轮结束、失败、需要审批、完成），每条附「定位」胶囊；其余只进运行抽屉日志。
