# 05 · 动效

## 1. 原则

1. **动效只为传达信息**：状态变了、东西从哪来到哪去、操作已被接收。没有信息的动效一律不做。
2. **快**：大多数反馈在 160ms 内完成；最长的视图过渡 380ms。
3. **可打断**：用户的新操作永远优先，正在进行的动画立即让位（跳到终点或从当前值继续）。
4. **只动廉价属性**：`transform`、`opacity` 优先。
5. **可关闭**：`prefers-reduced-motion: reduce` 时所有时长令牌变为 0，功能不受影响。

## 2. 令牌速查

| 令牌 | 值 | 用于 |
|---|---|---|
| `--hx-t-1` | 90ms | 悬停、按下 |
| `--hx-t-2` | 160ms | 选中、状态切换、展开折叠、离开 |
| `--hx-t-3` | 240ms | 面板、菜单、弹层进入 |
| `--hx-t-4` | 380ms | 视图过渡：适应视图、聚焦、进入子图、展开画布、自动布局 |
| `--hx-ease` | cubic-bezier(.2,.8,.2,1) | 标准，状态变化 |
| `--hx-ease-out` | cubic-bezier(.16,1,.3,1) | 进入、视图过渡 |
| `--hx-ease-in` | cubic-bezier(.4,0,1,1) | 离开 |

循环类动画（旋转弧、流动光点、呼吸点）不用时长令牌，固定周期见清单，reduced-motion 时停止。

## 4. 展开画布的 FLIP 步骤

目标：卡片里的画布平滑放大到中间栏，过程中画布内容保持当前视角，不重新渲染。

1. **First**：读取卡片画布容器的 `getBoundingClientRect()` → `r0`。
2. 切换 DOM：给容器加 `is-expanded`，挂到中间栏的展开槽位（同一个 DOM 节点移动，不复制）。
3. **Last**：读取新位置 `r1`。
4. **Invert**：设置
   `transform: translate(r0.left-r1.left, r0.top-r1.top) scale(r0.width/r1.width, r0.height/r1.height)`，`transform-origin: 0 0`，同时把画布世界容器的缩放补偿掉，使内容视觉不变。
5. **Play**：下一帧把 transform 过渡到 `none`，时长 `--hx-t-4`，曲线 `--hx-ease-out`。
6. 浮动面板（节点库、检查器、停靠栏、小地图）在 Play 结束后再以 #8、#10 的方式淡入（延迟 0，时长 t-3），不参与 FLIP。
7. 结束后执行一次"适应视图"吗？**不执行**，保持用户原来的视角；只在首次展开时执行。
8. 退回卡片时反向执行；面板先淡出（t-2），再 FLIP 收回。

注意：FLIP 期间暂停网格点阵的 background 更新和小地图重绘。

## 5. 可动画与不可动画的属性

| 可以 | 有条件 | 禁止 |
|---|---|---|
| transform | box-shadow：只用于选中、运行、模型闪光、拖起 | width / height |
| opacity | background-color / border-color / color：状态变化 | top / left / right / bottom |
| stroke-dashoffset | stroke-width：只用于连线悬停 | margin / padding |
| | filter：禁止 blur；不要用 | font-size、line-height |
| | | SVG path d 的 CSS 过渡（改为 JS 每帧计算） |

## 6. 性能注意

- 循环动画（#21 #25 #39）只加在**正在运行**的元素上，运行结束立即移除 class。
- 画布上同一时间的循环动画数 ≤ 60；超过时连线流动降级为实色线。
- 不对整张画布加 `transition`；缩放/平移期间临时给根加 `.is-viewport-moving`，关闭网格与文字的过渡，停止 120ms 后移除。
- 一帧内触发的多个状态变化合并到一次 rAF 中应用。
- 用 `will-change: transform` 的只有世界容器、被拖动的节点和 AI 光标；不要给所有节点加。
- 动画结束监听用 `transitionend` 时必须加超时兜底（时长 + 50ms），防止事件丢失导致状态卡住。

```css
@media (prefers-reduced-motion: no-preference){
  .hx-node.is-running .hx-status__arc{ animation: hx-spin 900ms linear infinite; }
  .hx-edge.is-flowing .hx-edge__flow{ animation: hx-flow 600ms linear infinite; }
}
@keyframes hx-spin{ to{ transform: rotate(360deg); } }
@keyframes hx-flow{ to{ stroke-dashoffset: -12; } }
```
