# 07 画布

> 适用范围：展开态与全屏态下的编辑画布；卡片态的只读缩略画布使用同一套视口和渲染逻辑，只是关闭了交互。
> 依赖令牌：`--hx-bg-1`、`--hx-grid-dot`、`--hx-grid`、`--hx-marquee`、`--hx-marquee-line`、`--hx-model-line`、`--hx-t-4`、`--hx-ease-out`。
> 相关文档：08_节点.md、09_端口与连线.md、13_交互模式与快捷键.md、17_性能.md。

## 1. 坐标系与视口

### 1.1 三套坐标

| 坐标 | 原点 | 单位 | 用在哪里 |
|---|---|---|---|
| 屏幕坐标 `(sx, sy)` | 画布容器 `.hx-canvas` 的左上角 | CSS px | 指针事件：`clientX − rect.left` |
| 世界坐标 `(wx, wy)` | 图的原点 | 世界单位（缩放为 1 时等于 1px） | 节点位置、连线、存盘数据 |
| 节点局部坐标 | 节点左上角 | 世界单位 | 端口位置、内部控件 |

### 1.2 视口模型

```ts
type View = { x: number; y: number; k: number }; // 平移（屏幕 px）与缩放倍率
```

世界容器只有一个 transform：

```css
.hx-world { position: absolute; left: 0; top: 0; transform-origin: 0 0;
            transform: translate3d(var(--vx), var(--vy), 0) scale(var(--vk));
            will-change: transform; }
```

换算公式：

```js
const toScreen = (wx, wy, v) => [wx * v.k + v.x, wy * v.k + v.y];
const toWorld  = (sx, sy, v) => [(sx - v.x) / v.k, (sy - v.y) / v.k];
```

**规则**：所有存进图数据的坐标都是世界坐标。指针事件拿到屏幕坐标后，立刻用 `toWorld` 换算。`getBoundingClientRect` 只在指针按下那一刻用一次，用来取得容器的偏移量，并缓存起来；容器尺寸变化时由 `ResizeObserver` 负责更新。

### 1.3 缩放

| 参数 | 值 |
|---|---|
| 范围 | `k ∈ [0.2, 2.5]` |
| 鼠标滚轮每格 | ×1.1 或 ÷1.1 |
| 触控板捏合（`ctrlKey` 为 true 的 wheel 事件） | `k *= exp(−deltaY × 0.01)`，连续平滑 |
| 按钮 / 快捷键 `+` `−` | ×1.2 或 ÷1.2，带过渡动画 |
| 双击缩放控件里的百分比 | 回到 100% |

以光标为中心缩放（光标下的世界点保持不动）：

```js
function zoomAt(v, sx, sy, nextK) {
  const k = clamp(nextK, 0.2, 2.5);
  const [wx, wy] = toWorld(sx, sy, v);
  return { k, x: sx - wx * k, y: sy - wy * k };
}
```

### 1.4 区分鼠标和触控板

浏览器无法确切区分两者，按下面的规则推断，只要满足其一就当作触控板：

| 信号 | 判断 |
|---|---|
| `e.ctrlKey && e.deltaMode === 0` | 触控板捏合，执行缩放 |
| `deltaMode === 0` 且 `|deltaX| > 0` | 触控板双指滑动，执行**平移** |
| `deltaMode === 0` 且 `|deltaY|` 不是 100 / 120 的整数倍 | 触控板，执行平移 |
| 其他情况（`deltaMode === 1`，或 deltaY 是 ±100 / ±120） | 鼠标滚轮，执行**缩放** |

设置里提供一个开关「滚轮行为：缩放 / 平移」，默认是「自动」。

### 1.5 平移方式

| 方式 | 说明 |
|---|---|
| 在空白处左键拖动 | 选择工具（V）下默认平移。只有按住 Shift 拖动才是框选（见第 4 节） |
| 按住 Space 拖动 | 任何工具下都可以，光标变为 `grab` / `grabbing` |
| 中键拖动 | 任何时候都可以 |
| 平移工具（H） | 左键拖动即平移 |
| 触控板双指滑动 | 见 1.4 |
| 方向键（未选中任何节点时） | 每次移动 40px，按住 Shift 移动 200px |
| 小地图 | 点击或拖动，见第 9 节 |

平移有惯性吗？**没有**。松手立刻停下，这是工具类软件的习惯，也方便精确操作。

## 2. 点阵网格

### 2.1 实现

网格画在画布容器的背景上，不放进世界容器，也不用 DOM 或 canvas：

```css
.hx-canvas {
  background-color: var(--hx-bg-1);
  background-image: radial-gradient(circle, var(--hx-grid-dot) var(--dot-r), transparent calc(var(--dot-r) + .5px));
  background-size: var(--gs) var(--gs);
  background-position: var(--gx) var(--gy);
}
```

```js
function renderGrid(v) {
  const base = 20;                                   // --hx-grid
  const step = v.k < 0.5 ? base * 2 : base;          // 缩小时网格间距翻倍
  const gs = step * v.k;                             // 屏幕上的点间距
  const r = v.k < 0.35 ? 0.75 : 1;                   // 点的半径
  canvasEl.style.setProperty('--gs', gs + 'px');
  canvasEl.style.setProperty('--gx', (v.x % gs) + 'px');
  canvasEl.style.setProperty('--gy', (v.y % gs) + 'px');
  canvasEl.style.setProperty('--dot-r', r + 'px');
}
```

### 2.2 视觉参数

| 参数 | 浅色（默认） | 深色 |
|---|---|---|
| 画布底色 | `--hx-bg-1` | `--hx-bg-1` |
| 点色 | `--hx-grid-dot` | `--hx-grid-dot` |
| 点半径（k ≥ 0.35） | 1px | 1px |
| 点半径（k < 0.35） | 0.75px | 0.75px |
| 屏幕上的最小点间距 | 16px，低于这个值就翻倍 | 同左 |
| 选中框填充 / 描边 | `--hx-marquee` / `--hx-marquee-line` | 同左 |
| 对齐参考线 | 1px `--hx-model-line` | 同左 |

**浅色主题的要点**：画布底色 `--hx-bg-1` 比面板 `--hx-bg-2`（纯白）略灰，这样白色节点和面板才能"浮"起来。点色透明度不要再调高，否则画布会显得脏。

### 2.3 网格密度切换

间距翻倍发生在 `k = 0.5` 处。为了避免来回跨过阈值时网格闪动，加一个滞回区间：k 降到 0.48 以下才翻倍，升到 0.52 以上才恢复。

## 3. 细节分级（LOD）

| 档位 | 阈值（带滞回） | 节点上显示 | 隐藏 | 连线 |
|---|---|---|---|---|
| **L1 完整** | k ≥ 0.75（降到 0.72 以下才切换） | 全部：图标、标题、类型行、端口名、端口类型标签、内联控件、状态脚文字、AI 签 | — | 线宽 1.75，运行时有流动效果 |
| **L2 简化** | 0.45 ≤ k < 0.75 | 图标、标题、端口圆点、状态点、状态脚进度条、AI 签 | 类型行、端口名、内联控件、状态脚文字 | 线宽 1.75，流动效果保留 |
| **L3 概览** | k < 0.45（升到 0.48 以上才切换回 L2） | 节点变成色块：`--hx-bg-3` 底、`--hx-line-2` 外框；标题字号放大为 `14 / k × 0.45` 并居中，状态用外框颜色表示 | 其他所有内容 | 线宽固定为屏幕上 1px（`vector-effect: non-scaling-stroke`），关闭流动效果 |

实现：

```js
function lodOf(k, prev) {
  if (prev === 1) return k < 0.72 ? (k < 0.45 ? 3 : 2) : 1;
  if (prev === 3) return k > 0.48 ? (k >= 0.75 ? 1 : 2) : 3;
  return k >= 0.75 ? 1 : k < 0.45 ? 3 : 2;
}
// 只改一个属性，让 CSS 去切换显示
worldEl.dataset.lod = lod;
```
```css
/* 类型行、端口名、状态脚文字不影响高度，可以直接隐藏 */
[data-lod="2"] .hx-node__type, [data-lod="2"] .hx-port__name,
[data-lod="2"] .hx-node__foot-text { display: none; }
/* 控件行会影响高度，必须占位隐藏，保证端口坐标不变 */
[data-lod="2"] .hx-node__widgets { visibility: hidden; }
```

**避免闪烁和跳动**：
1. 阈值带滞回（见上表）。
2. **节点高度在 L1 和 L2 下保持不变**：被隐藏的控件行用 `visibility: hidden` 占位，不用 `display: none`。这样端口坐标不会变，连线也不会跳。
3. 在缩放过程中不切换档位。等滚轮停止 120ms 后再判断一次，和 17_性能.md 中的 R9 共用同一个计时器。

## 4. 选择

### 4.1 规则

| 操作 | 结果 |
|---|---|
| 单击节点 | 只选中它 |
| Shift 或 ⌘/Ctrl 加单击 | 切换这个节点是否选中 |
| 单击连线 | 只选中这条线（节点选择清空） |
| 单击空白（移动距离 < 4px） | 清空选择 |
| Shift 加在空白处拖动 | 框选 |
| ⌘A | 选中当前这一层的全部节点 |
| Esc | 清空选择；如果有弹层，先关弹层 |

### 4.2 框选：包含还是相交

由**拖动方向**决定（与 CAD 的习惯一致），界面上用不同的框线样式提示：

| 方向 | 模式 | 框线 | 选中条件 |
|---|---|---|---|
| 从左往右拖 | 包含 | 实线 `--hx-marquee-line` | 节点矩形**完全**在框内 |
| 从右往左拖 | 相交 | 虚线 `--hx-marquee-line`，`stroke-dasharray: 4 3` | 节点矩形和框**有交集** |

拖动过程中实时高亮将被选中的节点（显示选中描边，透明度 0.6）；松手后才写入 `ui.selection`。加按 Shift 时把框选结果和已有选择合并，按 Alt 时从已有选择中减去。

### 4.3 选中的表现

见 08_节点.md 第 6 节。多选时，检查器显示「已选 N 个」和批量操作。

## 5. 吸附与对齐

| 规则 | 说明 |
|---|---|
| 网格吸附 | 默认开启。拖动结束时节点左上角吸附到 20 的整数倍。拖动过程中**实时吸附**（节点按格跳动），手感更明确 |
| 临时关闭 | 拖动时按住 Alt |
| 全局开关 | 停靠栏的「吸附」切换，状态保存在用户设置里 |
| 多选拖动 | 以被拖动的那个节点为基准吸附，其余节点保持相对位置 |
| 新建节点 | 放下的位置也吸附 |

**对齐参考线（P1，可选）**：拖动时，如果节点的左边、右边、水平中线、顶边、底边和视口内其他节点的对应边距离小于 6 个屏幕像素，就吸附过去，并画一条 1px 的 `--hx-model-line` 参考线，横贯两个节点。同一方向只显示最近的一条。参考线吸附优先于网格吸附。

## 6. 适应视图与聚焦

### 6.1 算法

```js
function fitView(rects, vpW, vpH, pad = 48, maxK = 1) {
  if (!rects.length) return { x: vpW / 2, y: vpH / 2, k: 1 };
  const b = union(rects);                                   // 世界坐标下的包围盒
  const k = clamp(Math.min((vpW - pad * 2) / b.w, (vpH - pad * 2) / b.h), 0.2, maxK);
  return { k, x: (vpW - b.w * k) / 2 - b.x * k, y: (vpH - b.h * k) / 2 - b.y * k };
}
```

| 命令 | 范围 | maxK | pad |
|---|---|---|---|
| 适应视图（1） | 当前层全部节点 | 1 | 48 |
| 聚焦选中（2） | 选中的节点 | 1.25 | 96 |
| 定位到节点（从对话或日志点进来） | 单个节点 | 保持当前 k，但不低于 0.75 | — |

计算可用视口时，要**扣除浮动面板遮挡的区域**：左边减去节点库宽度加 12，右边如果检查器开着就减去 332，底部减去运行抽屉的高度。

### 6.2 动画

从当前视图到目标视图做插值，时长 `--hx-t-4`，曲线 `--hx-ease-out`。缩放在对数空间里插值，看起来更匀速：

```js
const lerpView = (a, b, t) => {
  const k = Math.exp(lerp(Math.log(a.k), Math.log(b.k), t));
  // 以两个视图中心对应的世界点为锚，避免中途画面漂走
  const ca = toWorld(vpW / 2, vpH / 2, a), cb = toWorld(vpW / 2, vpH / 2, b);
  const cx = lerp(ca[0], cb[0], t), cy = lerp(ca[1], cb[1], t);
  return { k, x: vpW / 2 - cx * k, y: vpH / 2 - cy * k };
};
```

动画过程中，只要用户有任何指针或滚轮操作，立刻中止动画，停在当前位置。

## 7. 空画布

| 情况 | 显示 |
|---|---|
| 新建，空图 | 画布中央：20px 的 `add` 图标、标题「从这里开始」(`--hx-fs-16`、`--hx-text-1`)、一行说明「从左侧拖入节点，按 A 快速添加，或在下方对话里告诉模型你要做什么」(`--hx-fs-13`、`--hx-text-2`)，下面三个次按钮：「添加节点」「从模板开始」「让模型搭建」 |
| 进入一个空子图 | 同上，但标题换成「这个子图还是空的」，按钮去掉「从模板开始」。入口和出口两个子图端口始终存在，所以这种情况很少见 |
| 节点库搜索无结果 | 见 14_状态反馈与异常.md |

空状态不需要插图，保持界面安静。

## 8. 大图：视口裁剪

当前层节点数 > 150 时启用（阈值可配置）：

```js
function cull(v, vpW, vpH, margin = 200) {
  const [x0, y0] = toWorld(-margin, -margin, v);
  const [x1, y1] = toWorld(vpW + margin, vpH + margin, v);
  for (const n of nodes) {
    const vis = n.x < x1 && n.x + n.w > x0 && n.y < y1 && n.y + n.h > y0;
    if (vis !== n._vis) { n._vis = vis; n.el.style.contentVisibility = vis ? 'visible' : 'hidden'; }
  }
  // 连线：两端节点都不可见，并且线段包围盒和视口不相交，就跳过不画
}
```

- 在平移或缩放停止后 60ms 执行，用 rAF 合并。拖动过程中不重新计算。
- `margin` 留 200 个屏幕像素，平移时边缘不会出现空白。
- 被裁剪的节点仍然参与小地图、搜索和适应视图的计算（这些用的是数据层，和 DOM 无关）。

更大规模的图（> 1000 个节点）的处理见 17_性能.md 第 6 节。

## 9. 小地图

| 项 | 规格 |
|---|---|
| 位置 | 画布左下角，距左边和底边 12px；节点库展开时贴在它右侧 |
| 尺寸 | 180 × 120，圆角 `--hx-r-lg`，背景 `--hx-bg-2`，阴影 `--hx-shadow-float` |
| 绘制 | 一个 `<canvas>`，按 devicePixelRatio 设置分辨率 |
| 内容 | 节点画成填充 `--hx-line-3` 的矩形；选中的节点用 `--hx-text-2`；运行中的用 `--hx-accent`；失败的用 `--hx-danger`。不画连线 |
| 视口框 | 1px `--hx-text-2` 描边，内部填充 `--hx-marquee` |
| 交互 | 点击：把视图中心移到那里（带 `--hx-t-3` 动画）；拖动视口框：实时平移，没有动画 |
| 重画时机 | 图结构、节点位置或节点状态变化时重画节点层；视图变化时只移动视口框（视口框用一个绝对定位的 div 叠在 canvas 上） |
| 收起 | 右上角小按钮，收成 28×28 的图标按钮 |

颜色从 CSS 变量里读取：`getComputedStyle(root).getPropertyValue('--hx-line-3')`，切换主题时重新读一次并重画。
