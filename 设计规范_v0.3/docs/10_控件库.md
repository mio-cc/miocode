## 10.0 通用约定（所有控件都遵守）

### 10.0.1 两种尺寸

| 项 | 标准 `hx-ctl--md` | 紧凑 `hx-ctl--sm`（节点内、表格内、工具条） |
|---|---|---|
| 高度 | `--hx-ctl-h`（28px） | `--hx-ctl-h-sm`（24px） |
| 水平内边距 | `--hx-s-5`（12px） | `--hx-s-4`（8px） |
| 字号 | `--hx-fs-13` | `--hx-fs-12` |
| 图标 | 16px | 14px |
| 圆角 | `--hx-r-md`（按钮） / `--hx-r-sm`（输入类） | 一律 `--hx-r-sm` |
| 图标与文字间距 | `--hx-s-3` | `--hx-s-2` |
| 使用位置 | 检查器、面板、对话框、对话卡片 | **节点内联控件**、表格单元格、停靠栏、运行抽屉 |

规则：
- **节点里的控件一律用紧凑尺寸**，class 加 `hx-ctl--sm`。节点内联控件行高是 `--hx-node-widget`（28px），控件 24px 高，上下各留 2px。
- 同一行里的控件尺寸必须一致，不能标准和紧凑混用。
- 紧凑尺寸下不显示控件内的辅助文字（如单位），单位移到标签上，例如「超时 (s)」。

### 10.0.2 通用状态令牌

除非某控件另有说明，状态外观按下表：

| 状态 | 背景 | 外框 | 文字 | 其他 |
|---|---|---|---|---|
| 默认 | `--hx-bg-4` | 透明 | `--hx-text-1` | — |
| 悬停 | `--hx-bg-4` | `--hx-line-3` | `--hx-text-1` | 过渡 `--hx-t-1` |
| 按下 | `--hx-bg-5` | `--hx-line-3` | `--hx-text-1` | — |
| 聚焦（键盘） | `--hx-bg-3` | `--hx-text-2` | `--hx-text-1` | `box-shadow: 0 0 0 3px` 用 `--hx-line-2` 作光晕 |
| 禁用 | `--hx-bg-4` | 透明 | `--hx-text-3` | `cursor: not-allowed`，整体不降透明度（保证可读） |
| 加载 | 同默认 | 同默认 | 内容替换为旋转弧 | 宽度锁定，不跳动 |
| 错误 | `--hx-danger-weak` | `--hx-danger` | `--hx-text-1` | 下方 `--hx-fs-12` 错误文字用 `--hx-danger` |

- 聚焦环只在键盘聚焦时出现：用 `:focus-visible`，不用 `:focus`。
- 浅色主题下，`--hx-bg-4` 放在白色面板上依然可辨；若控件直接放在 `--hx-bg-4` 底上（如表格悬停行），默认态改用 `--hx-bg-3` 并加 `--hx-line-2` 外框。

### 10.0.3 class 命名

BEM + `hx-` 前缀：`hx-<块>`、`hx-<块>__<元素>`、`hx-<块>--<变体>`；状态用 `is-*`：

```
hx-btn  hx-btn--primary  hx-ctl--sm  hx-btn__icon  is-loading  is-error
```

### 10.0.4 无障碍通用
- 可点击元素一律 `<button type="button">`；跳转才用 `<a>`。
- 只有图标的控件必须有 `aria-label`，并配提示框。
- 禁用用原生 `disabled`；暂不可用但需要解释原因的（例如授权不足）用 `aria-disabled="true"`，仍可聚焦，点击时给出原因提示。

## 10.1 按钮 `hx-btn`

**用途**：触发一个动作。
**用**：明确的动作，如「运行」「采纳」「保存」。
**不用**：页面跳转（用链接）；状态切换（用开关或分段）；一组互斥选项（用分段）。

### 变体

| 变体 | class | 用途 | 一个区域最多 |
|---|---|---|---|
| 主按钮 | `--primary` | 当前区域最重要的动作 | 1 个 |
| 次按钮 | `--secondary`（默认） | 一般动作 | 不限 |
| 幽灵按钮 | `--ghost` | 工具条、低频动作 | 不限 |
| 危险按钮 | `--danger` | 删除、急停、不可逆操作 | 1 个 |
| 模型按钮 | `--model` | 「让模型…」「采纳模型提议」 | 1 个 |

### 状态矩阵

| 变体 \ 状态 | 默认 | 悬停 | 按下 | 聚焦 | 禁用 | 加载 |
|---|---|---|---|---|---|---|
| primary | 底 `--hx-accent`，字 `--hx-text-inv` | `filter: brightness(1.04)` | `transform: scale(.97)` | 外加光晕 `--hx-accent-weak` 3px | 底 `--hx-bg-5`，字 `--hx-text-3` | 旋转弧，字 `--hx-text-inv` |
| secondary | 底 `--hx-bg-4`，字 `--hx-text-1` | 外框 `--hx-line-3` | 底 `--hx-bg-5` + scale(.97) | 外框 `--hx-text-2` + 光晕 `--hx-line-2` | 字 `--hx-text-3` | 旋转弧 `--hx-text-2` |
| ghost | 透明，字 `--hx-text-2` | 底 `--hx-bg-4`，字 `--hx-text-1` | 底 `--hx-bg-5` | 同 secondary | 字 `--hx-text-3` | 同 secondary |
| danger | 底 `--hx-danger-weak`，字 `--hx-danger` | 底 `--hx-danger`，字 `--hx-bg-3` | scale(.97) | 光晕 `--hx-danger-weak` | 字 `--hx-text-3` | 旋转弧 `--hx-danger` |
| model | 底 `--hx-model-weak`，字 `--hx-model` | 外框 `--hx-model-line` | scale(.97) | 光晕 `--hx-model-weak` | 字 `--hx-text-3` | 旋转弧 `--hx-model` |

> 浅色下琥珀主按钮的文字用 `--hx-text-inv`（深色字），不用白字，否则对比度不足。

### 尺寸
标准 28px / 紧凑 24px，见 10.0.1。纯文字按钮最小宽 64px，文字不换行，超长截断加提示框。

### 结构
```
[图标?] 文字 [快捷键?]
```
快捷键用 `hx-kbd--inline`（见 10.29），只在面板与菜单中显示，节点内不显示。

### 键盘与无障碍
- `Enter` / `Space` 触发；加载中再次触发无效。
- 加载中设 `aria-busy="true"`；危险按钮的文字必须是动词+对象（「删除节点」而不是「确定」）。

### HTML
```html
<button type="button" class="hx-btn hx-btn--primary">
  <svg class="hx-btn__icon" aria-hidden="true">…</svg>
  <span class="hx-btn__label">运行</span>
  <kbd class="hx-kbd hx-kbd--inline">⌘↵</kbd>
</button>
<button type="button" class="hx-btn hx-btn--primary is-loading" aria-busy="true">
  <span class="hx-spinner" aria-hidden="true"></span><span class="hx-btn__label">运行中</span>
</button>
```

## 10.2 图标按钮 `hx-iconbtn`

**用途**：工具条、节点头部、面板头部的紧凑动作。
**不用**：主要动作（必须有文字）。

| 项 | 标准 | 紧凑 |
|---|---|---|
| 尺寸 | 28×28 | 24×24 |
| 图标 | 16 | 14 |
| 圆角 | `--hx-r-md` | `--hx-r-sm` |

状态：默认透明、图标 `--hx-text-2`；悬停底 `--hx-bg-4`、图标 `--hx-text-1`；按下底 `--hx-bg-5`；**激活**（切换型，如「吸附开」）底 `--hx-bg-5`、图标 `--hx-text-1`，并设 `aria-pressed="true"`；禁用图标 `--hx-text-3`。

必须有提示框：名称 + 快捷键，延迟 400ms。

```html
<button type="button" class="hx-iconbtn" aria-label="适应视图" data-tip="适应视图" data-kbd="1">
  <svg aria-hidden="true">…</svg>
</button>
```

## 10.3 按钮组 `hx-btngroup`

把相关的几个按钮连成一组，如「缩小 · 100% · 放大」。
- 组内按钮之间无间隙，中间用 1px `--hx-line-1` 分隔；只有首尾按钮有外圆角。
- 整组共用背景 `--hx-bg-4`，外框透明；悬停只作用于单个按钮。
- 组内最多 5 个；互斥选择请改用分段控件（10.11）。

```html
<div class="hx-btngroup" role="group" aria-label="缩放">
  <button class="hx-iconbtn" aria-label="缩小">−</button>
  <button class="hx-btn hx-btn--ghost hx-ctl--sm" aria-label="重置缩放">100%</button>
  <button class="hx-iconbtn" aria-label="放大">+</button>
</div>
```

## 10.4 数字步进 `hx-num`

**用途**：整数或小数参数，如并发、最大轮数、温度、预算比例。这是节点里最常用的控件。
**不用**：范围很大且精确值不重要（用滑块）；枚举（用下拉或分段）。

### 结构
```
[ − ][   3   ][ + ]          标准：宽 ≥ 96，按钮 24×28
                              紧凑：宽 ≥ 80，按钮 20×24
```
数值居中，`--hx-font-mono`，`tabular-nums`。悬停数值区时光标为 `ew-resize`。

### 拖拽调值（重点）

| 项 | 规则 |
|---|---|
| 触发 | 在数值区按下并水平移动 ≥ 3px（小于 3px 视为点击，不改值） |
| 指针 | 开始拖动时 `requestPointerLock()`，光标隐藏，避免拖出屏幕；松开时退出 |
| 灵敏度 | 默认每 4px 改变 1 个 `step` |
| Shift | 加速 ×10 |
| Alt | 减速 ×0.1（若 step 为整数，则至少改变 1） |
| 精度 | 结果按 `step` 的小数位数四舍五入，避免 0.30000000004 |
| 节流 | 拖动中每帧最多派发一次 `input`；松开时派发一次 `change`，并合并为**一条** Op（见 13 号文档 §13.6） |
| 反馈 | 拖动中数值区底色 `--hx-bg-5`，数值上方浮出当前值气泡（样式同提示框） |

### 其他输入方式
- **滚轮**：只有控件**已聚焦**时滚轮才改值，避免和画布缩放冲突；每格 1 step，Shift ×10。
- **双击**数值区或按 `Enter`：进入文本编辑并全选；`Enter` 提交，`Esc` 取消。支持简单表达式 `3*2`、`+5`（相对当前值）。
- **方向键**：`↑` / `↓` 每次 1 step，Shift ×10。
- `−` / `+` 按钮：单击 1 step；**长按** 400ms 后每 60ms 自动重复一次。

### 范围限制与越界反馈
- 到达 `min` 时 `−` 按钮禁用；`max` 同理。
- 拖动超出范围：数值停在边界，数值区左右轻微抖动一次（`translateX` ±2px，`--hx-t-2`）；reduced-motion 下改为外框闪 `--hx-wait` 一次。
- 手动输入越界：失焦时夹紧到边界，并在下方提示「最大为 32」，3 秒后消失。
- 非法输入（字母等）：错误态，不提交。

### 状态矩阵
| 状态 | 背景 | 外框 | 数值文字 |
|---|---|---|---|
| 默认 | `--hx-bg-4` | 透明 | `--hx-text-1` |
| 悬停 | `--hx-bg-4` | `--hx-line-3` | `--hx-text-1` |
| 拖动中 | `--hx-bg-5` | `--hx-line-3` | `--hx-text-1` |
| 编辑中/聚焦 | `--hx-bg-3` | `--hx-text-2` | `--hx-text-1` |
| 禁用 | `--hx-bg-4` | 透明 | `--hx-text-3` |
| 错误 | `--hx-danger-weak` | `--hx-danger` | `--hx-text-1` |
| 模型改过 | 同默认 | 同默认 | 新值 `--hx-model`；前面旧值 `--hx-text-3` 加删除线 |

### 无障碍与 HTML
```html
<div class="hx-num hx-ctl--sm" role="spinbutton" tabindex="0"
     aria-valuenow="3" aria-valuemin="1" aria-valuemax="32" aria-label="并发">
  <button class="hx-num__dec" tabindex="-1" aria-hidden="true">−</button>
  <span class="hx-num__value">3</span>
  <button class="hx-num__inc" tabindex="-1" aria-hidden="true">+</button>
</div>
```

### 伪代码
```js
onPointerMove(e){
  acc += e.movementX * (e.shiftKey ? 10 : e.altKey ? 0.1 : 1) / 4;
  const steps = Math.trunc(acc); if (!steps) return; acc -= steps;
  setValue(clamp(round(value + steps * step, decimals(step)), min, max));
}
```

## 10.5 滑块 `hx-slider`

**用途**：连续范围，而且相对位置比精确值重要，如预算比例 0–1、抽检率。
**不用**：需要精确值（用数字步进）；节点内（空间不够，用数字步进）。

| 项 | 规格 |
|---|---|
| 轨道 | 高 4px，底 `--hx-bg-5`，圆角 `--hx-r-full` |
| 已填充 | `--hx-text-2`（不用强调色，强调色只给运行态） |
| 拇指 | 12px 圆，底 `--hx-bg-3`，外框 1px `--hx-line-3`，`--hx-shadow-node` |
| 悬停拇指 | 放大到 14px（`transform: scale`） |
| 拖动中 | 拇指上方浮出值气泡 |
| 刻度 | 可选，`--hx-line-2` 1×4px 竖线 |
| 右侧数值 | 可选，mono，宽 48 |

键盘：`←/→` 1 step，`PageUp/PageDown` 10 step，`Home/End` 到端点。
无障碍：用原生 `<input type="range">` 定制样式，或 `role="slider"` + `aria-value*`。

```html
<label class="hx-field"><span class="hx-field__label">抽检率</span>
  <input type="range" class="hx-slider" min="0" max="1" step="0.05" value="0.2">
  <output class="hx-slider__out">0.20</output>
</label>
```

## 10.6 文本输入 `hx-input`

**用途**：单行文本，如节点名称、字段路径、表达式。

| 项 | 标准 | 紧凑 |
|---|---|---|
| 高 | 28 | 24 |
| 内边距 | 0 `--hx-s-4` | 0 `--hx-s-3` |
| 圆角 | `--hx-r-sm` | `--hx-r-sm` |
| 占位符 | `--hx-text-3` | 同 |

变体：
- `--mono`：路径、表达式、类型名，字体 `--hx-font-mono`。
- 前缀/后缀图标：搜索框左侧放搜索图标，右侧放清空按钮（有内容才出现）。
- 行内编辑（节点标题、检查器标题）：默认无背景，悬停出现 `--hx-bg-4`，单击进入编辑；`Enter` 提交，`Esc` 恢复，失焦提交。

状态按 10.0.2。出错时下方显示一行错误文字；**不要**只把外框变红而不说原因。

```html
<div class="hx-input hx-input--mono is-error">
  <input aria-invalid="true" aria-describedby="e1" value="判定.achived">
</div>
<p id="e1" class="hx-field__error">找不到字段 achived，是不是 achieved？</p>
```

## 10.7 多行文本 `hx-textarea`

用于角色卡字段、理由、说明。
- 最小高 3 行，随内容自动增高，超过 12 行后出现滚动条。
- 行高 1.55，字号 `--hx-fs-13`。
- 右下角显示字数「128 / 300」（有 `max_chars` 时），超出时数字变 `--hx-danger`，但**不截断**输入。
- 在对话框或表单中，`⌘/Ctrl+Enter` 提交。

## 10.8 代码 / YAML 编辑框 `hx-code`

**用途**：YAML 视图、长表达式、授权书、角色卡原文、信封 JSON 查看。

### 结构
```
┌────┬────────────────────────────────────────┐
│  1 │ node: Agent                            │  ← 行号栏宽 36，右对齐，--hx-text-3
│  2 │ params:                                │
│  3 │   concurrency: 3                       │
│ ●4 │   output_schema: 方案@9                │  ← 错误行
└────┴────────────────────────────────────────┘
```
- 背景 `--hx-bg-4`，圆角 `--hx-r-md`，字体 `--hx-font-mono` `--hx-fs-12`，行高 20px。
- 行号栏右侧 1px `--hx-line-1` 分隔。当前行行号 `--hx-text-1`，当前行背景 `--hx-line-1`。
- `Tab` 插入 2 空格；`Shift+Tab` 反缩进；`⌘/Ctrl+/` 切换注释。

### 高亮配色（只用令牌）

| 记号 | 令牌 |
|---|---|
| 键名 | `--hx-text-2` |
| 冒号、短横、括号 | `--hx-text-3` |
| 字符串 | `--hx-type-list` |
| 数字 | `--hx-type-ctx` |
| 布尔、null | `--hx-type-ctrl` |
| 类型引用 `xxx@1` | `--hx-type-ref` |
| 注释 | `--hx-text-3` 斜体 |
| 节点 id / 引用 | `--hx-type-gen` |

### 错误行标记
- 行号位置换成 6px `--hx-danger` 圆点，整行背景 `--hx-danger-weak`。
- 错误片段下方 `text-decoration: underline wavy`，颜色 `--hx-danger`。
- 悬停错误行显示提示框：错误原因 + 修复建议。
- 编辑框底部状态条：「2 处错误 · 第 4 行：类型 方案@9 不存在」，点击跳到该行。
- 模型改动的行：行号左侧 2px 竖条 `--hx-model`；新增行背景 `--hx-model-weak`。

### 只读模式
`aria-readonly="true"`，背景改 `--hx-bg-1`，右上角显示「复制」图标按钮。

```html
<div class="hx-code" role="textbox" aria-multiline="true" aria-label="YAML 视图">
  <div class="hx-code__gutter">…</div><div class="hx-code__body" contenteditable="true">…</div>
  <div class="hx-code__status">2 处错误</div>
</div>
```
> 真实项目建议用 CodeMirror 6 并接入上述令牌主题；原型可用 `<textarea>` 叠一层高亮 `<pre>`。

## 10.9 下拉选择 `hx-select`

**用途**：从 5 个以上选项中选一个或多个，如模型、输出类型、工具。
**不用**：2–4 个互斥选项（用分段）；布尔（用开关）。

### 触发器
与文本输入同尺寸，右侧 ▾ 图标 `--hx-text-3`；展开时图标旋转 180°（`--hx-t-2`）。显示值过长时截断加省略号。

### 弹层
- 背景 `--hx-bg-2`，阴影 `--hx-shadow-pop`，圆角 `--hx-r-lg`，内边距 `--hx-s-2`。
- 宽度 = 触发器宽，最小 200，最大 360；最大高 320，超出滚动。
- 默认出现在下方，空间不足自动翻到上方；与触发器间距 4px。
- 进入：`opacity 0→1` + `translateY(-4px→0)`，`--hx-t-3` `--hx-ease-out`。

### 选项
- 高 28，圆角 `--hx-r-sm`，左右内边距 `--hx-s-4`。
- 结构：`[图标?] 名称 ……… [次要信息 mono --hx-text-3] [✓]`
- 悬停/键盘高亮：底 `--hx-bg-4`。选中：右侧 ✓ `--hx-text-1`。禁用：字 `--hx-text-3`，悬停显示原因。

### 过滤
选项多于 8 个时顶部出现过滤输入框，弹层打开即聚焦；匹配字符加粗；可选支持拼音首字母匹配（P1）。无结果显示「没有匹配的选项」。

### 分组
组标题高 24，`--hx-fs-11` `--hx-text-3`；组之间 1px `--hx-line-1`。

### 多选
- 选项左侧换成复选框；点击选项不关闭弹层。
- 触发器显示为标签串：最多显示 2 个标签 + 「+3」。
- 底部固定一行：「已选 5 · 全选 · 清空」。

### 键盘
| 键 | 作用 |
|---|---|
| `Enter` / `Space` / `↓` | 打开 |
| `↑` `↓` | 移动高亮 |
| `Home` `End` | 首项 / 末项 |
| 字符 | 过滤（无过滤框时跳到首字母） |
| `Enter` | 选中（单选时关闭） |
| `Esc` | 关闭，焦点回到触发器 |
| `Tab` | 选中当前高亮并关闭 |

### 无障碍与 HTML
触发器 `role="combobox" aria-expanded aria-controls`；列表 `role="listbox"`（多选加 `aria-multiselectable="true"`）；选项 `role="option" aria-selected`。

```html
<button class="hx-select" role="combobox" aria-expanded="false" aria-controls="lb1">
  <span class="hx-select__value">large-model</span><svg class="hx-select__chev">…</svg>
</button>
<div class="hx-pop hx-listbox" id="lb1" role="listbox" hidden>
  <div class="hx-listbox__group">厂商 A</div>
  <div class="hx-listbox__opt is-active" role="option" aria-selected="true">large-model <span>128k</span></div>
</div>
```

## 10.16 进度条 `hx-progress`

- 轨道高 3px（节点状态脚）/ 4px（面板），底 `--hx-line-2`，圆角 `--hx-r-full`。
- 填充用 `transform: scaleX(p)` + `transform-origin: left`，**不改 width**。
- 颜色：运行 `--hx-accent`，完成 `--hx-ok`，失败 `--hx-danger`。
- 不确定进度：30% 长的填充从左到右循环（1.2s）；reduced-motion 下改为静止 30% 斜纹。
- 右侧可显示百分比（mono `--hx-fs-11`）。`role="progressbar" aria-valuenow`。

## 10.17 环形进度 `hx-ring`

用于循环节点的轮次、预算消耗。

- 底环 `--hx-line-2`，进度弧 `--hx-accent`（运行）或 `--hx-text-2`（静止）。

## 10.19 弹出层 `hx-pop`

**用途**：点击触发、可交互的浮动内容，如授权档位面板、类型选择、快速添加面板。

## 10.22 通知 toast `hx-toast`

- 位置：画布右上角（检查器可见时在其左侧），距边 12，垂直堆叠，间距 8；最多显示 3 条，多出的合并为「还有 2 条」。
- 宽 320；背景 `--hx-bg-2`，阴影 `--hx-shadow-float`，圆角 `--hx-r-lg`；左侧 3px 竖条表示语义：成功 `--hx-ok`、失败 `--hx-danger`、等待 `--hx-wait`、模型 `--hx-model`，普通通知无竖条。
- 结构：`[图标] 标题（1 行） / 说明（≤2 行，--hx-text-2） [撤销] [×]`
- 停留时间：普通 4s；带「撤销」6s；错误不自动消失；鼠标悬停时暂停计时。
- 进入 `translateX(12px)→0` + 淡入；离开淡出后高度收起（这里允许高度动画，因为不在高频路径上）。
- `role="status"`（普通）/ `role="alert"`（错误）。

## 10.23 确认对话框 `hx-dialog`

**只用于**不可撤销或影响范围大的操作（判断规则见 13 号文档 §13.11）。
- 宽 420，居中；背景 `--hx-bg-2`，阴影 `--hx-shadow-pop`，圆角 `--hx-r-xl`，内边距 `--hx-s-8`；遮罩 `--hx-scrim`。
- 结构：
  1. 标题：`--hx-fs-16` 600，写成问句，如「删除子图"执行池"？」
  2. 后果说明：具体到数量，如「将同时删除 6 个节点和 9 条连线」
  3. 可选「不再询问」复选框
  4. 按钮行右对齐：「取消」（次按钮）+「删除」（危险按钮，文字用动词）
- 默认焦点在「取消」；`Esc` = 取消；`Enter` 不触发危险操作。
- `role="alertdialog" aria-modal="true"`，焦点锁定在对话框内。

## 10.27 参数行 `hx-param`

检查器与节点内联控件共用的基础行。

```
检查器（标准）：
┌──────────────────────────────────────────────────┐
│ 并发            [ −    3    + ]          ◯   ⚿  │  高 32；◯ 转端口，⚿ 锁定
```

| 标签 | 宽 96（检查器）/ 72（节点），`--hx-fs-12` `--hx-text-2`，超长截断加提示框 |
| 控件 | 占剩余宽度；按参数 schema 自动选择：数字→步进，枚举 ≤4→分段，枚举 >4→下拉，布尔→开关，文本→输入，表达式→mono 输入，引用→组合框 |

| 必填未填 | 标签后加 `--hx-danger` 小圆点 |

## 10.30 控件选择速查

| 参数形态 | 检查器 | 节点内 |
|---|---|---|
| 整数/小数，有范围 | 数字步进（大范围可加滑块） | 数字步进（紧凑） |
| 0–1 比例 | 滑块 + 数值 | 数字步进，step .05 |
