**修饰键**

| 修饰 | 作用 |
|---|---|
| `Shift` + 单击 | 加选 / 减选 |
| `⌘/Ctrl` + 单击 | 加选 / 减选（同 Shift） |
| `Shift` + 在空白处拖动 | 框选：**相交**就选中 |
| `⌘/Ctrl+Shift` + 在空白处拖动 | 框选：**完全包含**才选中 |
| `Alt` + 拖动节点 | 临时关闭网格吸附 |
| 按下 `Alt` 后再开始拖动节点 | 复制并拖动（P1） |
| `Alt` + 单击端口 | 断开该端口的所有连线 |
| `Shift` + 拖动节点 | 锁定为水平或垂直方向移动 |

> 注：当前工具是选择（V）时，在空白处拖动是**平移**（ComfyUI 的习惯），需要框选时用 Shift+拖动。当前工具是平移（H）时，在任何位置拖动都是平移。

## 13.2 滚轮与触控板

| 输入 | 判定依据 | 行为 |
|---|---|---|
| 鼠标滚轮 | `deltaMode=1`，或 `|deltaY| ≥ 50` 且没有 deltaX | 以光标为中心缩放，每格 ×1.1 |
| 触控板双指滑动 | delta 小，并带有 deltaX | 平移 |
| 触控板捏合 | wheel 事件带 `ctrlKey=true` | 以光标为中心缩放，系数 `exp(-deltaY*0.01)` |
| `⌘/Ctrl` + 任意滚轮 | 强制 | 缩放 |
| `Shift` + 鼠标滚轮 | 强制 | 水平平移 |

用户可以在设置里把鼠标滚轮改成「平移」（偏好项 `wheel: zoom | pan`）。缩放过程中暂停网格和文字过渡，停止 120ms 后恢复（性能规则 R9）。

## 13.3 拖放

| 来源 | 落点 | 结果 |
|---|---|---|
| 节点库条目 | 画布 | 在落点创建节点（左上角对齐落点并吸附网格） |
| 节点库条目 | 连线上（距离 ≤ 12px） | 插入到这条连线中间，两头自动连上；类型不兼容时只创建、不连线，并给出提示 |
| 节点库条目 | 端口上 | 创建节点并连到该端口 |
| 子图库条目 | 画布 | 创建子图引用节点 |
| 文件（P1） | 画布 | 创建资源节点（kind=文件，value=指针）；图片显示缩略图；多个文件 → 一个资源节点（列表） |
| 文件（P1） | 节点的输入端口 | 创建资源节点并连上 |
| 外部文本 | 画布 | 创建资源节点（常量） |
| 画布上的节点 | 节点库 | 无效，不支持拖回 |

拖动反馈：可放置区域外框变为 `--hx-line-3`；不可放置时光标为 `not-allowed`，并显示原因。

## 13.4 选择

- 选中集合是 `Set<id>`，节点和连线可以同时选中。
- `⌘/Ctrl+A`：选中当前层的全部节点（不包括子图内部）。
- `Esc`：清空选中；如果有弹层打开，先关闭弹层。
- 选中状态的变化**不**进入撤销历史。
- 进入子图后清空选中；返回上一层时恢复离开前的选中。
- 焦点在画布上时，`Tab` / `Shift+Tab` 按拓扑顺序在节点间移动焦点并选中。

## 13.5 复制、粘贴、复制一份

| 操作 | 规则 |
|---|---|
| `⌘/Ctrl+C` | 复制选中的节点，以及它们**之间**的连线；序列化为图片段 JSON 写入系统剪贴板（`text/plain` + 自定义 MIME），可以粘贴到另一个标签页 |
| `⌘/Ctrl+X` | 复制后删除，算一条 Op |
| `⌘/Ctrl+V` | 光标在画布内时，片段包围盒的左上角对齐到光标；否则放到视口中心；与原位置重合时偏移 (+2,+2) 格。粘贴后新节点处于选中状态 |
| `⌘/Ctrl+Shift+V` | 粘贴并**保留外部连线**：原外部连线的另一端如果在当前层还存在，就一并连上 |
| `⌘/Ctrl+D` | 复制一份，偏移 (+2,+2) 格 |
| 跨子图粘贴 | 允许。片段的外部连线丢弃；如果片段引用了只属于原层的账本（scope=local），粘贴后标记为「需要重新配置」，并显示警告徽标 |
| 粘贴 YAML 文本 | 剪贴板内容是 YAML 时按 YAML 解析成节点；解析失败时提示「剪贴板内容不是有效的图片段」 |
| id | 粘贴时全部重新生成 id，内部连线按新 id 重连 |

## 13.6 撤销与重做的粒度

所有修改都经过 `dispatch(op)`。合并规则如下：

| 场景 | 合并为 |
|---|---|
| 一次拖动多个节点 | 一条 `move_nodes`（从按下到松开） |
| 数字步进拖拽调值 | 一条 `set_param`（从按下到松开） |
| 文本输入连续键入 | 失焦或按 `Enter` 时一条；或停止输入 800ms 后一条 |
| 滑块拖动 | 一条 |
| 封装子图 | 一条 `group`（包含节点移动和连线改接） |
| 自动布局 | 一条 `layout` |
| 粘贴 | 一条 `paste` |
| YAML 应用 | 一条 `yaml_apply` |
| 模型的一批修改 | 每处一条 Op，共享同一个 `batch_id`；撤销按钮默认撤销整批，在操作历史里可以单条撤销 |
| 采纳提议 | 一条 `accept_proposal`（actor=模型，approved_by=用户） |

不进入历史的：选择、视口变化、面板开关、悬停、运行控制（运行、暂停、取消另有独立的运行记录）。

撤销反馈：受影响的节点外框闪一下 `--hx-line-3`（300ms），并弹出通知「已撤销：移动 3 个节点」。这条通知不带撤销按钮，而是带「重做」。
历史最多保留 500 条，更早的合并成一个检查点快照。

### 与浏览器快捷键冲突
| 组合 | 处理 |
|---|---|
| `⌘/Ctrl+D`（书签）、`⌘/Ctrl+P`（打印）、`⌘/Ctrl+=/-/0`（浏览器缩放）、`⌘/Ctrl+G`（查找下一个）、`⌘/Ctrl+E`、`⌘/Ctrl+K`、`⌘/Ctrl+J` | 焦点在画布/应用内时 `preventDefault()` 接管 |
| `⌘/Ctrl+W/T/N/Q/L/R`、`F5`、`F11`、`F12` | **不接管**，永远交给浏览器 |
| `Tab` | 只在焦点位于画布元素时接管；在表单内保持原生焦点切换 |
| 桌面应用（Electron 等） | 同表，额外可接管 `F11` 作全屏 |

### 生效范围优先级
弹层/对话框 > 文本输入框 > 逐条查看模式 > 画布 > 全局。焦点在输入框内时，单字母快捷键全部失效；`⌘K`、`⌘.`、`Esc` 例外。

### 用户自定义
- 设置 → 快捷键：表格列出所有命令，点击后按下新组合即可绑定；冲突时提示「已被"复制一份"使用，替换？」。
- 存储格式：`{ "command.id": "Mod+Shift+K" }`，`Mod` = Mac 的 ⌘ / 其他平台 Ctrl。
- 不可重绑：`⌘/Ctrl+.`（急停）。可恢复默认。

## 13.10 键盘导航与焦点顺序

页面级 Tab 顺序：顶部条 → 节点库 → 画布 → 检查器 → 运行抽屉 → 对话输入框。

画布获得焦点后（画布容器 `tabindex=0`，焦点环绕画布内侧 2px `--hx-focus`）：
| 键 | 作用 |
|---|---|
| `Tab` / `Shift+Tab` | 按拓扑顺序在节点间切换（专注模式开关需要焦点不在画布上，或使用命令面板） |
| `Enter` | 有子图则进入；否则聚焦该节点第一个内联控件 |
| `Esc` | 从控件回到节点；从节点回到画布；从子图返回上一层 |
| `←↑→↓` | 移动节点 1 格 |
| `Alt+→` / `Alt+←` | 沿连线跳到下游 / 上游节点 |
| `P` | 进入端口模式：方向键在端口间移动，`Enter` 开始连线，再选目标端口 `Enter` 完成 |
| `Space` | 打开节点的快捷菜单（同右键） |

焦点节点显示 `--hx-focus` 2px 外环（与选中环相同；键盘焦点额外显示 1px 内侧虚线以示区别）。

## 13.11 确认策略

原则：**可以撤销的直接执行**；**不可撤销或影响范围大的才确认**。

| 操作 | 策略 | 说明 |
|---|---|---|
| 删除节点、连线（任意数量） | 直接执行 + 通知「撤销」 | 可撤销 |
| 删除含 ≥ 10 个节点的子图 | 确认对话框 | 影响大（可勾「不再询问」） |
| 清空当前层 | 确认对话框 | |
| 解散子图 | 直接执行 + 撤销 | |
| 载入模板覆盖当前图 | 确认对话框（并自动存版本） | |
| 合并草稿到主线 | 差异对话框（列出新增/删除/修改）+ 确认 | |
| 丢弃草稿分支 | 确认对话框 | 不可撤销 |
| 回到旧版本 | 直接执行（当前状态自动存为新版本） | 可再回来 |
| 运行 | 直接执行 | |
| 取消运行 | 直接执行 | 已完成结果保留 |
| 急停 | **立即执行，永不确认** | |
| 解除急停 | 直接执行，随后要求重新选择档位 | |
| 授权档位提高到 3 / 4 | 确认（显示能力差异） | 降低档位直接执行 |
| 关闭污染标记 | 确认对话框（说明风险） | |
| 执行 L3 工具 | 人工审批节点（流程内） | |
| 采纳单条提议 | 直接执行 + 可撤销 | |
| 全部采纳 ≥ 10 处提议 | 确认（显示数量与类别统计） | |
| 删除扩展包 / 子图库条目 | 确认对话框（列出引用它的图） | |
| 关闭有未保存修改的标签 | 不需要——一切实时保存 | |
