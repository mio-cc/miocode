# 06 图标

> 适用范围：节点头部图标、停靠栏、工具栏、菜单、检查器、通知。
> 依赖令牌：`--hx-text-1/2/3`、`--hx-bg-5`、`--hx-r-sm`、语义色 `--hx-ok / --hx-danger / --hx-wait / --hx-model / --hx-accent-strong`。
> 本文所有 SVG 都可以直接复制使用，图标按名称收录在 `icons.js` 的 `HX.ICON` 对象中。

---

## 1. 设计规格

| 项 | 规格 | 说明 |
|---|---|---|
| 画板 | `viewBox="0 0 20 20"` | 所有图标都在 20×20 网格内绘制 |
| 安全区 | 四周各留 2px，主体落在 16×16 内 | 圆形主体直径 ≤ 15，方形主体 ≤ 14×14，保证视觉重量一致 |
| 线宽 | `stroke-width="1.5"` | 任何尺寸下都不缩放线宽（见 1.3） |
| 端点 / 拐角 | `stroke-linecap="round"`、`stroke-linejoin="round"` | 不允许出现尖角 |
| 填充 | 默认 `fill="none"`；只有"实心点"（半径 ≤ 1.75）可以用 `fill="currentColor"` | 不做面状填充图标 |
| 颜色 | `stroke="currentColor"` | 颜色由父元素的 `color` 决定，图标本身不写颜色 |
| 坐标精度 | 关键点落在 0.25 的整数倍上；1.5px 线的直线坐标放在 **x.75 或 x.25** | 在 1× 屏幕上，线正好覆盖整像素，不发虚 |
| 圆角矩形 | `rx` 用 1.5 或 2 | 和界面圆角 `--hx-r-sm` 的感觉一致 |
| 元素数量 | 一个图标最多 4 个图形元素 | 太复杂说明含义没想清楚 |

### 1.1 视觉重量统一

不同形状的面积感不同。按下面的尺寸画，看起来才一样大：

| 主体形状 | 外接尺寸 |
|---|---|
| 圆 | 直径 14–15 |
| 正方形 | 13×13 |
| 三角形 | 底 14、高 13 |
| 横向长条组合（如三条线） | 宽 14，总高 10–12 |

### 1.2 像素对齐示例

```svg
<!-- 正确：1.5px 线放在 x.75，覆盖 [4,5.5]，边缘清楚 -->
<path d="M4.75 6h10.5"/>
<!-- 错误：放在整数 5，覆盖 [4.25,5.75]，两侧发虚 -->
<path d="M5 6h10"/>
```

### 1.3 尺寸档位

| 档位 | CSS 尺寸 | 用于 | 线宽处理 |
|---|---|---|---|
| `xs` | 12px | 徽标内、端口类型标签、AI 签 | `vector-effect: non-scaling-stroke` 后线宽 1.25 |
| `sm` | 14px | 菜单项、检查器参数行、通知 | 1.5 |
| `md`（默认） | 16px | 节点头部图标格内、工具栏、停靠栏 | 1.5 |
| `lg` | 20px | 空状态、对话卡片标题 | 1.5 |

规则：图标统一用 `viewBox 0 0 20 20` 绘制，通过 CSS 的 `width/height` 缩放；对小于 16px 的档位加上 `vector-effect="non-scaling-stroke"` 并把 `stroke-width` 设为 1.25，防止线条糊成一团。

```css
.hx-icon { width: 16px; height: 16px; flex: none; color: inherit; }
.hx-icon--xs { width: 12px; height: 12px; }
.hx-icon--xs * { vector-effect: non-scaling-stroke; stroke-width: 1.25; }
.hx-icon--sm { width: 14px; height: 14px; }
.hx-icon--lg { width: 20px; height: 20px; }
```

### 1.4 颜色继承

图标不写颜色，由所在位置决定：

| 位置 | 颜色令牌 |
|---|---|
| 节点头部图标格（20×20，底色 `--hx-bg-5`，圆角 `--hx-r-sm`） | `--hx-text-2` |
| 工具栏、停靠栏按钮：默认 / 悬停 / 激活 | `--hx-text-2` / `--hx-text-1` / `--hx-text-1` |
| 菜单项 | `--hx-text-2`；危险菜单项 `--hx-danger` |
| 状态图标：成功 / 失败 / 挂起 / 运行中 | `--hx-ok` / `--hx-danger` / `--hx-wait` / `--hx-accent-strong` |
| AI 标记、模型相关 | `--hx-model` |
| 禁用 | `--hx-text-3` |

**禁止**：按节点类别给图标上不同颜色。类别靠图形区分，颜色只表达状态和身份。

### 1.5 节点头部图标格

```html
<span class="hx-node__icon"><svg class="hx-icon" viewBox="0 0 20 20">…</svg></span>
```
```css
.hx-node__icon {
  width: 20px; height: 20px; display: grid; place-items: center;
  border-radius: var(--hx-r-sm); background: var(--hx-bg-5); color: var(--hx-text-2);
}
.hx-node__icon .hx-icon { width: 14px; height: 14px; }
```

图标格里的图标用 `sm` 档（14px），这样四周有 3px 留白，看起来不挤。

## 4. 在代码里使用

### 4.1 图标表

```js
// icons.js —— 只存 path 片段，外壳统一生成
HX.ICON = {
  agent: '<rect x="3.75" y="4.75" width="12.5" height="11" rx="2.5"/>…',
  run:   '<path d="M6.25 4.25v11.5L15.5 10Z"/>',
  // …
};

HX.icon = (name, size = 'md', extraClass = '') =>
  `<svg class="hx-icon hx-icon--${size} ${extraClass}" viewBox="0 0 20 20" fill="none"
        stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round"
        aria-hidden="true" focusable="false">${HX.ICON[name] || HX.ICON.more}</svg>`;
```

- 找不到名称时回退到 `more`，开发环境下在控制台打印警告。
- 装饰性图标一律加 `aria-hidden="true"`。只有图标、没有文字的按钮，可读名称写在按钮的 `aria-label` 上，不写在 SVG 里。

### 4.2 节点类型 → 图标映射

| 节点 type | 图标 key |
|---|---|
| 资源 | `resource` |
| Agent | `agent` |
| 上下文装配 | `context` |
| 工具 | `tool` |
| 扇出 | `fanout` |
| 汇合 | `join` |
| 聚合 | `aggregate` |

## 5. 新增图标流程

1. **先确认是否真的需要**：同样的含义已有图标就复用；只是状态不同，用颜色区分，不要新画一个。
2. **在 20×20 网格上画**：遵守第 1 节规格。推荐先在 Figma 里建 20×20 画框，并放一个 16×16 的安全区参考框。
3. **自检**：

| 检查项 | 通过标准 |
|---|---|
| 线宽 | 只有 1.5，没有填充面（实心点除外） |
| 端点 | 全部圆头、圆角 |
| 视觉重量 | 和 `agent`、`ledger` 放在一起看，大小相当 |
| 16px 下的清晰度 | 1× 屏截图放大检查，直线没有发虚 |
| 12px 下的可辨认度 | 缩到 12px 依然能认出 |
| 两套主题 | 浅色（`--hx-text-2` 在 `--hx-bg-5` 上）和深色下都清楚 |
| 元素数量 | ≤ 4 |
| 颜色 | 没有写死任何颜色 |

4. **压缩**：去掉 Figma 导出带的 `id`、`fill`、`clip-path`、`<g>`，坐标保留 2 位小数。
5. **入库**：加入 `HX.ICON`，在本文档第 2 或第 3 节的表里补一行，写清用途。
6. **评审**：和三个相邻用途的图标并排，在浅色主题下截一张图，附在变更说明里。

## 6. 常见错误

| 错误 | 后果 | 改正 |
|---|---|---|
| 给不同类别的节点图标上不同颜色 | 画布变花，和状态色、类型色冲突 | 图标统一 `--hx-text-2` |
| 用 emoji 或字体图标代替 | 风格不统一，各系统渲染不同 | 用本文 SVG |
| 线宽随尺寸缩放（12px 时变成 0.9px） | 小图标发灰 | 小档位加 `non-scaling-stroke` |
| 直线落在整数坐标 | 1× 屏幕上发虚 | 移到 x.25 / x.75 |
| 在 SVG 内写 `<title>` 当可读名称 | 屏幕阅读器重复朗读 | 名称写在按钮的 `aria-label` |
| 浅色主题下把图标格背景设成白色 | 图标格和节点主体融为一体 | 图标格固定用 `--hx-bg-5` |
