# Harness · 积木编排 UI/UX 设计规范 v0.3

> 本文档是**摘要版**。细则拆分在 `docs/` 下的 20 份文档里，从 `docs/00_README.md` 开始读；摘要和细则冲突时以 `docs/` 为准。
> **默认主题是浅色（白天白色）**，深色是可选项。
> 令牌（颜色、字号、间距、圆角、动效）的唯一来源是同目录的 `tokens.css`。本文只引用令牌名，不写裸值。
> 旗舰实现：`画布_旗舰demo.html`。规范和 demo 不一致时，以本文档为准，并修改 demo。

## 0. 给接手者的 60 秒速读

1. **气质**：精密仪器面板，不是营销页。默认白天浅色工作台（白色面板浮在浅灰底上），信息靠层级和留白区分，颜色只用来**表达含义**。
2. **颜色有严格分工**：
   - 橙 `--hx-accent`：运行中、主路径、主按钮
   - 绿 `--hx-ok`：完成
   - 红 `--hx-danger`：失败、删除、急停
   - 黄 `--hx-wait`：挂起、等待审批
   - 蓝紫 `--hx-model`：**模型做的事**
   - 端口和连线用 `--hx-type-*`，**按数据类型着色**
   - 其余一律中性灰。
3. **三条动效铁律**：只动 `transform` 和 `opacity`；拖拽时直接写 DOM，不走重新渲染；所有动画都能被 `prefers-reduced-motion` 关掉。
4. **一切修改走 `dispatch(op)`**：人点按钮、模型改图、YAML 应用，都生成同一种 Op，进入历史，可以撤销。界面上**永远标出操作者是谁**。
5. **画布交互要和 Figma、ComfyUI 的用户习惯一致**（见第 6 节），不要发明新手势。

## 1. 设计原则

| # | 原则 | 落地方式 |
|---|---|---|
| P1 | **内容是主角，界面退后** | 面板浮在画布上方，不切割画布；铬件（工具栏、边框）用最低对比度 |
| P2 | **颜色 = 含义** | 一个颜色只表达一种含义。装饰性用色一律禁止 |
| P3 | **状态一眼可读** | 节点状态同时用颜色、图形和文字三种方式表达，不能只靠颜色 |
| P4 | **模型的行为永远可见** | 模型做的事带 `--hx-model` 标记和理由，可以撤销 |
| P5 | **直接操作优先** | 能在节点上直接改的就不进检查器；能拖的就不用点；常用操作都有快捷键 |
| P6 | **流畅是功能** | 拖拽、缩放、连线保持 60fps；任何操作 100ms 内要有视觉反馈 |
| P7 | **渐进披露** | 缩小时节点只显示标题；悬停才出类型；选中才出完整参数 |

**禁止**：渐变色块、玻璃拟态、彩虹配色、emoji 图标、每个卡片都带悬停动画、每个区块都有入场动画、全大写小标签、同一圆角和阴影套在所有元素上。

## 2. 令牌

### 2.1 表面层级（深色主题）

| 令牌 | 用途 |
|---|---|
| `--hx-bg-0` | 应用最底层：侧栏、对话背景 |
| `--hx-bg-1` | 画布底 |
| `--hx-bg-2` | 浮动面板：检查器、停靠栏、节点库 |
| `--hx-bg-3` | 节点主体、卡片 |
| `--hx-bg-4` | 输入框、悬停态 |
| `--hx-bg-5` | 按下态、分段控件的选中项 |

规则：**每往上浮一层，背景亮一档**。不要用阴影代替层级。只有浮动元素（面板、菜单、被拖起来的节点）才有阴影。

### 2.2 线
- `--hx-line-1`：内部分区
- `--hx-line-2`：组件外框
- `--hx-line-3`：悬停

所有表面顶部加 1px 内高光 `--hx-highlight`（已经写在阴影令牌里），这是让界面显得精致的关键细节。

### 2.3 文字
- `--hx-text-1`：标题、数值
- `--hx-text-2`：次要信息
- `--hx-text-3`：标签、占位

同一个组件里最多用两级文字颜色。

### 2.4 端口类型色

| 类型 | 令牌 | 典型端口 |
|---|---|---|
| 任意 | `--hx-type-any` | 汇合.in、子图端口 |
| 上下文包 | `--hx-type-ctx` | 上下文装配.context → Agent.context |
| 资源引用 | `--hx-type-ref` | 资源.ref → Agent.model |
| 列表 | `--hx-type-list` | 扇出.results、聚合.items |
| 工具端点 | `--hx-type-tool` | 工具.endpoint → Agent.tools |
| 泛型 T/U | `--hx-type-gen` | Agent.result、分支.value |
| 判定 / 控制 | `--hx-type-ctrl` | 分支的各个出口 |
| 状态 | `--hx-type-state` | 账本.value |

连线颜色等于**源端口**的类型色。新增类型必须映射到这 8 类之一，不能新增颜色。

### 2.5 字体与字号
- UI 字体 `--hx-font-ui`：Latin 用 Geist，中文回退到 Noto Sans SC、微软雅黑
- 等宽 `--hx-font-mono`：数值、类型名、路径、快捷键、YAML
- 字号只允许 8 档：`--hx-fs-10/11/12/13/14/16/20/28`。界面基准是 13
- 字重只用 400 / 500 / 600。数字一律设 `font-variant-numeric: tabular-nums`

### 2.6 间距、圆角、尺寸
- 间距：4 的倍数，令牌 `--hx-s-1…10`
- 圆角按层级递增：徽标 `xs`、输入 `sm`、按钮 `md`、节点和面板 `lg`、停靠栏和对话卡片 `xl`
- **嵌套圆角**：内层圆角 = 外层圆角 − 内边距，最小为 `xs`
- 控件高度：标准 `--hx-ctl-h`（28），紧凑 `--hx-ctl-h-sm`（24）

### 2.7 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 悬停、按下 | `--hx-t-1` | `--hx-ease` |
| 选中、状态变化、展开折叠 | `--hx-t-2` | `--hx-ease` |
| 面板、菜单、弹层进入 | `--hx-t-3` | `--hx-ease-out` |
| 离开 | `--hx-t-2` | `--hx-ease-in` |
| 视图过渡：适应视图、聚焦节点、展开画布 | `--hx-t-4` | `--hx-ease-out` |

允许做动画的属性：`transform`、`opacity`、`stroke-dashoffset`、`background-color`、`border-color`、`box-shadow`（只在选中或运行时）。**禁止对 `width/height/top/left` 做动画。**

## 3. 界面结构：画布在对话里

### 3.1 三种嵌入形态

| 形态 | 位置 | 尺寸 | 显示内容 |
|---|---|---|---|
| **卡片** | AI 回复中的一张卡片 | 宽度占满对话列，高 440 | 只读缩略画布 + 状态行 + 「打开」。可以看运行状态，不能编辑 |
| **展开** | 占满中间栏，对话输入框保留在底部 | 中间栏全高 | 完整编辑能力。可以一边看图一边用文字指挥模型 |
| **全屏** | 覆盖整个应用 | 视口 | 和展开一样，加上隐藏侧栏，适合大图 |

切换卡片和展开时，用 FLIP 动画从卡片位置放大到中间栏，时长 `--hx-t-4`，期间画布内容保持当前视角。快捷键：`F` 切换全屏，`Esc` 退回上一形态。

### 3.2 展开态布局（浮层式，画布占满）

```
┌──────────────────────────────────────────────────────────────┐
│ ① 顶部条：面包屑 · 分支 · │ 授权档位 · 运行状态 · 运行 ▶ · 急停  │ 48
├──────┬───────────────────────────────────────────┬───────────┤
│ ②    │                                           │ ④ 检查器  │
│ 节点库│              画布（满铺）                  │  320 宽   │
│ 260  │                                           │  浮动面板 │
│ 可收起│                                           │  选中时出现│
│      │   ⑥ 小地图        ③ 底部停靠栏（居中）      │           │
├──────┴───────────────────────────────────────────┴───────────┤
│ ⑤ 运行抽屉（可拖动高度）：时间线 · 日志 · 操作历史               │ 0–40%
├──────────────────────────────────────────────────────────────┤
│ 对话输入框（保留，可以文字指挥模型改图）                           │
└──────────────────────────────────────────────────────────────┘
```

- ②、④、⑥ 都是**浮在画布上方**的面板：距边缘 12px，背景 `--hx-bg-2`，阴影 `--hx-shadow-float`，圆角 `--hx-r-lg`。画布始终满铺。
- ③ 停靠栏放工具：选择 V、平移 H、添加 A、封装 ⌘G、自动布局 L、适应 1。用 `--hx-r-xl` 胶囊形。
- 按 `Tab` 隐藏或显示所有浮动面板，进入专注模式。

## 4. 画布

### 4.1 背景
- 点阵网格，间距 `--hx-grid` × 缩放倍率，点色 `--hx-grid-dot`
- 缩放低于 0.5 时网格间距翻倍，避免点阵过密
- 网格用 CSS `background-image` 画，平移和缩放时只改 `background-position` 和 `background-size`，不重建 DOM

### 4.2 视图
- 缩放范围 0.2–2.5，滚轮缩放以光标为中心，每格 ×1.1。触控板捏合同理
- **细节分级（LOD）**：

| 缩放 | 显示 |
|---|---|
| ≥ 0.75 | 完整节点：端口名、内联控件、状态文字 |
| 0.45–0.75 | 隐藏端口名和控件，只留端口圆点、标题、状态条 |
| < 0.45 | 节点缩成色块加大号标题；连线变细 |

- 「适应视图」「聚焦节点」用视图过渡动画，不跳变

### 4.3 选择
- 单击选中；`Shift` 或 `⌘/Ctrl` + 单击加选或减选
- `Shift` + 在空白处拖动是框选，框选区域用 `--hx-marquee` 填充、`--hx-marquee-line` 描边（中性灰，不用模型色）
- 选中描边：节点外 2px 处画 1.5px 的 `--hx-focus` 环（outline + outline-offset），不改变节点尺寸
- 多选时检查器显示「已选 N 个」和批量操作

### 4.4 吸附与对齐
- 节点拖动默认吸附到网格，按住 `Alt` 临时关闭
- 和相邻节点的左边、右边、中线、顶边对齐时，显示 1px 的 `--hx-line-3` 对齐参考线（可选，P1）

## 5. 节点

### 5.1 结构

```
        ┌──────────────────────────────────────┐
        │ [图标] 标题                  ● 状态   │ ← 头部 38：图标 20、标题 14/600
        │        类型 · 标签（mono 10.5）       │
        ├──────────────────────────────────────┤
  ●─────┤ context  上下文包                    │ ← 端口行 24：输入在左，输出在右
  ●─────┤ model                       result ├─────●
        ├──────────────────────────────────────┤
        │ 输出类型        [ 方案@1        ▾ ] │ ← 内联控件行 28（最多 3 行）
        │ 并发            [ −   3   + ]       │
        ├──────────────────────────────────────┤
        │ ▬▬▬▬▬▬▬▬▬▬▬▱▱▱▱  生成中 62%         │ ← 状态脚（只在运行时出现）
        └──────────────────────────────────────┘
```

- 宽：标准节点 `--hx-node-w`，紧凑节点 `--hx-node-w-sm`
- 主体背景 `--hx-bg-3`，外框 `--hx-line-2`，圆角 `--hx-r-lg`，阴影 `--hx-shadow-node`
- 图标格是 20×20 的圆角块，背景 `--hx-bg-5`，里面是 1.5px 线宽的单色 SVG 图标，颜色 `--hx-text-2`。**图标颜色不随类别变化**，类别用图形区分
- 端口圆点直径 `--hx-port`，填充为类型色，外面加 2px 的 `--hx-bg-3` 描边，让圆点和节点边缘之间有一道细缝。圆点圆心正好落在节点左右边框上
- 端口名用 `--hx-fs-12`、`--hx-text-2`；悬停时在旁边浮出类型名标签（mono 10.5，类型色）
- **内联控件**：每个节点最多直接放 3 个最常改的参数，其余放进检查器。控件见第 7 节
- 由参数转成的端口，在输入端口列表里显示，端口名后加一个小的「⇢」标记

### 5.2 状态

| 状态 | 外框 | 头部状态点 | 状态脚 | 其他 |
|---|---|---|---|---|
| 待运行 idle | `line-2` | 无 | 隐藏 | — |
| 排队 queued | `line-3` | 空心灰圆 | “排队中” | — |
| 运行中 running | `accent-line` + 外发光 `0 0 0 3px accent-weak` | 橙色旋转弧 | 橙色进度条 + 百分比 | 出边显示流动 |
| 完成 done | `line-2` | 绿色对勾 | 收起，留 2px 绿线 1.2s 后淡出 | 头部显示耗时（mono） |
| 失败 failed | `danger` | 红色叉 | 红色错误摘要 | 「重试」按钮 |
| 挂起 waiting | `wait` 虚线 | 黄色暂停符 | “等待审批 · 2 分钟” | 审批按钮直接显示在节点上 |
| 跳过 skipped | `line-1` | 灰色横线 | 隐藏 | 整个节点透明度 0.45 |
| 缓存命中 cached | `line-2` | 灰色闪电 | 隐藏 | 头部显示“缓存” |

状态切换时，外框和阴影过渡 `--hx-t-2`；进度条用 `transform: scaleX()` 变化。

### 5.3 模型标记
- 模型创建或修改过的节点，头部右上角显示一个 16px 高的「AI」小签（`--hx-model-weak` 底、`--hx-model` 字）。悬停显示模型理由、时间、所用授权，以及「撤销」
- **幽灵节点**（模型提议、尚未采纳）：主体透明度 0.72，外框改为 1.5px `--hx-model-line` 虚线，头部下方加一条提议条：「模型提议 · 理由一句话 · [采纳] [拒绝]」。幽灵连线是 `--hx-model` 虚线
- 被删除的提议：红色虚线外框，标题加删除线
- 被修改的参数：值前显示 `旧值 →` 并划线，新值用 `--hx-model` 色

### 5.4 子图节点
- 外观上，节点右侧和底部各多一道 4px 的「叠层边」，表示里面还有一层
- 节点主体显示内部缩略图（64px 高，只画方块和线）和「N 个节点」
- 双击进入时，用视图过渡从节点位置放大进入子图；面包屑同步更新
- 循环节点的头部显示轮次「2 / 5」，运行时用环形进度表示

### 5.5 交互热区
- 拖动节点：头部区域，以及节点主体上不是控件或端口的地方
- 端口热区：圆点周围 18×18 范围
- 节点悬停时外框变为 `line-3`，不加阴影，不放大

## 6. 连线

### 6.1 形状与样式
- 三次贝塞尔曲线，两端切线保持水平。控制点偏移 = `clamp(|dx| × 0.5, 48, 180)`；当终点在起点左侧（回连）时偏移固定为 120，让曲线绕出去
- 线宽 1.75，悬停 2.5，选中 2.5 并外加一层 6px 宽、透明度 0.18 的同色描边作为光晕
- 颜色 = 源端口类型色，透明度 0.75；完成后变为 1
- **运行中**：叠加一条 `stroke-dasharray: 1 11`、`stroke-linecap: round` 的 `--hx-accent` 路径，持续动画 `stroke-dashoffset`，看起来像光点在流动
- 每条线另有一条 14px 宽的透明路径作为点击热区

### 6.2 连线交互（照搬 ComfyUI 和 Figma 的习惯）

| 操作 | 结果 |
|---|---|
| 从输出端口按下并拖动 | 拉出一条预览线，跟随光标；画布上**兼容的输入端口放大并发亮，不兼容的变暗** |
| 拖到兼容端口 18px 范围内 | 端点吸附过去，端口出现一圈光环 |
| 在端口上松开 | 建立连线。目标端口不支持多连时，替换旧线并给提示 |
| 在空白处松开 | 打开**快速添加**面板，只列出能接这种类型的节点；选中后自动创建节点并连好线 |
| 从已连接的输入端口拖出 | 把这条线拔下来，可以重新接到别处；拖到空白处松开就删除 |
| 悬停连线 | 线变粗，中点出现「+」（插入节点）和「×」（删除）两个小按钮 |
| 按 `Alt` 点击端口 | 断开这个端口上的所有连线 |
| 类型不兼容 | 预览线变成红色虚线，旁边显示原因，比如「列表 不能接 上下文包」 |
| 连出环 | 拒绝，提示「环只能通过循环节点形成」 |

## 7. 控件库

所有控件高度为 `--hx-ctl-h`（节点内用 `--hx-ctl-h-sm`），背景 `--hx-bg-4`，外框为透明。悬停时外框变为 `line-3`，聚焦时外框变为 `--hx-text-2`，再加 `0 0 0 3px` 的同色 15% 光晕。

| 控件 | 规格 | 交互 |
|---|---|---|
| **按钮** | 主按钮：`accent` 底、`text-inv` 字。次按钮：`bg-4` 底。幽灵按钮：透明底。危险按钮：`danger-weak` 底、`danger` 字 | 按下时 `scale(.97)`；加载时文字换成旋转弧 |
| **图标按钮** | 28×28，`r-md` | 悬停时背景变为 `bg-4`；带快捷键提示 |
| **数字步进** | `[ − 数值 + ]`，数值用 mono 字体 | 在数值上**左右拖动**可以连续调整（Shift 加速）；滚轮调整；双击进入输入 |
| **滑块** | 轨道 4px，`bg-5`；已填充部分 `text-2`；拇指 12px | 拖动时在上方浮出当前数值 |
| **下拉选择** | 右侧带 ▾，弹层用 `bg-2` 和 `shadow-pop` | 可以输入过滤；键盘上下选择 |
| **分段控件** | 2–5 段，选中段 `bg-5` | 选中背景用滑块动画在段之间移动 |
| **开关** | 28×16 | 打开时轨道为 `accent` |
| **文本、代码框** | mono 字体，行号用 `text-3` | 支持 YAML 高亮：键名 `text-2`，字符串 `type-list` 色，数字 `type-ctx` 色 |
| **标签、徽标** | 高 18，`r-xs`，mono 10.5 | 状态徽标统一用「弱色底 + 实色字」 |
| **参数转端口** | 参数行右侧有一个 14px 的端口图标 | 点击后这个参数变成输入端口，图标变为类型色 |
| **提示框** | `bg-2`，`shadow-pop`，延迟 400ms 出现 | 显示内容 + 快捷键 |

## 8. 浮动面板

### 8.1 节点库（左）
- 顶部是搜索框（`/` 聚焦），下面按类别分组的列表，每项高 32：图标 + 名称 + 一行很淡的描述
- 可以直接拖到画布上；拖动时显示节点的半透明预览
- 底部 Tab 切换「原子节点 / 子图库 / 扩展包」

### 8.2 检查器（右）
- 只在有选中时滑入，从右侧 `translateX(12px)` + 透明度渐入，时长 `t-3`
- 结构：头部（图标、可编辑的标题、类型、状态徽标）→ 参数分组（可折叠）→ 端口 → 运行信息 → 模型记录
- 每个参数行：左边标签，右边控件，最右边「转端口」图标。被内核锁定的参数显示一个锁形图标，不能修改

### 8.3 小地图（左下）
- 180×120，背景 `bg-2`。节点画成小方块，当前视口画成 `text-2` 线框
- 在小地图上拖动或点击，可以移动视图
- 用 `<canvas>` 绘制，只在图结构变化时重画，视图变化时只移动视口框

### 8.4 运行抽屉（底部）
- 三个 Tab：时间线、日志、操作历史
- 时间线：每个节点一行；并行执行重叠显示；可以点击某一时刻回看当时状态
- 操作历史：每条操作显示操作者（人或模型，模型用 `--hx-model`）、时间、内容、理由，以及「回到此处」

## 11. 性能规范（硬性要求）

| # | 规则 | 原因 |
|---|---|---|
| R1 | 平移和缩放只改**一个**世界容器的 `transform: translate3d() scale()`，并设 `will-change: transform` | 交给 GPU 合成，不触发布局 |
| R2 | **端口坐标用布局常数计算**（节点 x + 宽度，y + 头部高 + 行号 × 行高 + 半行），不用 `getBoundingClientRect` | 避免在动画帧里强制回流 |
| R3 | `pointermove` 只记录最新坐标，在 `requestAnimationFrame` 里统一处理，每帧最多一次 | 防止事件比帧还多 |
| R4 | 拖动节点时只更新被拖节点的 `transform`，以及和它相连的连线的 `d` 属性；不重建其他 DOM | 拖动时工作量和图的大小无关 |
| R5 | 节点 DOM 按 id 复用，状态变化只切换 class 和文字，不重写 innerHTML | 保持事件绑定和焦点 |
| R6 | 用 `setPointerCapture` 处理拖动，指针移出画布也不会丢 | 交互更稳 |
| R7 | 节点数 > 150 时开启视口裁剪：视口外的节点设 `content-visibility: hidden`，连线不画 | 大图也流畅 |
| R8 | 连线全部放在一个 SVG 里；运行流动动画只加在活跃的连线上 | 控制合成层数量 |
| R9 | 缩放过程中暂时关闭网格和文字过渡，停止 120ms 后再恢复 | 缩放时不卡 |
| R10 | 目标：200 个节点、300 条连线时，拖动和缩放保持 60fps | 验收标准 |

## 12. 代码结构约定（实现参考）

```
state = {
  graph:   { nodes: Map<id, Node>, edges: Map<id, Edge> },   // 数据，唯一事实来源
  view:    { x, y, k },                                      // 视口
  ui:      { selection: Set<id>, hover, tool, panels },      // 界面状态
  run:     { status, nodeStatus: Map<id, Status>, progress },
  history: { past: Op[], future: Op[] },
  actor:   'user' | 'model',
  level:   0..4                                              // 当前授权档位
}

dispatch(op)   // 唯一修改入口：校验 → 授权 → apply → 写入历史 → 增量渲染
  op = { kind, actor, reason?, payload, inverse }            // inverse 用于撤销

render 分三层：
  renderView()       只改世界容器 transform、网格、小地图视口框
  renderNode(id)     创建或更新单个节点 DOM（按 id 复用）
  renderEdges(ids?)  只重算指定连线的 path d
```

- 节点 DOM 结构固定：`.hx-node > .hx-node__head + .hx-node__ports + .hx-node__widgets + .hx-node__foot`
- class 命名用 BEM 并加 `hx-` 前缀；状态用 `is-running`、`is-selected`、`is-ghost` 这类修饰类
- 文案集中放在一个 `T = { ... }` 对象里，方便以后做多语言

## 13. 可访问性
- 所有可点击元素都用 `<button>`，并能用键盘聚焦；焦点环使用 `--hx-focus`
- 正文对比度 ≥ 4.5:1，次要文字 ≥ 3:1（深色和浅色主题都已按这个标准校过）
- 状态不能只靠颜色区分：每种状态都同时有图形和文字
- 画布本身提供键盘操作：Tab 在节点之间切换，方向键移动节点
